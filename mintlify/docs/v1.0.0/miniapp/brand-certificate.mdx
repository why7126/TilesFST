# 小程序品牌与证书

本页说明小程序中品牌和证书的浏览方式。

![小程序首页品牌入口截图](/assets/screenshots/sha256-1225c7d9dfcb2200-miniapp-home.png)

## 品牌列表

1. 点击底部“品牌”。
2. 浏览品牌列表和品牌卡片。
3. 点击品牌进入品牌详情。

v1.0.0 修复了品牌列表轮播图中的多余文案展示问题，页面不再显示 `BRAND GALLERY` 或“轮播图保持现有品牌页能力”等说明性文案。

## 品牌详情

品牌详情用于查看品牌介绍、品牌图片和品牌相关商品。

常用操作：

- 查看品牌基础信息。
- 浏览品牌图片。
- 点击品牌商品进入商品详情。
- 从证书详情返回品牌主页。

## 证书列表

![管理端媒体上传截图](/assets/screenshots/sha256-ac2a20b7e3fb1ef4-admin-brand-certificate.png)

1. 点击底部“证书”。
2. 浏览证书名称、类型、所属品牌和证书图片。
3. 点击证书进入详情。

证书图片类素材会优先展示缩略图，加载失败时回退原图或占位图。

## 证书详情

详情页展示证书名称、类型、编号、发证机构、有效状态、备注、所属品牌和证书文件。

常用操作：

- 预览证书图片。
- 打开或复制证书文件链接。
- 点击所属品牌进入品牌详情。
- 分享证书页面。

## 异常提示

- “证书文件暂不可预览”：当前文件类型或链接不支持直接预览。
- “图片预览失败”：图片 URL 不可访问或网络异常。
- “品牌主页暂不可打开”：品牌信息缺失或跳转失败。

遇到异常时，可先刷新页面；若持续出现，联系企业内部维护人员检查管理端证书、品牌和媒体文件状态。
