# 公开/店主浏览说明

公开浏览入口用于将用户引导到管理端登录或移动端产品浏览链路。v1.0.0 的 Web 根路径提供 Web 展示端入口，并可进入管理端登录。

![Web 管理端登录入口截图](/assets/screenshots/sha256-3f9a5408df8e587d-web-login.png)

## Web 展示入口

1. 打开 Web 根路径。
2. 查看 TilesFST 展示端入口。
3. 企业内部员工点击“进入管理端登录”进入后台。

当前 Web 展示端仍以入口页和管理端为主；店主完整浏览体验主要在微信小程序中完成。

## 店主浏览建议

- 使用微信小程序浏览首页、分类、品牌、证书和收藏。
- 商品图片、品牌图片和证书图片优先通过后端受控媒体链路读取。
- 如图片加载失败，可重试或联系维护人员检查媒体状态。

## 公开信息边界

公开用户只能查看已发布、允许展示的商品、品牌、证书和图片。内部管理功能、账号管理、日志审计、API 文档和系统设置仅面向授权员工或管理员。
