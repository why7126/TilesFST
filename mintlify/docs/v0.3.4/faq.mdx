# 常见问题

![小程序商品列表真实截图](/assets/screenshots/sha256-9180ce7351ecfa54-miniapp-sku-detail.png)

## v0.3.4 是否需要重新培训用户？

建议对内部维护人员补充说明品牌图片、证书图片缩略图和 usage docs 快照；小程序用户侧主要感知为图片加载和品牌列表文案优化，不需要复杂培训。

## 为什么 v0.3.4 下有完整手册？

历史版本未生成 usage docs。v0.3.4 作为当前发布版本，一次性补齐当前产品公开使用手册，后续版本以本快照为基线维护。

## 管理端看不到用户管理、日志或设置怎么办？

这些入口需要管理员权限。普通员工只能访问日常资料维护页面。请联系管理员确认账号角色和状态。

## 图片上传成功但列表不显示怎么办？

先刷新列表或重新进入页面。若仍不显示，检查媒体 URL 是否可访问，确认原图和缩略图对象存在。品牌图片和图片类证书在 v0.3.4 起会优先使用缩略图，缩略图失败时应回退原图或占位图。

## 小程序商品或证书打不开怎么办？

可能是目标数据已下架、状态不可展示、网络异常或媒体链接不可用。可返回列表重试；若持续出现，由维护人员在管理端检查商品、品牌、证书和媒体状态。

## 收藏会同步到其他设备吗？

当前收藏保存在本机。更换设备或清理本地数据后，收藏可能不可见。

## 发布部署需要注意什么？

生产部署 env 必须显式设置 `TILESFST_IMAGE_TAG=v0.3.4`。镜像包 sha256 以 v0.3.4 release manifest 记录为准。

## 本手册可以写内部配置或运维地址吗？

不可以。本手册是公开使用文档，不得写入真实密钥、数据库连接串、Authorization header、Cookie、对象存储凭据、生产私有运维地址或真实客户数据。
