# 小程序使用说明

小程序面向店主、导购和公开浏览用户，提供首页、分类、品牌、证书、收藏和搜索等入口。底部自定义 Tab 包含：首页、分类、品牌、证书、收藏。

![小程序首页截图](/assets/screenshots/sha256-1225c7d9dfcb2200-miniapp-home.png)

## 页面入口

| 页面 | 用途 |
|---|---|
| 首页 | 浏览门店信息、Banner、新品、热门和快捷入口。 |
| 分类 | 按一级/二级类目进入商品列表。 |
| 品牌 | 浏览品牌列表，进入品牌详情和品牌相关商品。 |
| 证书 | 查看公开证书列表和证书详情。 |
| 收藏 | 查看本机已收藏商品。 |
| 搜索 | 按关键词查找商品。 |
| 商品列表 | 查看全部、分类、新品、热门或品牌关联商品。 |
| 商品详情 | 查看图片、视频、参数、品牌、类目、收藏和相关推荐。 |
| 门店信息 | 查看门店基础介绍。 |

## 基本操作

- 点击底部 Tab 切换首页、分类、品牌、证书和收藏。
- 点击顶部或页面内搜索入口进入搜索页。
- 点击商品卡片进入商品详情。
- 点击品牌卡片进入品牌详情。
- 点击证书卡片进入证书详情。
- 在详情页可收藏商品；收藏保存在本机。

## 图片与缩略图

v0.3.3 起品牌图片和图片类证书会优先使用真实缩略图。用户侧感知是列表加载更轻，图片失败时会尽量回退原图或占位图，不应出现浏览器破图或异常空白。

## 分享

商品详情、证书详情等页面支持微信分享能力。分享后进入的用户应看到对应商品或证书的公开信息。
