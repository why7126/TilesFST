# 商品资料维护

本页说明管理端中分类、规格和 SKU 的维护方式。建议先维护分类、规格和品牌，再创建或编辑 SKU。

![SKU 管理列表截图](/assets/screenshots/sha256-1761a95b2917d44e-admin-sku-list.png)

## 类目管理

类目用于组织小程序分类页和商品筛选。

1. 进入“类目管理”。
2. 点击“新增”创建一级或二级类目。
3. 填写类目名称、排序和状态。
4. 保存后在列表中确认层级、路径和状态。
5. 如需下架类目，先确认关联商品展示影响。

注意事项：

- 当前类目按一级/二级结构维护。
- 类目名称应简短清晰，避免过长导致小程序展示拥挤。
- 已被商品引用的类目删除可能受限。

## 规格管理

规格用于 SKU 的尺寸、型号或规格筛选。

1. 进入“规格管理”。
2. 新增或编辑规格名称、排序和状态。
3. 保存后在 SKU 表单中选择对应规格。

注意事项：

- 停用规格前确认是否仍有商品使用。
- 规格命名建议保持统一格式，便于搜索和筛选。

## SKU 管理

SKU 是对外展示的商品资料核心。

1. 进入“SKU 管理”。
2. 使用品牌、类目、状态或关键词筛选已有商品。
3. 点击“新增”或“编辑”进入表单。
4. 维护商品名称、品牌、分类、规格、价格、卖点、状态、图片和视频。
5. 上传主图和素材图，确认上传回显正常。
6. 保存后在列表中检查排序、状态和图片展示。

## 上下架与展示

- 草稿或下架状态的商品不应作为公开主推内容。
- 上架前检查主图、分类、品牌、规格和价格信息是否完整。
- 下架后确认小程序首页、分类、搜索和详情入口不再错误展示。

## 图片与视频

- 主图用于商品卡片、列表和详情页首屏展示。
- 多图用于详情页素材浏览。
- 视频用于详情页播放；如视频不可用，页面应保持图片和文字信息可浏览。
- 缩略图用于提升列表加载速度，若缩略图不可访问，系统会尝试回退到原图或占位图。

## 发布前检查

- 商品名称、品牌、分类、规格准确。
- 主图可访问，缩略图不是原图字节复制。
- 列表、详情、小程序卡片均能看到正确图片。
- 状态、排序和筛选结果符合预期。
