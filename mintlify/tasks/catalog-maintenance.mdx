# 商品资料维护

商品资料维护覆盖分类、规格、SKU、上下架状态和公开展示信息，是管理端最常用的工作流。

<Steps>
  <Step title="维护基础资料">
    从 [管理端使用说明](/docs/latest/admin/index) 进入商品资料模块，确认账号具有维护权限。
  </Step>
  <Step title="调整分类、规格和 SKU">
    按 [商品资料维护说明](/docs/latest/admin/catalog) 检查分类层级、规格项、SKU 状态和展示字段。
  </Step>
  <Step title="从小程序侧复核展示">
    对外展示问题应回到 [小程序浏览说明](/docs/latest/miniapp/browse) 复核搜索、筛选和详情页表现。
  </Step>
</Steps>

<Warning>
商品资料变更会影响公开浏览体验。文档站只记录使用方式，不替代正式发布公告和 release manifest。
</Warning>
