# TILESFST v0.3.1

发布时间：2026-07-31 23:43:40

关联 Sprint：sprint-015

TILESFST v0.3.1 汇总 Sprint 015 的已归档交付，聚焦管理端筛选与类目维护体验、小程序品牌列表体验，以及商品卡片图片链路稳定性。

## 新增功能

- 微信小程序品牌列表页优化品牌 Hero、品牌矩阵、品牌卡片和类目胶囊交互。
- 品牌卡片与类目胶囊点击边界拆分，支持品牌详情与品牌类目商品列表的独立跳转。

## 修复 BUG

- 修复管理端 SKU 列表类目筛选只能选择一级类目的问题，支持级联选择和父类目包含子孙类目 SKU。
- 修复管理端 SKU 素材列展示冗余主图状态标签的问题，素材列收敛为图片数量和视频数量。
- 修复管理端类目树右侧计数口径，节点显示下一层级类目数量，“全部类目”显示顶层类目数量。
- 修复小程序商品列表图片加载优化后的无图回归，补齐公开列表主图、同路径缩略图生成和历史回填链路。
- 统一管理端品牌、类目、规格、品牌证书、Banner、用户、系统设置、日志审计、接口文档和界面主题等页面的筛选下拉样式。

## 发布注意事项

本版本 release-prepare、image-prepare 与 image-build 已执行，测试阻断项已修复，镜像构建计划和镜像 manifest 均已生成并校验通过。当前可进入发布确认。

## 已知问题

- 小程序 DevTools 多尺寸、真机验收和对象存储历史缩略图回填执行仍需发布前补录或确认。
- 生产 Compose fallback tag 仍是旧版本，发布环境需显式设置 `TILESFST_IMAGE_TAG=v0.3.1`。

## 升级步骤

1. 部署前完成数据库、环境变量和媒体对象存储配置备份，并显式设置 `TILESFST_IMAGE_TAG=v0.3.1`。
2. 使用 `../releases/v0.3.1/images/tilesfst-v0.3.1-linux-amd64.tar.gz` 和对应 sha256 完成镜像交付或加载。
3. 部署后执行管理端 SKU 列表、类目树、筛选下拉，小程序品牌列表、商品列表图片和公开媒体 URL smoke。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 复核对象存储公开访问边界、缩略图回退和公开 SKU cover_image 返回策略。
4. 如发现数据或媒体链路异常，按发布前备份执行恢复。

## 影响范围

| 范围 | 影响 |
|---|---|
| Web 管理端 | SKU 列表类目级联筛选、素材列展示、素材完整度筛选移除、类目树计数口径、多页面筛选下拉一致性 |
| 店主 Web | 不涉及 |
