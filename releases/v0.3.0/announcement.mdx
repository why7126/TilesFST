# TILESFST v0.3.0

发布时间：2026-07-31 08:33:28

关联 Sprint：sprint-014

## 新增功能

- 发布流程新增镜像准备与镜像构建治理，发布对象可明确记录 image plan、manifest、输入 hash 和阻断门禁。
- 管理后台瓷砖类目名称支持中文、英文、数字和常见可见特殊字符，保留 15 个用户可见字符上限。
- 小程序品牌列表页保持顶部轮播不变，下半部按品牌单行展示 Logo、名称、商品数量和末级类目汇总。
- Web 管理端和展示端标准弹窗点击遮罩或外部空白区域不再自动关闭，降低编辑和确认操作误触风险。
- 小程序非首页页面新增统一返回首页悬浮按钮，覆盖搜索、分类、品牌、证书、收藏和商品详情等主要页面。

## 修复 BUG

- 管理端 SKU 列表默认排序按发布状态和业务时间保持稳定，已发布优先并按发布时间排序。
- 小程序搜索商品结果页与分类商品列表页默认排序与品牌详情页商品 Tab 保持一致。
- 小程序商品卡片图片加载优化为缩略图优先、非首屏按需加载，并提供缺图和对象不存在时的稳定占位。
- 小程序分类页二级类目卡片调整为两列展示，完整显示长名称。

## 发布注意事项

- 本版本发布范围来自已归档的 sprint-014，包含 5 个 REQ、4 个 BUG 和 9 个 OpenSpec Change。
- 发布准备已更新 `src/shared/product-version.ts` 的 `PRODUCT_VERSION` 为 v0.3.0。
- 本版本 `image_required=true`，发布前必须继续执行 `/image-prepare v0.3.0` 生成 `image-build-plan.json`，并执行 `/image-build v0.3.0` 生成 `image-manifest.json`。
- 当前公告不包含真实环境变量、数据库连接串、密钥、Authorization header、Cookie 或真实客户数据。

## 已知问题

- 小程序品牌列表、返回首页悬浮按钮、分类页二级类目展示、商品卡片图片加载的 DevTools 多尺寸、真机或体验版 Network evidence 仍按 sprint-014 验收报告记录为 follow_up，发布确认前需补录或继续标明不可用原因。
- BUG-0091 与 BUG-0092 的全量 `tests/test_miniapp_home.py` 回归中存在非本次修复范围的分类树测试数据冲突失败；相关变更聚焦用例已通过，发布确认前需确认风险接受结论或另行修复。
- 镜像准备和镜像构建证据尚未生成，缺失前不得执行 `/release-publish v0.3.0`。

## 升级步骤

1. 完成升级前数据库、对象存储引用和发布配置备份。
2. 执行 `/image-prepare v0.3.0`，确认 image plan 无阻断项。
3. 执行 `/image-build v0.3.0`，确认 manifest 与当前发布输入一致。
4. 部署 v0.3.0 镜像或部署包。
5. 完成管理端类目、SKU 列表、Web 弹窗、小程序品牌列表、商品排序、商品卡片图片、分类页和返回首页悬浮按钮 smoke。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 本版本计划阶段未声明数据库 schema 或 migration 变更；如发布准备后发现数据库变更，按对应数据库回滚说明处理。
4. 复核对象存储公开访问边界和媒体 URL 降级行为，确认回退后不暴露未授权资源。
