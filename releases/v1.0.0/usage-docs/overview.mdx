# v1.0.0 使用文档总览

本目录是 TILESFST v1.0.0 的公开产品使用手册快照，集中覆盖当前版本可用的管理端、小程序、公开浏览入口和常见问题。由于历史版本未生成 usage docs，本版本一次性补齐当前可公开的用户使用说明，后续版本只记录相对于本快照的增量或修订。

![管理端概览截图](/assets/screenshots/sha256-0df4d31166f358b3-admin-dashboard.png)

## 适用读者

| 读者 | 使用入口 | 主要任务 |
|---|---|---|
| 企业内部员工 | Web 管理端 | 维护品牌、证书、Banner、分类、规格、SKU、图片和状态。 |
| 系统管理员 | Web 管理端 | 管理用户、系统设置、日志审计和接口文档。 |
| 店主或导购 | 微信小程序 | 浏览首页、分类、品牌、商品、证书、收藏和搜索。 |
| 公开访问者 | Web 展示入口 / 小程序分享页 | 查看公开产品信息并进入移动端浏览链路。 |

## 本版本重点

- 品牌图片和图片类品牌证书支持真实缩略图生成、读取和安全回退。
- 管理端品牌和证书列表、卡片、上传回显可优先展示缩略图。
- 小程序品牌列表轮播图移除多余说明文案，并保留图片、切换、指示点和跳转能力。
- 媒体类验收要求覆盖对象 key、对象存在、URL、缩略图收益和端上渲染证据。
- 发布治理新增版本化 usage docs，当前目录即 v1.0.0 的使用文档快照。

## 使用边界

本手册只记录公开产品使用说明、功能入口、操作注意事项和版本差异。不得写入密钥、真实客户数据、内部数据库连接串、Authorization header、Cookie、对象存储凭据或生产私有运维地址。
