# 品牌、证书、Banner 与媒体

本页说明品牌、证书、Banner 和媒体上传的日常维护方式。v1.0.0 的重点是品牌图片和图片类证书支持真实缩略图。

![管理端媒体上传截图](/assets/screenshots/sha256-ac2a20b7e3fb1ef4-admin-brand-certificate.png)

## 品牌管理

1. 进入“品牌管理”。
2. 新增或编辑品牌名称、排序、状态和展示资料。
3. 上传品牌 Logo 或品牌图片。
4. 保存后在列表、卡片、小程序品牌页和相关商品中检查展示效果。

注意事项：

- 品牌名称应与对外物料保持一致。
- 停用品牌前确认相关商品、证书和 Banner 展示影响。
- 品牌图片上传后，列表优先展示缩略图；缩略图不可用时安全回退。

## 品牌证书

1. 进入“品牌证书”。
2. 新增证书，选择所属品牌。
3. 填写证书名称、编号、类型、发证机构、有效状态和备注。
4. 上传证书文件或证书图片。
5. 保存后在证书列表、详情和小程序证书页检查展示。

注意事项：

- 图片类证书会生成缩略图，用于列表、卡片和默认主图。
- 文件类证书应保证链接可打开或可复制。
- 证书状态和有效期应与实际证书保持一致。

## Banner 管理

![Banner 管理列表截图](/assets/screenshots/sha256-751ed81a06ab7388-admin-banner-list.png)

1. 进入“Banner 管理”。
2. 新增 Banner，上传图片并选择展示位置或跳转目标。
3. 设置排序、状态和展示时间。
4. 保存后在小程序首页轮播或指定运营位检查展示。

注意事项：

- Banner 图片需适合移动端展示。
- 跳转到商品、品牌或门店信息时，确认目标仍可访问。
- 下架 Banner 前确认首页运营位不会出现空白。

## 媒体五联验收

处理图片、证书、视频或缩略图问题时，按以下五项检查：

| 维度 | 检查点 |
|---|---|
| key | 对象 key 不应停留在临时 pending 路径，不应包含用户原始文件名。 |
| object | 对象存储中原图、缩略图或文件对象存在。 |
| URL | 后端受控媒体 URL 可访问，不暴露未授权对象存储。 |
| thumbnail benefit | 缩略图尺寸或体积明显低于原图，且不是原图字节复制。 |
| render | 管理端、小程序和公开浏览端渲染正常，无破图、遮挡或错位。 |

## 常见处理

- 上传失败：检查文件类型、大小和网络状态。
- 图片不显示：刷新列表后重试，确认媒体 URL 可访问。
- 缩略图异常：先确认原图可访问，再检查缩略图是否生成；必要时执行存量补齐流程。
- 证书无法打开：确认文件类型、文件 URL 和小程序预览能力。
