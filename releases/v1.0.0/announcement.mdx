# 产品版本 v1.0.0

发布时间：2026-08-06 08:26:43

关联 Sprint：sprint-020

## 新增与优化

- 管理端 SKU 列表和 Banner 列表优先展示缩略图，降低图片密集列表加载成本。
- 管理后台系统设置支持全局缩略图目标体积上限；默认不限制，启用后影响新生成缩略图。
- Mintlify 文档站完成信息架构、版本入口、任务入口与公开安全校验收口。

## 修复 BUG

- 小程序移除电话拨打、复制门店微信号和复制证书文件链接的残留隐私接口能力，支持提审时“未采集用户隐私”口径复核。

## 发布注意事项

- 产品版本号已更新为 v1.0.0。
- v1.0.0 产品使用文档已生成并投影到 Mintlify 文档站源目录。
- 镜像构建计划与镜像构建结果已完成校验；最终镜像校验以 `releases/v1.0.0/image-manifest.json` 和离线包 `.sha256` sidecar 为事实源。
- 后端与小程序发布范围 pytest 需在恢复 Pillow/PIL 测试依赖后复跑。

## 已知问题

- 部分归档 trace 状态字段与归档事实存在不一致，prepare 前建议执行 Workflow Sync 或归档一致性复核。
- 本地后端 pytest 环境缺少 PIL，相关测试尚未完成。

## 升级步骤

1. 确认 v1.0.0 release metadata、公告和 usage docs 校验结果。
2. 执行镜像准备与镜像构建。
3. 部署新版本并完成 smoke 与回归验证。

## 回滚说明

1. 回退到上一发布版本 v0.3.5 的部署包或镜像 tag。
2. 恢复上一版本环境变量、Compose 配置和 docs-site 运行方式。
3. 暂停历史缩略图重生成任务，并复跑核心路径 smoke。
