# TILESFST v0.3.2

发布时间：2026-08-01 09:51:07

关联 Sprint：sprint-016

## 新增功能

- 管理端 SKU 列表默认优先展示未上架 SKU，未上架组内按创建时间倒序展示。
- 已上架 SKU 组内按发布时间倒序展示，SKU 下架后仍保留最近一次发布时间用于运营复核。

## 修复 BUG

- 修复公开商品主图对象 key 长期停留在 pending 暂存路径的问题，绑定 SKU 后归入商品目录。
- 修复 `media_type=tile-sku` 缩略图与原图尺寸一致的问题，新生成缩略图会真实降尺寸并与原图保持同目录。

## 发布注意事项

- 本版本已执行发布准备校验，OpenSpec specs、目录结构、API 标准、OpenAPI / Orval、Docker Compose、Web Vitest 全量测试和 Mintlify broken-links 已通过。
- 镜像准备与镜像构建已完成，发布镜像 tag 为 `v0.3.2`，离线镜像包已生成。
- 后端发布相关 pytest 已使用后端 `.venv` 重跑通过，镜像 manifest 与离线镜像包 sha256 已校验。
- 发布后建议执行管理端 SKU 列表、公开 SKU 主图 URL、缩略图 URL、小程序商品卡片图片和对象存储对象存在性 smoke。

## 已知问题

- 目标环境的小程序真机图片渲染、历史 pending 主图迁移 apply 和历史同尺寸缩略图再生成 apply 需补录证据或明确风险接受。

## 升级步骤

1. 完成数据库、环境变量和对象存储配置备份。
2. 校验离线镜像包 sha256，并确保发布环境显式设置 `TILESFST_IMAGE_TAG=v0.3.2`。
3. 部署新版本。
4. 执行 smoke 与回归验证。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 按备份清单核对对象存储图片对象，必要时回退迁移或再生成结果。
