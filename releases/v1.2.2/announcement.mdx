# 产品版本 v1.2.2

发布时间：2026-08-30 14:58:17

关联 Sprint：sprint-028

## 新增与改进

- 小程序证书列表页现在会优先展示图片类证书的真实缩略图，只有非图片证书或缺失媒体时才显示占位。
- 发布状态检查增加更清晰的决策面板，用于区分用户决策缺口、准备证据缺口、发布证据缺口和生产专属待办。
- 发布与归档流程补齐环境分层证据门禁，开发验收、体验版证据和生产发布证据会分别记录。
- AI Usage 本地 session 自动发现口径已统一，常规 workflow 命令可优先尝试读取本地真实 session 事实。

## 修复 BUG

- 修复小程序证书列表页图片类证书 `file_url` 与 `thumbnail_url` 缺失导致全部显示占位的问题。

## 发布注意事项

- 本版本按项目单一发布流程确认，不区分 development / production 发布目标。
- 产品版本号已由 release-prepare 自动同步为 `v1.2.2`（2026-08-30 22:53:23）。
- 产品使用文档是否生成或更新尚未确认，发布准备阶段需要先做决策。
- 镜像计划和镜像构建证据尚未生成，后续需执行 `/image-prepare v1.2.2` 与 `/image-build v1.2.2`。

- 证书缩略图回填脚本的聚焦测试曾因本地缺少 PIL 未执行；发布准备阶段需复核该测试是否仍适用。
