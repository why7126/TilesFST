# 产品版本 v0.3.3

发布时间：2026-08-02 19:47:26

关联 Sprint：sprint-017

发布确认状态：published，发布门禁、产品使用文档和镜像构建证据已完成。

## 新增功能

- 建立版本化产品使用文档治理能力，发布准备阶段需先确认是否生成或更新当前版本 usage docs。
- 建立媒体五联验收模板与媒体类 BUG 四联验收模板，强化对象 key、对象存在、URL、缩略图收益和端上渲染证据。
- 增强 REQ/BUG 子文档状态同步与验收结果回填治理，减少归档前后的状态漂移。
- 为品牌图片和图片类品牌证书支持真实缩略图生成、优先读取、端上展示和存量补齐治理。

## 修复 BUG

- 修复小程序品牌列表页轮播图中多余的 `BRAND GALLERY` 与能力说明文案展示问题。

## 发布注意事项

- 产品版本常量已更新为 `v0.3.3`。
- 发布准备已通过后端/治理 pytest、Web Vitest、API 标准、OpenAPI / Orval、Docker Compose、Mintlify broken-links、usage docs validation 与 release publish validation 校验。
- 本版本已生成当前版本完整产品使用手册，覆盖管理端、小程序、公开/店主浏览和 FAQ，并使用真实系统/QA 截图证据。
- 本版本涉及后端、管理端、小程序、店主 Web、对象存储与镜像交付边界；镜像构建计划、镜像 manifest、离线包 sha256 均已生成并通过校验。

## 已知问题

- 生产部署 env 必须显式设置 `TILESFST_IMAGE_TAG=v0.3.3`；Compose fallback tag 仍为 `v0.0.4`。

## 升级步骤

1. 完成升级前备份。
2. 使用已生成并校验通过的 v0.3.3 镜像离线包或等价受控镜像源部署。
3. 部署前设置 `TILESFST_IMAGE_TAG=v0.3.3`，并复核对象存储、数据库、环境变量和当前镜像包备份。
4. 部署后执行管理端品牌/证书上传回显、缩略图 URL、小程序品牌列表轮播、店主 Web 图片展示和后端媒体读取 smoke。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 按对象存储备份与存量补齐记录核对图片对象回退范围。

## 影响范围

| 范围 | 影响 |
|---|---|
| Web 管理端 | 品牌与证书图片缩略图、上传回显和列表展示 |
| 店主 Web | 品牌与证书图片展示及降级 |
| 小程序 | 品牌列表轮播文案、品牌与证书图片展示 |
| 后端 | 媒体读取、缩略图生成与存量补齐治理 |
| 数据库 | 不涉及数据库表结构变更 |
| 对象存储 | 缩略图对象生成、读取、回退与补齐 |
| Docker | 需要镜像 plan 与 manifest |
