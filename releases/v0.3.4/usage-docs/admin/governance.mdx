# 账号、设置、日志与接口文档

本页说明管理员相关功能。普通员工可能看不到这些入口。

![账号资料页面截图](/assets/screenshots/sha256-fba24b100c99d8da-admin-user-list.png)

## 用户管理

1. 进入“用户管理”。
2. 新增账号，填写用户名、显示名、角色和状态。
3. 编辑账号资料或停用账号。
4. 需要时使用“重置密码”。

注意事项：

- 管理员账号拥有更高权限，应谨慎分配。
- 停用账号前确认该账号不再承担日常维护任务。
- 密码不应通过公开渠道传递。

## 个人资料与修改密码

1. 打开右上角用户菜单。
2. 进入个人资料查看账号信息。
3. 选择修改密码，按表单提示提交。
4. 修改后重新登录确认新密码可用。

## 系统设置

![管理端页面布局截图](/assets/screenshots/sha256-bff42343e0485214-admin-system-settings.png)

系统设置用于维护基础配置。变更前建议确认：

- 是否影响管理端展示。
- 是否影响小程序公开信息。
- 是否需要同步发布说明或培训口径。

## 日志审计

![管理端列表页面截图](/assets/screenshots/sha256-fba9da927946b3e3-admin-log-audit.png)

日志审计用于追踪后台操作和 API 调用。

1. 进入“日志审计”。
2. 使用操作人、时间、类型、状态或关键词筛选。
3. 查看请求摘要、路由模板、响应状态和错误信息。
4. 将异常记录用于排查或回归验证。

注意事项：

- 日志用于排查问题，不应对外公开内部细节。
- 导出或截图前先确认不包含敏感信息。

## API 文档

API 文档页面用于查看当前后端接口清单和前端 Orval 方法名。

适用场景：

- 产品或测试确认某个页面调用的接口。
- 开发联调时核对路径、方法和描述。
- 发布前确认 OpenAPI / Orval 已同步。

## 权限异常

- 如果普通员工访问管理员页面，会进入无权限提示。
- 如果登录状态过期，请重新登录。
- 如果连续出现权限异常，请联系管理员检查账号角色和状态。
