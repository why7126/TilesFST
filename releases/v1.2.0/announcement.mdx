# 产品版本 v1.2.0

发布时间：2026-08-28 16:50:24

关联 Sprint：sprint-026、sprint-025

## 新增功能

- 媒体图片多规格展示图能力，统一 thumbnail、display、original 三类展示与预览口径，并补充 WebP 派生图策略。
- 版本部署升级与回滚治理能力，覆盖首次部署、相邻升级、跨版本升级、env diff、数据库校验和回滚证据。
- 日志审计行为链路与任务链路采集模型，支持从用户行为、接口请求追踪到任务链路和流程节点。
- 通用产品数据采集与链路观测规范，以及 REQ、OpenSpec、Sprint 和实现级硬门禁。
- 小程序搜索体验统一，覆盖首页搜索入口、搜索结果、品牌、证书、收藏和商品列表相关路径。
- 小程序商品详情页底部操作栏紧凑化与证书详情页返回首页入口优化。

## 修复 BUG

- 修复管理后台头像上传路径重定向导致端口丢失和 CORS 拦截的问题。
- 修复当前登录用户头像引用缺失媒体对象时的展示一致性问题。
- 修复管理端头像 WebP 缩略图生成长尾性能问题。
- 修复小程序埋点请求放大与 usage-events 过量上报问题。
- 修复小程序多处媒体普通展示回退原图导致的冷加载问题。
- 修复管理端日志详情长链路字段布局重叠问题。
- 修复 Workflow Sync 与 AI usage 统计相关治理缺陷，提升迭代关闭和命令输出一致性。

## 发布注意事项

- 本版本需要生成产品使用文档；文档快照位于 `releases/v1.2.0/usage-docs/`，公开站点投影位于 `mintlify/docs/v1.2.0/` 和 `mintlify/docs/latest/`。
- `PRODUCT_VERSION` 已确认为 `v1.2.0`。
- 本版本需要镜像构建证据；发布前需执行 `/image-prepare v1.2.0` 和 `/image-build v1.2.0`。
- 数据库影响已记录 MySQL schema、迁移测试和回滚治理证据；生产发布前仍应按升级计划完成目标环境复核。
- 发布前需生成首次部署与相邻升级计划，并完成 smoke 与回归验证。

## 已知问题

- 当前尚未生成 `image-build-plan.json` 与 `image-manifest.json`，因此不能直接发布。
- 当前尚未生成 v1.2.0 的升级计划，发布确认前需补齐。

## 升级步骤

1. 执行 `/image-prepare v1.2.0` 生成并校验镜像构建计划。
2. 执行 `/image-build v1.2.0` 生成镜像 manifest、离线包和 sha256 sidecar。
3. 生成 `fresh -> v1.2.0` 与 `v1.1.2 -> v1.2.0` 的部署升级计划并完成校验。
4. 在目标环境完成数据库、对象存储、后端 API、Web 管理端和小程序核心路径 smoke。
5. 执行 `/release-publish v1.2.0` 记录发布确认结果。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 按升级计划中的数据库备份与回滚步骤处理数据变更。
4. 暂停或回退批量派生图维护任务，保留 dry-run、apply 与对象存储影响证据。
5. 回滚后重新执行后端、管理端和小程序核心路径 smoke。
