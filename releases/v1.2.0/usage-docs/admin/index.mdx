# 管理端使用说明

管理端用于企业内部员工维护瓷砖资料、品牌信息、证书、Banner、媒体素材和系统配置。普通员工可进入日常资料维护页面；管理员可额外访问用户管理、日志审计、接口文档和系统设置。

![管理端登录界面截图](/assets/screenshots/sha256-3f9a5408df8e587d-web-login.png)

## 登录与首页

1. 打开 Web 展示入口，点击“进入管理端登录”。
2. 输入账号和密码登录。
3. 登录后默认进入 `/admin/dashboard`，用于查看管理端概览。
4. 左侧导航可折叠；用户菜单可进入个人资料、修改密码或退出登录。

## 常用菜单

| 菜单 | 用途 | 角色 |
|---|---|---|
| Dashboard | 查看管理端概览。 | 员工、管理员 |
| 品牌管理 | 维护品牌名称、排序、状态、Logo 和品牌图片。 | 员工、管理员 |
| 品牌证书 | 维护证书名称、编号、类型、文件、图片和展示状态。 | 员工、管理员 |
| Banner 管理 | 维护小程序首页或运营位 Banner。 | 员工、管理员 |
| 类目管理 | 维护一级/二级瓷砖分类。 | 员工、管理员 |
| 规格管理 | 维护规格基础资料。 | 员工、管理员 |
| SKU 管理 | 维护商品资料、价格、状态、图片和视频。 | 员工、管理员 |
| 个人资料 | 查看或维护当前账号信息。 | 员工、管理员 |
| 用户管理 | 创建、编辑、停用账号和重置密码。 | 管理员 |
| 日志审计 | 查看后台操作与 API 调用记录。 | 管理员 |
| API 文档 | 查看接口清单和 Orval 方法名。 | 管理员 |
| 系统设置 | 维护基础配置。 | 管理员 |

## 列表通用操作

- 使用关键词、状态、分类、品牌或类型筛选列表。
- 使用分页查看更多数据。
- 点击“新增”创建记录。
- 点击“编辑”修改已有记录。
- 对启用/停用类操作，先确认影响再提交。
- 删除前确认记录未被业务数据引用；无法删除时按页面提示处理。

## 媒体上传通用规则

- 上传图片、Logo、证书图片或 SKU 图片时，等待上传完成后再保存表单。
- 上传成功后页面会展示可访问的媒体 URL 或缩略图回显。
- v1.2.0 起品牌图片和图片类证书支持真实缩略图，列表和卡片优先使用缩略图，失败时回退原图或占位图。
- 不要上传包含真实客户隐私、密钥、内部配置截图或不可公开运维信息的文件。

## 权限与安全

- 管理端仅面向企业内部员工。
- 店主端和公开浏览端只能查看已允许公开展示的数据。
- 管理员页面对普通员工不可见或不可访问。
- 修改账号、密码、系统设置或状态类数据前，请确认业务影响。
