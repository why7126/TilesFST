# 小程序浏览、搜索、商品与收藏

本页说明店主或导购如何在小程序中查找和查看商品。

![小程序分类页截图](/assets/screenshots/sha256-484cf6c2f6fc8ce5-miniapp-category.png)

## 首页浏览

首页提供门店名称、Banner、快捷入口、新品和热门推荐。

常用操作：

1. 点击 Banner 查看关联商品、品牌或门店信息。
2. 点击“选瓷砖”进入分类。
3. 点击“品牌”进入品牌列表。
4. 点击新品或热门商品卡片进入详情。
5. 点击搜索入口进入搜索页。

## 分类浏览

1. 点击底部“分类”。
2. 选择一级类目。
3. 查看二级类目或商品入口。
4. 点击类目进入商品列表。

注意事项：

- 类目由管理端维护，当前支持一级/二级结构。
- 长名称会在页面中尽量完整展示，但建议管理端保持名称简洁。

## 商品列表

![小程序商品卡片截图](/assets/screenshots/sha256-9180ce7351ecfa54-miniapp-product-card.png)

商品列表可来自分类、新品、热门、品牌或搜索结果。

可查看信息：

- 商品图片。
- 商品名称。
- 品牌。
- 分类或规格摘要。
- 价格或展示价格。

点击商品卡片进入详情。如果商品暂不可查看，小程序会提示“商品暂不可查看”或“商品打开失败，请重试”。

## 商品详情

![小程序商品列表真实截图](/assets/screenshots/sha256-9180ce7351ecfa54-miniapp-sku-detail.png)

详情页展示商品主图、多图、视频、参数、品牌、类目、规格、主色系、表面工艺和备注等信息。

常用操作：

1. 浏览图片和视频。
2. 查看基础参数。
3. 收藏或取消收藏。
4. 通过相关推荐进入其他商品。
5. 分享给微信好友或朋友圈。

## 搜索

1. 从首页或发现页进入搜索。
2. 输入关键词。
3. 查看匹配商品。
4. 点击商品进入详情。

建议使用商品名称、品牌、规格或类目相关关键词。

## 收藏

收藏用于本机快速保存感兴趣商品。

1. 在商品详情页点击收藏。
2. 进入底部“收藏”查看已收藏商品。
3. 再次点击收藏可取消。

注意事项：

- 收藏保存在当前设备本地。
- 更换设备或清理本地数据后，收藏可能不可见。
