# 产品版本 v1.1.2

发布时间：2026-08-21 15:04:07

关联 Sprint：sprint-024

## 新增功能

- 本版本不包含面向终端用户的新增功能。
- 治理侧完成跨项目质量经验应用、文档治理经验应用，以及评审命令默认确认体验优化。

## 修复 BUG

- 修复小程序首页无跳转轮播图显示内部标题的问题。无跳转 Banner 不再展示内部标识，点击保持静默，并保留首页首屏图片无遮挡、不透明化的展示效果。
- 修复小程序商品详情页轮播图清晰度不足且高度偏小的问题。详情页优先使用高清展示图，列表、卡片和推荐位继续保留缩略图策略。

## 发布注意事项

- 本版本已确认不生成或更新产品使用文档。
- BUG-0130 未改变公开 Banner API schema，不需要 Orval。
- 镜像构建计划、镜像 manifest 与离线包校验已完成；最终镜像校验信息以 `releases/v1.1.2/image-manifest.json` 和离线包 `.sha256` sidecar 为事实源。
- 发布确认时已确认部署环境显式使用 `TILESFST_IMAGE_TAG=v1.1.2`。
- 发布确认时已确认小程序首页 Banner 与 SKU 详情页的 DevTools、真机或体验版 render evidence 位置。

## 已知问题

- 暂无已知阻断发布的问题。

## 升级步骤

1. 确认当前发布环境使用 v1.1.2 版本号和镜像 tag。
2. 使用已校验的 v1.1.2 离线镜像包或等价镜像交付物部署新版本。
3. 完成小程序首页 Banner 与 SKU 详情页 smoke / render 回归。
4. 如发现阻断问题，按回滚说明恢复上一版本。

## 回滚说明

1. 回退到上一 Git tag 或上一部署包。
2. 恢复上一版本环境变量、Compose 配置和镜像 tag。
3. 如后续确认存在数据影响，按数据库备份或回滚说明处理。

## 影响范围

| 范围 | 影响 |
|---|---|
| Web 管理端 | 不涉及管理端用户功能 |
| 店主 Web | 不涉及店主 Web 展示端用户功能 |
| 小程序 | 首页无跳转 Banner 标题展示、无跳转点击静默行为、SKU 详情页高清轮播 URL 与轮播高度 |
| 后端 | 公开 Banner DTO 标题净化，未改变公开 API schema |
| 数据库 | 不涉及 |
| 对象存储 | 涉及图片对象展示 URL 与缩略图/原图使用语义，未新增对象存储能力或桶策略 |
| Docker | 镜像构建计划、manifest、离线包和 sha256 sidecar 已完成校验 |
