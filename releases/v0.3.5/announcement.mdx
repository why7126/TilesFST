# 产品版本 v0.3.5

发布时间：2026-08-04 23:17:43

关联 Sprint：sprint-019

## 新增功能

- 新增生产媒体维护作业入口，用于以受控 dry-run / apply 方式审计和修复历史媒体对象引用。
- 建立管理端列表字段展示 adapter 检查表，统一图片、名称与 fallback 展示口径。
- 将小程序 Network 面板验证纳入发布准备清单，提升体验版与正式版发布前的资源加载确认质量。
- 增强 OpenSpec 归档证据治理：归档 trace 缺失时提供最小 trace 或结构化 fallback 摘要。
- 优化大型 Sprint Fact Sheet 的 AI usage 摘要输出，默认保持 compact，完整矩阵按需读取。

## 修复 BUG

- 修复证书图片对象 key 未归入 `images/` 前缀的问题，并收敛图片与文件资源分流口径。
- 修复 usage docs 前置版本选择的 SemVer 排序问题，避免跨版本继承来源选错。
- 修复 Fact Sheet AI usage fresh gate 与已刷新 snapshot 状态不一致的问题。
- 修复小程序品牌列表页品牌类目两列对齐与长名称溢出风险。
- 修复小程序返回首页悬浮按钮第二次点击失效的回归问题。
- 修复生产历史媒体对象与缩略图规范漂移问题，覆盖 SKU、品牌 Logo 与证书图片资源。

## 发布注意事项

- 用户可见产品版本为 `v0.3.5`。
- 本版本包含生产媒体维护与对象存储治理变更，镜像构建计划和镜像构建证据已生成。
- 本版本已确认跳过产品使用文档生成。
- 离线镜像包校验以 `releases/v0.3.5/image-manifest.json` 与离线包 `.sha256` sidecar 为事实源。
- 发布前需完成核心 smoke、媒体对象 key / URL / render 验收和小程序 Network 面板验证。

## 已知问题

- Sprint 019 AI usage snapshot 曾使用 estimated fallback。若需要真实成本分析，应使用本地会话输入刷新 AI usage 证据后再作为分析依据。

## 升级步骤

1. 更新产品版本号或记录正式豁免原因。
2. 校验发布公告、usage docs 决策、镜像 manifest 和离线包 `.sha256` sidecar。
3. 部署新版本并完成后台、店主端、小程序和媒体资源 smoke。
4. 复核媒体对象 key、受控 URL、缩略图和页面渲染结果。

## 回滚说明

1. 回退到上一发布版本的部署包或镜像 tag。
2. 恢复上一版本环境变量和 Compose 配置。
3. 停止或回滚生产媒体维护作业，并按维护脚本 dry-run 结果与备份策略恢复受影响媒体引用。
4. 复跑媒体对象 key、URL、render 与小程序核心路径 smoke。
