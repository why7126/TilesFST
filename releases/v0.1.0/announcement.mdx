# TILESFST v0.1.0

发布时间：2026-07-26 18:05:00

关联 Sprint：sprint-011、sprint-012

> 当前状态：发布准备已执行。OpenSpec、后端 pytest、Web TypeScript 项目级类型检查、Web Vitest、Web build、OpenAPI / Orval、API 标准、Docker Compose、数据库 schema、产品版本和公告安全校验已完成；Web tsc blocker 已关闭，等待最终发布确认。

## 新增功能

- 小程序商品详情页视频支持更清晰的全屏播放入口，并接入微信原生媒体预览菜单。
- 管理端上传链路新增 Task Trace 与审计日志查看能力，可按 `task_trace_id` 串联长耗时任务节点。
- 管理端日志审计操作者筛选支持按用户名称或账号搜索选择。
- API 请求日志补齐统一 Request Snapshot，提升日志详情还原和错误排障能力。
- Web 管理端、店主 Web 和微信小程序请求身份标准化，区分可信 `request_id` 与客户端请求标识。
- Task Trace 支持主请求、子请求和 span 请求关联，并扩展到首批任务型接口。
- 审计操作日志补齐任务链路关联字段，日志审计升级为链路观测仪表。

## 修复 BUG

- 修复生产管理端视频上传 99% 后返回 504 的问题。
- 修复生产小程序 SKU 详情页视频播放启动慢的问题。
- 修复生产管理端创建品牌类型 Banner 保存接口返回 500 的问题。
- 修复小程序 SKU 详情页视频进入全屏后重新加载很久的问题。
- 修复管理后台 SKU 视频上传长时间停留 99% 且状态不可感知的问题。
