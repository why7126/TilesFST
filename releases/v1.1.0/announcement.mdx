# v1.1.0 发布公告

v1.1.0 已完成发布确认。本版本聚焦商品召回置顶、前台展示体验、媒体加载性能、真实用户性能观测和管理端效率优化。

## 主要更新

- 商品召回列表支持少量商品排序置顶，便于运营在小程序普通商品列表和搜索结果中突出重点商品。
- 小程序商品卡片新增“置顶”标识，帮助用户识别当前列表中实际生效的召回置顶商品。
- Banner 展示链路优化：支持隐藏标题，并移除小程序前台标题遮罩，提升图片展示效果。
- 新增 Web 与微信小程序真实用户页面加载耗时监控，管理端可查看性能聚合与样本数据。
- 小程序商品详情页、品牌链路媒体加载性能完成优化，缩短图片与媒体资源展示等待时间。
- 管理后台 Banner 列表显示内容优化，主题切换入口收敛，用户菜单身份展示去除伪邮箱。
- 管理后台日志审计加载性能优化，用户管理页支持维护联系邮箱和手机号码。

## 发布范围

本次发布覆盖后端 API、Web 管理端、微信小程序、数据库 schema、对象存储媒体访问策略、OpenAPI/Orval 客户端和生产镜像交付证据。

产品使用文档本次按发布确认保持跳过状态。最终镜像校验信息以 `releases/v1.1.0/image-manifest.json` 和离线镜像包同目录 `.sha256` sidecar 为准。

## 部署提醒

- 生产部署环境必须显式设置 `TILESFST_IMAGE_TAG=v1.1.0`。
- 目标 MySQL 已通过 schema drift 与轻量 smoke 校验，确认 `performance_events` 表和 `tiles` 召回置顶字段存在。
- 如上线 smoke 或核心链路验证失败，请按 `releases/v1.1.0/release.json` 中的 rollback 步骤回退到上一版本镜像或部署包，并复跑后端 API、Web 管理端、小程序媒体链路和登录权限 smoke。
