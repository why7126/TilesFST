# 根因分析

## 直接原因

管理后台证书列表的证书字段展示内容包含上传资源的图片名称、文件名称、对象 key 或原始 URL 等辅助信息，而该列表场景只应面向业务用户展示证书主图和证书名称。

## 根本原因

证书列表字段的展示边界未与上传/编辑场景区分清楚。上传或编辑组件需要展示文件就绪、文件名或资源标识以辅助操作确认，但列表浏览场景关注的是证书业务信息，复用或透出上传态信息会造成信息噪音。

## 触发条件

- 证书存在主图或上传资源字段。
- 管理后台进入证书列表并渲染证书字段。
- 列表字段读取并展示了图片文件名、证书文件名、对象 key 或原始 URL。

## 分类

- 类型：展示逻辑缺陷。
- 层级：管理后台 UI / 列表字段渲染。
- 关联：`BUG-0089-admin-certificate-edit-image-filename-noise`。

## 实现阶段确认结论

- 确认证书列表是否复用了上传组件、编辑弹窗展示逻辑或资源字段格式化函数。
- 确认证书名称、主图 URL、文件名和对象 key 的字段来源，避免修复时误隐藏证书名称或主图占位。
