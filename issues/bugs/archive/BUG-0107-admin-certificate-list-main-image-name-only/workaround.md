# 临时规避

## 结论

暂无面向业务用户的有效临时规避方案。

## 说明

该问题发生在管理后台证书列表字段渲染阶段，业务用户无法通过配置或操作隐藏额外的图片名称、文件名称、对象 key 或原始 URL。

在修复前，可通过以下方式降低影响：

- 管理员在证书列表中以证书名称和主图为准，忽略文件名或对象标识信息。
- 如需核对证书详情，进入编辑或详情入口确认业务字段，避免将文件名当作证书名称。

## 风险

临时忽略额外字段不能消除界面噪音，也不能避免上传实现细节继续暴露在列表中；仍需通过后续修复调整列表字段渲染。
