# 临时规避

在正式修复前，测试和体验人员可使用以下方式绕过返回首页按钮失效问题：

1. 使用微信小程序底部 Tab、系统返回或重新进入小程序的方式回到首页。
2. 若某页面返回首页按钮失效，先退出当前页面栈再重新进入对应页面验证。
3. 测试时记录失效页面、首次点击是否成功、第二次进入路径、是否快速重复点击，以及开发者工具控制台是否有导航错误。
4. 对核心演示流程，优先选择可通过底部 Tab 或首页入口返回的路径，避免把返回首页按钮作为唯一返回方式。

# 注意事项

- 不建议通过隐藏返回首页按钮规避问题；这会掩盖全局导航能力缺陷。
- 不建议仅延长节流时间或简单禁止快速点击；如果状态未释放，仍会在后续进入页面时失效。
- 不建议让各页面分别补丁式重置按钮状态；应优先收敛为一致的返回首页组件或导航工具方法。
- 若调整页面栈策略或首页跳转 API，需要覆盖所有带返回首页按钮的页面回归。
