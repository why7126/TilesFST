# 现象

微信小程序内各页面的返回首页按钮在首次点击后会失效。用户第一次点击可以完成返回首页，但再次进入同一页面或其他非首页页面后，继续点击返回首页按钮不再正常生效。

# 复现步骤

1. 打开微信小程序。
2. 进入任一非首页页面。
3. 点击返回首页按钮，确认第一次跳转首页是否成功。
4. 再次进入该页面或其他非首页页面。
5. 再次点击返回首页按钮。
6. 观察按钮是否仍能正常触发返回首页。

# 期望与实际

- 期望：每次进入任一非首页页面后，返回首页按钮都可重复点击，并稳定跳转回首页。
- 实际：返回首页按钮在每个页面点击一次后失效，后续点击不再生效或无法继续正常返回首页。

# 影响范围

- 微信小程序各非首页页面的返回首页入口。
- 小程序页面栈管理、导航 API 调用、按钮点击状态和事件绑定逻辑。
- 商品详情、品牌详情、证书详情、搜索结果等需要返回首页的浏览路径。

# 严重等级说明

严重等级为 `high`。该问题影响小程序内全局返回首页能力，用户在浏览详情页或列表结果后可能无法通过固定入口回到首页，阻断核心导航路径，并可能造成页面栈或交互状态异常。
