# 现象

小程序返回首页按钮在每个页面点击一次后就失效，后续无法继续正常返回首页。

# 复现步骤

1. 打开微信小程序。
2. 进入任一非首页页面。
3. 点击返回首页按钮，确认第一次跳转。
4. 再次进入该页面或其他页面。
5. 再次点击返回首页按钮，观察是否失效。

# 期望 vs 实际

- 期望：每次进入任一页面后，返回首页按钮都可重复点击并正常回到首页。
- 实际：每个页面点击一次后按钮失效，后续点击不再生效。

# 影响范围

- 微信小程序各页面返回首页按钮。
- 小程序页面栈、导航 API 调用、按钮状态和事件绑定。

# 初步线索

- 需要检查返回首页按钮是否在第一次点击后被禁用但未恢复。
- 需要确认是否因节流、防重复点击、页面实例状态或路由 API 选择导致后续点击无效。

# 建议验收或复现要点

- [ ] 每个页面返回首页按钮可重复生效。
- [ ] 从商品详情、品牌详情、证书详情、搜索结果等页面均可返回首页。
- [ ] 多次进入同一页面并点击返回首页，行为一致。
- [ ] 快速重复点击不造成页面栈异常或报错。
