# 现象

管理后台上传视频时，上传进度长时间停留在 99%，用户感知为上传即将完成但迟迟无法结束。

# 复现步骤

1. 进入管理后台的视频上传入口。
2. 选择视频文件并开始上传。
3. 观察上传进度条和状态文案。
4. 当进度显示 99% 后继续等待，记录停留时长以及最终是否成功、失败或一直无响应。

# 期望 vs 实际

- 期望：视频上传进度到达末尾后，应在合理时间内完成上传并展示成功结果；若服务端处理、对象存储写入或后处理耗时，应显示明确的处理中状态或可理解的等待提示。
- 实际：上传状态长时间停留在 99%，缺少明确完成、失败或处理中反馈，影响管理员判断是否需要重试。

# 影响范围

- 管理后台视频上传流程
- 视频素材维护与商品视频资料更新
- 媒体上传链路，包括前端上传进度、后端上传完成响应、对象存储写入或上传后处理状态反馈

# 初步线索

- 用户截图显示文件上传状态为“上传中 99%”，进度条接近完成但未闭环。
- 可能与前端进度事件只覆盖请求体上传、服务端保存或对象存储写入仍在进行有关。
- 也可能与上传完成后的媒体元数据写入、超时、响应返回或错误处理没有及时反馈有关。
- 与 `BUG-0081-prod-cos-video-upload-fails` 同属视频上传链路问题，后续排查可确认是否存在共同根因或配置回归。

# 建议验收或复现要点

- 记录文件名、大小、格式、时长、网络环境、浏览器和管理后台环境。
- 上传同一视频，统计从 99% 到成功或失败的耗时。
- 验证上传请求是否已完成、响应状态码与响应体是否返回明确结果。
- 验证对象存储是否成功写入对象，以及数据库媒体记录是否创建。
- 验证长耗时阶段是否有“处理中”状态、超时提示和可恢复重试路径。
