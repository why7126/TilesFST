# 小程序返回首页按钮第二次点击失效回归

## 原始反馈

微信小程序的返回首页按钮，目前每个页面点击一次后，再一次点击就失效了。

## 类型判断

- 类型：BUG
- 理由：返回首页按钮是已存在的小程序导航能力，第二次点击失效属于既有交互行为偏差；历史同类 BUG-0109 已归档为完成，本次反馈按回归或仍可复现问题独立记录。

## 背景

用户在微信小程序多个页面使用返回首页按钮时，首次点击可触发返回首页；同一页面再次点击该按钮时交互失效。该问题会影响用户从深层页面快速回到首页的稳定性。

## 影响范围

- 端：微信小程序
- 页面：所有带返回首页按钮的页面
- 区域：返回首页按钮 / 页面导航交互
- 影响：用户首次使用后，再次尝试从当前页面返回首页失败，可能需要依赖系统返回、重新进入小程序或切换页面绕行。

## 建议复现要点

1. 打开微信小程序，进入任意带返回首页按钮的页面。
2. 点击返回首页按钮，确认首次点击是否能正常返回首页。
3. 再次进入同一页面或另一个带返回首页按钮的页面。
4. 再次点击返回首页按钮，观察是否不再触发跳转或无任何反馈。
5. 分别在多个页面重复以上步骤，确认是否为每个页面点击一次后再次失效。

## 建议验收要点

1. 所有带返回首页按钮的小程序页面，每次点击都能稳定返回首页。
2. 同一页面连续多次进入并点击返回首页按钮，行为一致且不失效。
3. 不同页面之间切换后，返回首页按钮不受历史点击状态影响。
4. 若当前已在首页，按钮状态或点击行为有明确、无异常的处理。
5. 修复后覆盖历史 BUG-0109 的回归场景。
