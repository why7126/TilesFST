# 临时规避

正式修复前，测试人员和体验人员可通过以下方式绕过：

1. 若返回首页按钮第二次点击失效，使用底部 TabBar 的首页入口返回首页。
2. 若当前页面没有可用 TabBar，可使用系统返回、重新进入小程序或从首页重新进入目标页面。
3. 复现时记录页面名称、首次点击是否成功、第二次进入路径、第二次点击是否有反馈，以及是否发生在 TabBar 页面或非 TabBar 页面。
4. 测试回归时优先覆盖分类页、品牌列表页、搜索结果页、商品详情页和品牌详情页，区分同页重复进入与跨页重复进入。

# 注意事项

- 不建议隐藏返回首页按钮规避问题；这会削弱已交付的全局导航能力。
- 不建议只延长防重复点击锁时间；如果锁释放时机不稳定，延长时间可能让失效更明显。
- 不建议各页面分别维护返回首页状态；应优先统一组件或导航工具的状态恢复策略。
- 修复前若需要演示核心流程，应避免把返回首页悬浮按钮作为唯一返回路径。
