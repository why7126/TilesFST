# Workaround

## 临时规避方案

在正式修复前，可通过运营和素材侧降低用户等待感：

1. 优先上传体积更小的 MP4 视频，控制时长、分辨率和码率。
2. 为商品视频配置稳定封面图，避免播放前空白或黑屏。
3. 对重点展示 SKU 使用压缩后的视频素材，避免直接上传高码率原片。
4. 在生产验收时记录首播耗时，优先替换首播明显过慢的视频。

## 不建议的规避方式

- 不建议让小程序绕过后端鉴权和媒体适配层直接上传对象存储。
- 不建议临时放开对象存储桶匿名公开读写权限。
- 不建议仅通过增大 Nginx 超时时间解决首播慢问题；超时配置只能避免中断，不能改善视频起播效率。

## 正式修复方向

- 后端媒体读取接口支持视频 Range/206 分段响应，或对播放场景返回受控签名播放 URL/CDN URL。
- SKU 视频媒体补齐封面图兜底。
- 后续增强可考虑转码、压缩、多清晰度和 CDN 缓存策略。
