# Acceptance

## AC-001 视频 Range 响应

给定生产或等价测试环境存在一个 SKU 视频对象，  
当客户端对 `/media/{object_key}` 发起 `Range: bytes=0-1023` 请求，  
则接口应返回 `206 Partial Content`，并包含 `Accept-Ranges: bytes` 与合法 `Content-Range`。

## AC-002 小程序首播体验

给定小程序生产环境打开包含视频的商品详情页，  
当用户点击视频播放，  
则在目标网络条件下应较快出现首帧或播放反馈，不应长时间黑屏或无响应。

验收时必须记录：

- SKU ID
- 视频文件大小、格式、编码、时长
- 机型与网络类型
- 点击播放到首帧耗时

## AC-003 视频封面兜底

给定 SKU 详情接口返回视频媒体项，  
当视频处于未播放或加载中状态，  
则小程序应展示可用封面图或明确兜底图，避免空白展示。

## AC-004 非回归

修复后应保持：

- 商品详情页图片轮播、图片预览、视频播放控件可用。
- `/api/v1/miniapp/skus/{sku_id}` 响应结构兼容现有小程序调用。
- 媒体读取仍遵守后端受控访问与对象存储安全边界。

## AC-005 测试覆盖

修复实现时应补充或更新：

- 后端媒体读取 Range/206 测试。
- 小程序商品详情页视频封面或播放 URL 静态测试。
- 如 API 响应新增字段，应同步 OpenAPI / Orval / 文档与相关契约测试。
