# 根因分析

## 直接原因

管理后台 SKU 列表的表头单元格缺少稳定的单行显示约束，较长字段在常用桌面宽度或列宽收缩时会按默认文本换行规则折行。

## 根本原因

SKU 列表列数较多，表头文本、列宽、横向滚动容器之间缺少明确的展示契约：表头需要保持单行可扫描，但现有样式没有把 `white-space`、最小列宽和横向滚动作为同一组约束处理，导致布局压缩时优先牺牲表头可读性。

## 触发条件

- 进入管理后台 SKU 列表页面。
- 页面处于常用桌面宽度或表格可用宽度不足。
- 表头字段文本较长，且对应列未设置足够的最小宽度或单行样式。

## 分类

- 类型：UI / Design
- 影响端：管理后台 Web
- 影响组件：SKU 列表表格表头与横向滚动布局

## 修复关注点

- 表头字段应保持单行显示。
- 表头与正文列宽必须保持一致。
- 列数较多时应优先使用既有横向滚动或合理最小列宽，而不是压缩正文内容。
- 修复不得影响排序、筛选、分页和操作列交互。
