# 临时规避

## 当前可用规避方式

在正式修复前，管理后台用户可通过以下方式降低影响：

1. 使用较宽的桌面浏览器窗口查看 SKU 列表。
2. 如页面已有横向滚动区域，优先横向滚动查看完整列。
3. 根据业务需要暂时减少筛选后的结果范围，降低连续扫描大量行时的阅读成本。

## 限制

上述方式只能缓解阅读体验问题，不能保证所有表头字段在常用宽度下稳定单行展示，也不能替代正式修复。

## 正式修复建议

在 SKU 列表表格层统一约束表头单行显示、最小列宽和横向滚动策略，确保表头与正文列保持对齐。
