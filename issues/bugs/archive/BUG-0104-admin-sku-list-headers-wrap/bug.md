# 管理后台 SKU 列表表头字段换行

## 现象

管理后台 SKU 列表中，部分表头字段发生换行显示，导致列表表头不够整齐，影响字段扫描、列对齐判断和日常维护效率。

## 复现步骤

1. 登录管理后台。
2. 进入 SKU 列表页面。
3. 查看列表所有表头字段。
4. 调整到常用桌面宽度，观察表头是否出现换行。

## 期望结果

所有表头字段在桌面管理端常用宽度下均保持单行显示，表头与内容列保持对齐；当列数较多时，应通过既有横向滚动或布局策略完整查看。

## 实际结果

部分表头字段换行显示，破坏表格扫描体验，并可能让用户误判表头与正文列的对应关系。

## 影响范围

- 管理后台 SKU 列表页面。
- 表格表头样式、列宽约束、横向滚动容器和响应式布局。
- 不应影响排序、筛选、分页和操作列。

## 严重等级说明

严重等级为 `low`。该问题主要影响管理后台列表可读性和操作体验，不阻断 SKU 数据查看、筛选、分页或维护流程；修复时需避免为了强制单行而压缩正文列，造成内容重叠或操作列不可用。
