# 管理后台证书编辑弹窗文件就绪文案冗余且图片信息无法正常显示

## 现象

管理后台证书编辑弹窗中，PDF/兼容文件区域显示不需要的 `证书文件已就绪` 文案；同时图片信息全部不能正常显示。

## 复现步骤

1. 登录管理后台。
2. 进入证书列表。
3. 打开任一已有证书的编辑弹窗。
4. 查看 PDF/兼容文件区域和图片信息区域。

## 期望结果

- PDF/兼容文件区域不显示 `证书文件已就绪` 这类冗余文案。
- 编辑已有证书时，图片信息应正常显示已有图片、主图状态和必要操作。
- 图片预览、替换、删除及保存后再次打开编辑弹窗的回显应保持一致。
- 不应显示对象 key、原始文件名或无意义文件名噪音。

## 实际结果

- PDF/兼容文件区域显示冗余的 `证书文件已就绪` 文案。
- 图片信息无法正常显示，影响已有图片、主图状态和图片相关操作的确认。

## 影响范围

- 管理后台证书编辑弹窗。
- 证书文件预览与状态提示。
- 证书图片列表、主图、图片信息展示与编辑。

## 严重等级说明

严重等级评估为 `medium`。该问题影响管理后台已有证书的编辑确认体验，可能导致运营人员无法判断证书图片现状或误读文件状态，但当前线索未表明会阻断证书列表访问、造成数据丢失或影响店主端公开展示。
