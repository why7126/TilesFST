# 临时规避

正式修复前，管理后台使用和测试可采用以下方式降低误判风险：

1. 不以编辑弹窗内的 `证书文件已就绪` 文案作为文件状态判断依据，优先通过保存前后的证书详情、列表展示或对象预览入口确认文件是否存在。
2. 对需要调整图片的证书，记录当前证书 ID、已有图片数量、主图预期和操作路径，避免仅依赖弹窗内图片信息判断。
3. 若图片信息完全不显示，暂停批量编辑该证书图片，避免误删、误替换或错误设置主图。
4. 测试时保留复现证书、图片数量、是否有主图、是否存在 PDF/兼容文件、浏览器控制台错误和网络响应字段，供修复阶段定位。

# 注意事项

- 不建议通过隐藏整个 PDF/兼容文件区域规避问题；这可能掩盖文件缺失或格式不兼容的必要提示。
- 不建议用对象 key、原始文件名或内部存储路径替代运营可读信息；这会延续 `BUG-0089` 同类噪音问题。
- 不建议只修正文案而忽略图片回显；本 BUG 需要同时覆盖文件提示和图片信息展示。
- 若确认后端响应缺少必要图片字段，应通过后续 OpenSpec Change 评估接口契约，而不是让前端猜测图片状态。
