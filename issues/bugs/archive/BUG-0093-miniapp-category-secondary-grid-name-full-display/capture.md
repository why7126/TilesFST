# 现象

微信小程序分类列表页中，二级类目卡片当前一行显示 3 个，卡片宽度不足，导致部分二级类目名称没有完整显示出来，会以省略号截断。

# 复现步骤

1. 打开微信小程序。
2. 进入底部导航“分类”页。
3. 在左侧一级类目中选择包含较长二级类目名称的类目，例如“木纹砖产品”。
4. 观察右侧二级类目卡片列表的列数和类目名称显示效果。

# 期望 vs 实际

- 期望：二级类目卡片调整为一行显示 2 个，并且所有二级类目名称都能完整显示，不出现省略号截断。
- 实际：二级类目卡片当前一行显示 3 个，较长名称在卡片内被截断为省略号，用户无法直接识别完整类目名称。

# 影响范围

- 微信小程序分类页。
- 分类页右侧二级类目卡片布局。
- 关联“查看全部商品”和点击二级类目进入商品列表的入口可读性。

# 初步线索

- 用户截图显示“木纹砖产品”下的二级类目卡片为 3 列布局。
- 卡片内名称如 `600X1200 仿古精雕...`、`800X800 仿古精雕...`、`750X1500 仿古精雕...` 被截断。
- 历史缺陷 `BUG-0077-miniapp-category-secondary-name-truncated` 已归档，但当前截图显示问题在二级类目卡片区域仍存在，需按本次明确验收调整为 2 列并保证完整显示。

# 建议验收或复现要点

- [ ] 分类页右侧二级类目卡片每行显示 2 个。
- [ ] 所有二级类目名称完整展示，不出现 `...` 或其他省略截断。
- [ ] 长名称可换行展示，且不遮挡卡片边框、相邻卡片、标题或“查看全部商品”入口。
- [ ] 覆盖 4 字以内、5-8 字、超过 8 字、含数字规格和中文组合的二级类目名称。
- [ ] 点击任意二级类目仍能进入对应分类商品列表，入口行为不受布局调整影响。
- [ ] 微信开发者工具、iOS 真机、Android 真机和窄屏设备展示一致可用。
