# 管理后台瓷砖类目名称不支持中文括号

## 现象

管理后台瓷砖类目名称支持输入英文括号，但不支持中文括号 `（`、`）`。当类目名称包含中文括号时，新增或编辑保存流程无法正常完成，表现为前端校验拦截、后端校验失败或保存失败。

## 复现步骤

1. 登录管理后台。
2. 进入瓷砖类目管理。
3. 新建或编辑类目名称。
4. 输入包含中文括号的名称，例如 `墙砖（哑光）`。
5. 点击保存，观察校验提示与保存结果。

## 期望结果

类目名称允许输入并保存中文括号 `（`、`）`，并与英文括号支持逻辑保持一致。保存后，类目树、列表和详情中应正常展示包含中文括号的名称，不出现乱码、截断或格式异常。

## 实际结果

包含中文括号的类目名称无法通过校验或无法正常保存，而包含英文括号的类目名称可以正常使用。

## 影响范围

- 管理后台瓷砖类目新增表单。
- 管理后台瓷砖类目编辑表单。
- 类目名称前端校验、后端 Pydantic Schema 校验或数据库约束。
- 类目树、列表和详情中的名称展示。

## 严重等级说明

严重等级为 `medium`。该问题不会阻断全部类目维护能力，但会影响中文业务命名的完整表达，导致带中文括号的常见类目名称无法录入或维护。修复时应仅补齐中文括号支持，不应放宽空名称、超长名称、重复名称或其他非法字符校验。
