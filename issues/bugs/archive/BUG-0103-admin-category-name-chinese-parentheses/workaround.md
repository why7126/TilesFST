# 临时规避

在正式修复前，可采用以下方式降低业务影响：

1. 类目名称中暂时使用英文括号 `(`、`)` 替代中文括号 `（`、`）`，例如使用 `墙砖(哑光)`。
2. 若必须保持中文排版，可先去掉括号并使用空格或短横线表达补充信息，例如 `墙砖 哑光`。
3. 对已经需要上线展示的类目，先使用当前可保存的名称完成维护，待修复后再统一改回中文括号。

# 注意事项

- 不建议直接关闭类目名称校验；修复应只补齐中文括号支持。
- 不建议临时扩大为任意字符输入，否则可能引入脚本字符、控制字符或展示异常。
- 不建议绕过管理后台直接写库；类目名称仍应经过统一校验与重复名检查。
