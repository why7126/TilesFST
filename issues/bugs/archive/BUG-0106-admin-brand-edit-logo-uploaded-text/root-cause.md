# 根因分析

## 直接原因

管理后台品牌编辑弹窗的 Logo 上传区域在已有 Logo 的状态下展示了成功态文案 `已上传Logo`。该文案与图片预览、上传或替换控件表达的信息重复，导致界面出现不必要的提示文本。

## 根本原因

品牌编辑表单中的 Logo 上传组件可能复用了通用上传成功态文案，未针对“编辑已有图片并展示预览”的场景收敛展示规则。当前 UI 对“已存在图片”和“上传成功提示”的边界不够清晰，使辅助状态文案进入了稳定展示态。

## 触发条件

1. 管理后台品牌数据已有 Logo。
2. 打开品牌编辑弹窗。
3. Logo 上传区域渲染已有图片状态。
4. 上传组件或表单字段同时渲染 `已上传Logo` 成功态文案。

## 分类

- 类型：`design`
- 影响层：管理后台 Web UI
- 影响模块：品牌编辑弹窗、Logo 上传/预览区域
- 初步判断：不涉及 API、数据库或对象存储结构变更。

## 待验证点

- 确认该文案来自品牌编辑表单自身，还是来自通用上传组件。
- 确认移除该成功态文案后，上传中、上传失败、格式不支持等状态提示仍可见。
- 确认 Logo 图片预览、替换、删除或重新上传操作不受影响。
