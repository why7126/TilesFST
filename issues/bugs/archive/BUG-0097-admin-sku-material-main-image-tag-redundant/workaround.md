# Workaround

## 临时规避

暂无需要业务侧执行的临时规避措施。该问题只影响管理后台 SKU 列表的信息密度，不阻断 SKU 新增、编辑、图片维护、视频维护、上下架或删除操作。

## 使用建议

在修复前，SKU 维护人员可继续以「图片数量 / 视频数量」作为判断依据；「主图已设」标签可视为当前列表的冗余状态提示，不代表额外的操作要求。

## 风险说明

不建议通过临时隐藏整列来规避该问题，因为这会影响图片、视频完整度的日常维护判断。
