# 现象

管理后台瓷砖 SKU 页列表的「素材」列中，在 SKU 有图片时显示「主图已设」标签。由于当前业务规则下只要有图片就会有主图，该标签属于冗余展示。

# 复现步骤

1. 登录管理后台。
2. 打开「瓷砖 SKU」页面。
3. 查看任意已有图片的 SKU 行。
4. 观察「素材」列中是否显示「主图已设」标签。

# 期望 vs 实际

- 期望：素材列不显示「主图已设」标签，仅保留图片/视频数量等真正需要判断素材完整度的信息。
- 实际：素材列显示「主图已设」标签，占用视觉空间并重复表达已有图片状态。

# 影响范围

- 管理后台瓷砖 SKU 列表素材列展示。
- SKU 维护人员快速扫描图片与视频素材完整度的体验。
- 可能涉及素材列展示组件中的标签渲染逻辑，以及素材完整度条件筛选入口。

# 初步线索

- 截图显示有图片的 SKU 行在素材列展示「主图已设」标签，下方同时展示「1 图 / 0 视频」。
- 业务规则为“只要有图，就会有主图”，因此无需单独显示主图状态。
- 需确认缺图、无主图异常数据或历史脏数据是否仍需其他告警机制；若没有，则列表中可直接移除该标签。

# 建议验收或复现要点

- [ ] 有图片的 SKU 行素材列不再显示「主图已设」标签。
- [ ] 素材列仍正确显示图片数量与视频数量。
- [ ] 缺图或素材不完整状态仍能通过图片/视频数量识别，页面不再提供素材完整度条件筛选。
- [ ] 移除标签后列表行高、列宽和操作区不出现布局抖动或遮挡。
- [ ] 不影响 SKU 新增、编辑、图片主图兜底、上下架、删除等操作。
