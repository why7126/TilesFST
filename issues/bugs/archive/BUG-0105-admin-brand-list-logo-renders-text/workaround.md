# 临时规避方案

## 1. 产品内规避

暂无产品内配置项可将品牌列表第一列从文字展示切换为 Logo 图片展示。

该问题属于管理后台品牌列表展示层异常，刷新页面、切换账号或重新上传同一 Logo 通常不能从根本上规避。

## 2. 运营规避

在正式修复前，运营和管理人员可按以下方式处理：

1. 继续通过品牌编辑页或详情入口核对品牌 Logo。
2. 在列表页不要仅依赖第一列 Logo 字段判断 Logo 是否上传成功。
3. 如需验收 Logo 展示效果，将列表第一列文字展示标记为本 BUG 的未通过项。

## 3. 技术规避

如需临时验证，可在修复分支中仅调整品牌列表 Logo 列渲染方式，将有效图片地址渲染为缩略图，并为缺失或加载失败状态提供占位。

不建议通过隐藏 Logo 列规避，因为这会削弱品牌列表的视觉识别能力，也无法验证已上传 Logo 的展示链路。

## 4. 风险说明

| 风险 | 说明 |
|---|---|
| 业务阻断 | 中低；不阻断品牌数据维护，但影响列表识别和核对 |
| 视觉体验 | 存在影响；Logo 字段没有按图片展示 |
| 修复误伤 | 需避免影响品牌搜索、编辑、上下架等列表操作 |
| API / DB | 当前阶段不预设必须修改；修复时需确认字段映射是否一致 |

## 5. 规避有效期

本规避仅适用于 `BUG-0105-admin-brand-list-logo-renders-text` 修复发布前。修复发布并验收通过后，应以正式修复结果为准。
