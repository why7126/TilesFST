# 临时规避方案

## 可用规避

在正式修复前，门店或运营人员可引导用户点击商品详情页轮播图进入图片预览，以查看 `preview_url` 对应的原图或高清预览图。该路径通常比首屏轮播展示更清晰。

## 限制

- 该规避依赖用户主动点击图片，不改善首屏轮播的第一眼展示质量。
- 不能解决轮播高度固定 `680rpx` 带来的展示比例问题。
- 对需要快速浏览多个 SKU 的用户不够友好。
- 若某 SKU 原始图片自身质量不足，点击预览也无法完全解决清晰度问题。

## 不建议的规避

- 不建议全局禁用 `.thumb`，否则商品列表、卡片、推荐位和 Banner 可能出现加载性能回退。
- 不建议让前端直连对象存储原始地址；媒体访问仍必须走后端受控 `/media/...` 或等价安全 URL。
- 不建议通过上传超大原图规避模糊问题，这会放大流量和首屏加载风险。

## 推荐正式修复方向

优先将商品详情页首屏展示图与列表缩略图语义分开：

- 商品详情页首屏使用原图或详情级展示图。
- 点击预览继续使用原图或高清 URL。
- 列表、卡片、推荐位和 Banner 继续使用 `.thumb`。
- 轮播高度改为基于视口的合理比例，并保证商品名称或关键商品信息仍在首屏可见。
