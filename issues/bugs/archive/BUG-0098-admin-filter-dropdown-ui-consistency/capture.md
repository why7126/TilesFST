# 现象

管理端多个页面的筛选条件下拉框位置、展开交互和 UI 样式不统一，需要统一为与瓷砖类目页一致的下拉交互和样式。

# 复现步骤

1. 登录管理端。
2. 分别打开瓷砖品牌页、瓷砖类目页、瓷砖规格页、品牌证书页、Banner 管理页、用户管理页、系统设置页、日志审计页、接口文档页、界面主题等页面。
3. 对比各页面筛选区域中的下拉框位置、触发方式、弹层宽度、选项样式、悬停/选中态、空态和重置后的表现。
4. 观察除瓷砖类目页外的筛选下拉是否存在位置或视觉样式不一致。

# 期望 vs 实际

- 期望：管理端所有筛选条件下拉框均复用或遵循瓷砖类目页一致的下拉交互、位置策略和视觉样式，筛选区在不同页面保持统一体验。
- 实际：多个管理端页面的筛选下拉框位置和 UI 样式不一致，影响后台操作一致性和页面专业度。

# 影响范围

- 管理端筛选体验一致性。
- 瓷砖品牌页、瓷砖类目页、瓷砖规格页、品牌证书页、Banner 管理页、用户管理页、系统设置页、日志审计页、接口文档页、界面主题等页面。
- 可能涉及管理端筛选栏组件、Select/Dropdown 封装、页面级筛选布局和 Design System token 使用。

# 初步线索

- 瓷砖类目页可作为下拉交互和样式基准。
- 需确认是否已有可复用的管理端筛选控件或页面模板，避免页面级重复样式。
- 若涉及接口文档页或界面主题页的非业务筛选，也应按同一筛选控件规范处理。

# 建议验收或复现要点

- [ ] 上述管理端页面的筛选下拉框触发位置、弹层对齐、宽度策略和层级表现与瓷砖类目页一致。
- [ ] 下拉选项、悬停态、选中态、禁用态、空态、加载态和重置后的表现一致。
- [ ] 筛选框高度、边框、背景、文字颜色、间距和图标样式遵守管理端 Design System semantic token。
- [ ] 下拉层不遮挡关键操作，不被表格、弹窗或页面容器裁切。
- [ ] 键盘、鼠标和移动窄屏下的基础交互不回退。
- [ ] 不改变现有筛选参数语义、接口请求和查询结果。
