# 现象

管理端多个页面已经提供筛选条件下拉框，但不同页面之间的下拉框位置、展开交互和 UI 样式不一致。用户期望所有筛选下拉统一为与瓷砖类目页一致的交互和视觉表现。

涉及页面包括但不限于：

- 瓷砖品牌页
- 瓷砖类目页
- 瓷砖规格页
- 品牌证书页
- Banner 管理页
- 用户管理页
- 系统设置页
- 日志审计页
- 接口文档页
- 界面主题页

# 复现步骤

1. 登录管理端。
2. 打开瓷砖类目页，记录筛选下拉框的位置、触发方式、弹层对齐、选项样式和状态反馈。
3. 分别打开瓷砖品牌页、瓷砖规格页、品牌证书页、Banner 管理页、用户管理页、系统设置页、日志审计页、接口文档页、界面主题页。
4. 在各页面操作筛选条件下拉框，对比其位置、宽度、边框、背景、文字、图标、悬停态、选中态、空态、加载态和重置后的表现。
5. 观察是否存在与瓷砖类目页不一致的页面级实现。

# 期望结果

管理端所有筛选条件下拉框应统一为与瓷砖类目页一致的下拉交互和样式：

- 筛选下拉框在筛选区中的位置、尺寸和对齐策略一致。
- 下拉弹层的宽度、层级、边界对齐和打开方向一致。
- 选项、悬停态、选中态、禁用态、空态、加载态和重置后的表现一致。
- 样式遵循管理端 Design System semantic token，不引入页面级裸样式差异。
- 下拉层不被表格、页面容器、弹窗或滚动区域裁切。
- 不改变现有筛选字段、查询参数、接口请求和筛选结果语义。

# 实际结果

多个管理端页面的筛选下拉框位置、展开行为或视觉样式与瓷砖类目页不一致，导致后台筛选体验不统一，也降低页面整体专业度。

# 影响范围

- 影响管理端 Web 的筛选体验一致性。
- 影响瓷砖品牌、瓷砖类目、瓷砖规格、品牌证书、Banner、用户、系统设置、日志审计、接口文档、界面主题等页面的日常筛选操作。
- 后续修复可能涉及管理端筛选栏组件、Select/Dropdown 封装、页面级筛选布局和 Design System token 使用。

# 严重等级说明

严重等级为 `medium`。

该问题不阻断核心业务数据维护，也暂未显示会造成数据错误；但它横跨多个管理端页面，影响高频后台筛选操作的一致性、可预期性和视觉质量，属于需要纳入统一修复的中等优先级体验缺陷。
