# Workaround

## 临时规避

暂无可靠的产品内临时规避方案。该问题属于管理端跨页面 UI 一致性缺陷，不能通过用户配置或运行时开关修复。

## 使用建议

在修复前，管理端使用者可继续按各页面现有筛选入口完成查询；若需要判断某个页面下拉交互是否符合预期，可暂以瓷砖类目页作为人工对照基准。

## 风险说明

不建议通过隐藏筛选条件、移除页面筛选能力或单独调整某一个页面的局部样式来临时规避。这样可能造成筛选能力退化，或继续扩大页面之间的交互差异。

## 后续处理建议

进入修复阶段后，应一次性梳理受影响页面，并通过统一组件、统一样式或统一页面模板解决，而不是逐页临时补丁式修正。
