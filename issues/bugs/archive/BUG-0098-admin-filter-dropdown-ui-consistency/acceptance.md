# Acceptance

## 回归验收

### AC-001 筛选下拉统一采用类目页基准

Given 管理员登录管理端  
When 分别打开瓷砖品牌页、瓷砖类目页、瓷砖规格页、品牌证书页、Banner 管理页、用户管理页、系统设置页、日志审计页、接口文档页、界面主题页  
Then 各页面筛选条件下拉框的位置、尺寸、触发方式和视觉样式与瓷砖类目页保持一致。

### AC-002 下拉弹层对齐与层级一致

Given 管理员在任意受影响页面打开筛选下拉框  
When 下拉弹层展开  
Then 弹层宽度、边界对齐、打开方向、层级和阴影表现与瓷砖类目页一致  
And 下拉弹层不被表格、页面容器、滚动区域或弹窗裁切。

### AC-003 下拉选项状态一致

Given 筛选下拉框包含可选项、当前选中项、禁用项、空态或加载态  
When 管理员查看或操作下拉选项  
Then 选项文本、间距、图标、悬停态、选中态、禁用态、空态和加载态与瓷砖类目页保持一致。

### AC-004 筛选重置表现一致

Given 管理员已在任意受影响页面选择筛选条件  
When 点击重置或清空筛选  
Then 下拉框恢复默认展示  
And 重置后的视觉状态、占位文案和筛选结果刷新行为与瓷砖类目页一致。

### AC-005 筛选语义和接口请求不变

Given 管理员在任意受影响页面使用筛选下拉框  
When 选择、切换或清空筛选条件  
Then 保持原有筛选字段、查询参数、接口请求和查询结果语义不变  
And 不新增、不删除、不改名现有 API 字段。

### AC-006 Design System 约束通过

Given 修复完成后的管理端筛选下拉框  
When 复核样式实现  
Then 使用管理端 Design System semantic token  
And 不新增页面级裸 Hex 颜色或与统一控件冲突的局部样式。

### AC-007 基础可用性不回退

Given 管理员使用鼠标、键盘或窄屏窗口操作筛选下拉框  
When 打开、选择、关闭、重置筛选条件  
Then 不出现文本溢出、按钮遮挡、焦点丢失、不可点击或布局抖动问题。
