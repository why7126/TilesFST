# 现象

小程序品牌列表页的轮播图区域展示了固定英文文案 `BRAND GALLERY`，并可能展示中文说明文案 `轮播图保持现有品牌页能力`。这些文案不属于当前品牌列表页期望展示内容，会让轮播图区域出现额外文字干扰。

# 复现步骤

1. 打开微信小程序。
2. 进入品牌列表页。
3. 查看页面顶部或品牌列表页轮播图区域。
4. 观察轮播图区域是否显示 `BRAND GALLERY` 或 `轮播图保持现有品牌页能力` 文案。

# 期望结果

- 品牌列表页轮播图不显示 `BRAND GALLERY` 文案。
- 品牌列表页轮播图不显示 `轮播图保持现有品牌页能力` 文案。
- 轮播图保留现有品牌页能力，包括图片加载、图片展示、轮播切换以及既有点击或跳转行为。
- 删除文案后轮播图布局保持稳定，不出现空白占位、错位、遮挡或高度异常。

# 实际结果

品牌列表页轮播图区域仍显示 `BRAND GALLERY` 或 `轮播图保持现有品牌页能力` 等多余说明文案，影响页面展示简洁性和品牌列表页视觉一致性。

# 影响范围

- 微信小程序品牌列表页。
- 品牌列表页轮播图视觉展示。
- 依赖品牌页轮播图的既有图片展示、切换、跳转或交互能力需要回归确认。

# 严重等级说明

严重等级为 `low`。该问题属于小程序品牌列表页的展示文案偏差，不阻断用户浏览品牌列表，也不影响数据写入、接口调用或核心业务流程；但会影响页面视觉质量和已交付品牌列表页体验，需要在后续修复中移除上述多余文案并回归轮播图现有能力。
