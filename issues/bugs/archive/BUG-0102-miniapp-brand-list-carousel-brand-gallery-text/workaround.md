# 临时规避方案

## 1. 产品内规避

暂无产品内配置项可关闭 `BRAND GALLERY` 或 `轮播图保持现有品牌页能力` 文案。

该问题属于小程序品牌列表页展示层文案残留，用户侧无法通过刷新、切换账号或调整品牌数据规避。

## 2. 运营规避

在正式修复前，运营和验收人员可按以下方式处理：

1. 继续使用品牌列表页浏览品牌内容，该问题不阻断品牌列表访问。
2. 验收时将轮播图多余文案标记为本 BUG 的未通过项。
3. 不通过修改品牌名称、品牌图片或 Banner 数据来规避该问题，避免引入额外数据噪音。

## 3. 技术规避

如需临时发布体验版，可在修复分支中仅移除轮播图可见说明文案，并保持轮播图数据来源和交互逻辑不变。

不建议通过隐藏整个轮播图区域规避，因为这会破坏“轮播图保持现有品牌页能力”的验收边界。

## 4. 风险说明

| 风险 | 说明 |
|---|---|
| 业务阻断 | 低；不阻断品牌列表浏览 |
| 视觉体验 | 存在影响；轮播图区域显示了不应出现的说明文案 |
| 修复误伤 | 需重点避免删除轮播图图片、切换、点击或跳转能力 |
| API / DB | 不涉及 |

## 5. 规避有效期

本规避仅适用于 `BUG-0102-miniapp-brand-list-carousel-brand-gallery-text` 修复发布前。修复发布并验收通过后，应以正式修复结果为准。
