# 现象

管理后台瓷砖 SKU 页的「类目」筛选下拉仅展示一级类目，例如高光产品、金丝绒产品、木纹砖产品等，无法选择二级或更深层级类目进行筛选。

# 复现步骤

1. 登录管理后台。
2. 打开「瓷砖 SKU」页面。
3. 点击筛选区的「类目」下拉框。
4. 观察下拉选项是否包含二级、三级等各层级类目。

# 期望 vs 实际

- 期望：类目筛选支持选择各层级类目，至少能覆盖当前类目树中可用于 SKU 归属的所有层级。
- 实际：下拉框只展示一级类目，无法按二级或更深层级类目筛选 SKU。

# 影响范围

- 管理后台瓷砖 SKU 列表筛选效率。
- SKU 维护人员按细分品类查找、批量检查商品资料和素材完整度的工作流。
- 可能涉及前端类目选项构造逻辑、后端类目列表接口入参或 SKU 查询筛选参数。

# 初步线索

- 截图显示类目下拉列表仅包含一级类目，未呈现层级缩进或级联选择。
- 需确认 SKU 归属类目字段是否支持任意层级类目 ID。
- 需确认筛选语义：选择父类目时是否包含子孙类目 SKU，选择子类目时是否只筛选该子树或精确类目。

# 建议验收或复现要点

- [ ] 类目筛选下拉或级联控件可选择当前类目树中的二级及更深层级类目。
- [ ] 层级展示清晰，不会把同名不同层级类目混淆。
- [ ] 选择父类目与子类目的筛选结果符合明确规则，并覆盖分页、关键词、品牌、状态、素材完整度组合筛选。
- [ ] 重置筛选后回到「全部类目」并恢复完整 SKU 列表。
- [ ] 不影响 SKU 新增、编辑、上下架、删除等操作。
