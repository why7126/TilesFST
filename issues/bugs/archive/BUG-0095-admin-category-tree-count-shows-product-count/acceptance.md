# 验收标准

## AC-001 一级类目显示直接子类目数量

- GIVEN 管理端类目树存在一级类目
- WHEN 用户查看一级类目右侧数字
- THEN 该数字应等于该一级类目的直接子类目数量
- AND 不应显示该一级类目下的商品数量

## AC-002 叶子类目显示 0

- GIVEN 某个类目没有下一层级子类目
- WHEN 用户查看该类目右侧数字
- THEN 应显示 `0`
- AND 即使该类目下存在商品，也不应在该位置显示商品数量

## AC-003 多层级类目口径一致

- GIVEN 类目树包含一级、二级、三级或更多层级
- WHEN 用户展开任意非叶子节点
- THEN 节点右侧数字应始终表示直接下一层级类目数量
- AND 不应累计孙级类目数量或商品数量

## AC-004 全部类目入口口径明确

- GIVEN 用户查看“全部类目”入口
- WHEN 该入口右侧显示数字
- THEN 数字应显示顶层类目数量
- AND 不应误显示商品总数

## AC-005 商品数量与类目数量不混淆

- GIVEN 页面仍需要展示商品数量
- WHEN 商品数量与类目数量同时存在
- THEN 商品数量应使用独立字段、位置或标签展示
- AND 类目树节点右侧默认计数不得被商品数量占用

## AC-006 全部类目入口计数列对齐

- GIVEN 用户查看左侧类目树
- WHEN “全部类目”入口与一级类目节点同时展示
- THEN “全部类目”右侧数字应与一级类目右侧数字保持同列视觉对齐
- AND “全部类目”文字应与类目树标题文字保持左对齐
- AND “全部类目”被选中时，选中态边框应完整包住文字和右侧数字

## AC-007 回归测试覆盖

- SHOULD 补充或更新管理端类目树组件测试，覆盖节点右侧数字来自直接子类目数量。
- SHOULD 补充或更新后端接口测试，确认类目树响应持续提供直接子类目数量字段。
- SHOULD 补充或更新管理端页面测试，覆盖“全部类目”、有子类目节点、叶子节点三类展示。
