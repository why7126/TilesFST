# 验收标准

## AC-001 体验版图片慢加载可复现并可量化

- GIVEN 微信小程序体验版连接生产 API
- WHEN 测试人员打开首页并记录网络面板
- THEN 应能统计首屏 `/media/` 图片请求数量、单张资源大小、P50/P95 耗时、失败状态和 HTTP 状态码
- AND 复现记录应能判断慢加载主要发生在小程序排队、后端 `/media` 代理、对象存储读取、网络链路或对象缺失

## AC-002 公开 SKU 主图引用完整

- GIVEN 生产或体验版数据中存在公开 SKU
- WHEN 校验 `tile_images.object_key` 主图引用
- THEN 所有公开 SKU 的主图对象均应能在对象存储中找到
- AND 不应存在 404、迁移残留 key、空主图引用导致的卡片长期空白或失败兜底

## AC-003 商品卡片使用轻量图片资源

- GIVEN 后端返回首页和商品列表卡片数据
- WHEN 小程序渲染商品卡片
- THEN 卡片图片应优先使用列表缩略图或等价轻量 URL
- AND 详情页仍能展示原图或高质量详情图
- AND 响应不得暴露 raw object key、本机路径、bucket 内部信息、Authorization header、Cookie 或敏感配置

## AC-004 小程序列表按需加载图片

- GIVEN 首页或商品列表页包含多张商品卡片
- WHEN 用户进入页面且未滚动到后续卡片
- THEN 非可见区域或低优先级卡片图片不应一次性抢占首屏图片下载
- AND 滚动到对应区域后图片能正常加载并保持兜底图逻辑

## AC-005 媒体读取具备缓存和排障能力

- GIVEN 小程序请求 `/media/{object_key}` 图片资源
- WHEN 后端返回图片响应
- THEN 图片响应应具备必要的缓存相关头或等价缓存策略
- AND 后端或边缘日志应能在不记录敏感 raw object key 的前提下观测媒体读取耗时、状态码和失败率

## AC-006 回归范围覆盖

- SHOULD 覆盖微信小程序首页、新品推荐、热销推荐、全部产品、商品列表、品牌商品列表、搜索结果和详情页图片展示。
- SHOULD 覆盖图片成功加载、图片缺失、对象存储异常、网络慢响应和兜底图展示。
- SHOULD 补充或更新小程序静态测试、后端媒体读取测试、对象引用一致性校验或等价验收脚本。
