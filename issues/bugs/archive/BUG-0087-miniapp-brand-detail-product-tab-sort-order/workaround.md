# Workaround - BUG-0087 品牌详情页商品 Tab 排序未按发布时间升序和 ID 升序

## 临时规避方案

暂无可在不改代码、不发版的情况下彻底规避该问题的方案。

在修复前，可通过以下方式降低验收或运营误判：

1. 若需要核对某品牌全部商品，可暂时以管理端 SKU 列表或接口导出结果作为排序核对依据。
2. 若需要向用户展示重点商品，可优先通过首页 Banner、新品榜、热销榜或其他已有运营入口承接，避免依赖品牌详情页商品 Tab 的顺序表达运营意图。
3. 验收时记录当前排序缺陷，避免将品牌详情页商品 Tab 的展示顺序作为已符合发布时间升序的依据。

## 运维 / 客服说明

如用户反馈品牌主页商品顺序不符合预期，可说明：

1. 当前问题为品牌详情页商品 Tab 排序规则未按预期固化。
2. 商品本身仍可正常浏览和进入详情页。
3. 后续修复会将品牌详情页商品 Tab 调整为发布时间升序、ID 升序的稳定顺序。

## 不建议的规避

- 不建议通过反复编辑 SKU 更新时间来模拟发布时间排序；这会污染真实更新时间。
- 不建议调整品牌、分类或上下架状态来影响排序；这会改变商品公开范围。
- 不建议在小程序前端对分页结果临时重排；跨页排序应由后端统一保证，否则可能产生分页顺序漂移。

## 风险

临时不处理不会造成数据损坏、权限绕过或服务不可用，但会持续影响品牌详情页商品陈列顺序的可预期性。
