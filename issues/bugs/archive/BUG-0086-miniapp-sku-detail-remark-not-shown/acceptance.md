# Acceptance

## AC-001 非空备注说明可见

给定某个商品/SKU 已维护非空备注说明信息，  
当用户打开微信小程序商品详情页，  
则页面应展示该备注说明内容，且内容与数据源或接口返回值一致。

## AC-002 接口与端侧字段映射一致

给定商品/SKU 详情接口返回备注说明字段，  
当小程序详情页加载该商品/SKU，  
则端侧数据适配层应正确读取该字段，并绑定到页面展示模型中。

验收记录应包含：

- 商品/SKU ID
- 接口响应中的备注说明字段名和值
- 小程序页面展示截图或真机录屏
- 微信开发者工具或真机环境信息

## AC-003 空备注说明不破坏布局

给定某个商品/SKU 未维护备注说明信息，  
当用户打开微信小程序商品详情页，  
则页面应按既有空态策略隐藏备注说明区或显示合理占位，不应出现异常空白、布局错位、报错 Toast 或控制台异常。

## AC-004 页面主要信息不回归

修复备注说明展示后，商品详情页以下既有能力不得回归：

- 商品主图、轮播图和视频展示正常。
- 商品名称、品牌、类目、规格、颜色、尺寸等既有详情信息展示正常。
- 收藏、分享、品牌跳转等详情页操作保持可用。
- 页面加载失败、无数据和接口异常时仍按既有规则展示错误或空态。

## AC-005 测试与证据

修复实现时应补充或更新：

- 小程序详情页字段映射或页面渲染相关静态测试。
- 至少一条包含备注说明的商品/SKU 回归样例。
- 微信开发者工具预览证据；如涉及平台差异，应补充真机预览证据。
- 如修改详情接口字段，应同步 API / OpenAPI / Orval / docs / 后端契约测试。
