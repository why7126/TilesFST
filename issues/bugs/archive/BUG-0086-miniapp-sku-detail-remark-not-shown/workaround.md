# Workaround

## 临时规避

在正式修复前，可采用以下临时规避方式降低影响：

1. 将关键备注信息临时写入当前小程序详情页已经展示的商品描述、规格说明或其他可见字段中。
2. 运营验收时优先选择包含备注说明的商品/SKU 作为回归样例，明确记录“小程序详情页备注说明暂未展示”为已知问题。
3. 如客户必须查看备注说明，可由店主或运营通过管理端、内部资料或其他已展示字段补充说明。

## 不建议的规避

- 不建议为了展示备注说明而在小程序端硬编码字段内容。
- 不建议让小程序直连数据库、对象存储或未授权接口读取补充信息。
- 不建议把备注说明复制到多个长期字段中形成数据冗余；临时复制只应作为短期运营规避。

## 永久修复方向

永久修复应在后续 OpenSpec fix Change 中确认：

- 商品/SKU 详情接口、端侧适配和页面模板对备注说明字段的统一字段名与空态规则。
- 详情页在备注说明非空时稳定展示，在为空时不产生异常空白或布局错位。
- 覆盖接口响应、页面渲染和真机预览的回归验收。
