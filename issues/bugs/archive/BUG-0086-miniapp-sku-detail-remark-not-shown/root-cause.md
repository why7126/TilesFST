# Root Cause

## 直接原因

小程序商品详情页未把商品/SKU 的备注说明信息展示到详情页内容区。现阶段根据用户现象和 capture 线索判断，缺陷可能发生在以下链路之一：

1. 后端详情接口未返回备注说明字段。
2. 小程序详情页数据适配层未从接口响应中读取备注说明字段。
3. 小程序页面模板或渲染逻辑缺少备注说明展示区域。
4. 接口字段名与小程序端字段名不一致，导致已返回的数据没有被绑定到页面。

由于 `/bug-complete` 阶段禁止修改或深入实现源码，本缺陷的具体代码根因需在后续 `/bug-opsx` 与修复实现阶段通过接口响应和页面字段映射验证确认。

## 根本原因

商品详情页信息展示验收未显式覆盖“备注说明字段”的端到端展示链路，导致备注说明即使在数据源中存在，也可能在接口响应、端侧适配或模板渲染任一环节被遗漏，而现有验收未及时发现该缺口。

## 触发条件

- 商品/SKU 数据中存在非空备注说明信息。
- 用户进入微信小程序商品详情页。
- 详情页当前接口响应、字段映射或页面模板未正确承接备注说明字段。

## 分类

- 类型：code / miniapp-data-binding / acceptance-gap
- 影响层：微信小程序商品详情页、商品/SKU 详情数据展示链路
- 关联能力：`REQ-0044-miniapp-sku-detail-page`
- 严重等级：medium

## 待验证项

- 后端商品/SKU 详情接口响应中是否包含备注说明字段及字段值。
- 小程序详情页数据模型是否声明或映射该字段。
- 页面模板是否存在备注说明展示节点，并在非空时渲染。
- 备注说明为空时是否符合既有空态展示策略。
