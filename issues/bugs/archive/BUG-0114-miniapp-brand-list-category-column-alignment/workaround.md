# Workaround

## 临时规避

暂无可靠的用户侧或运营侧临时规避方案。

该问题发生在小程序品牌列表页前端布局层，用户无法通过操作规避。运营侧即使缩短类目名称，也只能降低暴露概率，不能保证右侧列稳定左对齐，也不应要求业务数据为布局缺陷让步。

## 发布前处理建议

如需在修复前继续验证页面，可通过截图对比确认当前缺陷范围：

1. 选择包含多个类目的品牌。
2. 使用短类目与长类目混合数据。
3. 在常见小程序视口宽度下观察右侧列起点和长文本边界。

## 风险说明

不建议通过隐藏类目、限制展示数量或修改后端返回数据作为临时规避。品牌列表页的既有能力要求按品牌展示全部类目汇总，隐藏或裁剪数据会改变用户可见信息范围。
