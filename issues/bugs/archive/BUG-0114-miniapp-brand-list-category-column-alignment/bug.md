# 小程序品牌列表页品牌类目两列未分别左对齐

## 现象

微信小程序品牌列表页的“品牌矩阵”中，品牌卡片下方类目胶囊以两列视觉形态展示，但右侧列没有形成稳定统一的左对齐边界。不同类目文字长度下，右侧胶囊起始位置会随前序胶囊宽度发生偏移，整体扫描感不一致。

当类目文字较长时，还需要避免文本撑破胶囊边框或挤压两列布局。

## 复现步骤

1. 打开微信小程序。
2. 进入底部 Tab 的“品牌”页面。
3. 查看“品牌矩阵”中包含多个类目胶囊的品牌卡片。
4. 观察品牌卡片下方类目胶囊是否呈两列展示。
5. 对比右侧列各行胶囊的起始位置是否保持一致。
6. 使用较长类目名称的品牌数据，观察文本是否超出胶囊边框或造成横向溢出。

## 实际结果

- 类目胶囊以流式换行排布，右侧列起点会受左侧胶囊内容宽度影响。
- 右侧列没有稳定纵向对齐线。
- 长类目名存在撑开胶囊、影响两列稳定性的风险。

## 期望结果

- 品牌类目区保持两列展示。
- 左侧列内所有胶囊保持左对齐。
- 右侧列内所有胶囊保持左对齐，且右侧列有稳定统一的起始边界。
- 每个类目胶囊文本单行展示。
- 文本超出胶囊可用宽度时使用省略号，不换行、不撑破边框、不横向溢出。
- 点击被省略的类目胶囊时，仍使用完整类目名称与类目 ID 跳转商品列表。

## 影响范围

- 端：微信小程序
- 页面：`pages/brand-list/index`
- 模块：品牌列表页 / 品牌矩阵 / 品牌卡片类目胶囊区
- 关联能力：品牌列表页按品牌展示类目汇总
- 不涉及：后端接口、数据库结构、Orval、管理端、Web 展示端

## 严重等级说明

严重等级：medium。

该问题不阻断用户进入品牌主页或点击类目跳转商品列表，但会影响品牌列表页核心信息的视觉一致性和可读性。品牌矩阵是小程序品牌入口页的主要浏览区域，两列错位和长文本溢出风险会降低用户快速扫描类目的效率，因此按中等严重等级处理。

## 修复方向建议

优先采用“两列固定布局 + 单行省略号”：

- 类目容器使用固定两列布局，保证左右列各自拥有稳定起点。
- 胶囊宽度受所在列约束，不随文本无限撑开。
- 胶囊文本使用单行省略号显示。
- 保持现有点击事件、埋点字段和跳转参数不变。
