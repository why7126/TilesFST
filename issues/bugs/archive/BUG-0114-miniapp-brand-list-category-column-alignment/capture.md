# 小程序品牌列表页品牌类目两列未分别左对齐

## 原始反馈

小程序，品牌列表页中，品牌下方的类目分为两列，但是右侧列没有进行对齐，需要保持左侧列左对齐，右侧列左对齐。

## 类型判断

- 类型：BUG
- 理由：品牌列表页品牌下方类目摘要已存在两列展示能力，当前问题是右侧列起始位置随内容或布局偏移，未满足两列各自左对齐的展示预期。

## 背景

用户在微信小程序品牌列表页查看品牌矩阵时，品牌卡片下方展示多个类目标签。截图中类目被分成左右两列，但右侧列的起始边界没有形成稳定纵向对齐线，导致列表扫描感较差。

## 影响范围

- 端：微信小程序
- 页面：品牌列表页 / 品牌矩阵
- 区域：品牌卡片下方类目标签两列布局
- 影响：品牌类目信息阅读节奏不统一，视觉上显得右侧列错位。

## 建议复现要点

1. 打开微信小程序品牌列表页。
2. 查看包含多条类目标签的品牌卡片。
3. 观察品牌名称下方类目标签是否按两列展示。
4. 对比左侧列与右侧列各自的起始边界，确认右侧列是否存在未左对齐或随标签宽度偏移的问题。

## 建议验收要点

1. 品牌卡片下方类目仍按两列展示。
2. 左侧列内所有标签保持左对齐。
3. 右侧列内所有标签保持左对齐，且右侧列有稳定统一的起始边界。
4. 不同品牌、不同类目名称长度下，两列布局不发生文本重叠、截断异常或横向溢出。
5. 小程序常见机型宽度下展示一致。
