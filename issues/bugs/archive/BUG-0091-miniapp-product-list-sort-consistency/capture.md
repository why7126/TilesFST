# 现象

小程序搜索商品结果页、分类商品列表页的商品排序方式需要与品牌详情页商品列表一致；首页“全部产品”列表本次不调整。

# 复现步骤

1. 准备多条公开 SKU，确保发布时间或品牌详情页现行排序字段存在差异。
2. 在小程序品牌详情页查看商品列表排序。
3. 在小程序搜索商品结果页输入可命中同类商品的关键词。
4. 在小程序分类商品列表页进入同一或相近商品集合。
5. 对比三个列表的排序规则。

# 期望 vs 实际

- 期望：搜索商品结果页、分类商品列表页与品牌详情页使用一致的排序方式。
- 实际：搜索商品结果页、分类商品列表页排序方式与品牌详情页不一致或待确认，导致用户在不同入口看到的商品顺序不稳定。

# 影响范围

- 微信小程序搜索商品结果页。
- 微信小程序分类商品列表页。
- 小程序商品列表接口及相关查询参数。
- 明确不影响：首页“全部产品”列表。

# 初步线索

- 已有关联缺陷 `BUG-0087-miniapp-brand-detail-product-tab-sort-order` 曾修正品牌详情页商品排序规则。
- 后续实现需复用品牌详情页现行排序策略，避免为搜索页和分类页手写另一套排序。
- 需确认搜索结果页是否存在相关性排序；若有，需要产品评审明确是否被品牌详情页排序规则覆盖。

# 建议验收或复现要点

- [ ] 搜索商品结果页排序方式与品牌详情页一致。
- [ ] 分类商品列表页排序方式与品牌详情页一致。
- [ ] 首页“全部产品”列表排序保持不变。
- [ ] 分页加载更多后仍保持稳定排序，不出现重复、漏项或顺序跳动。
- [ ] 搜索关键词、类目筛选、品牌筛选组合时排序规则仍一致。
