# BUG-0091 小程序搜索商品结果页与分类商品列表页排序需与品牌详情页一致

## 现象

小程序品牌详情页商品列表已形成现行排序方式，但搜索商品结果页、分类商品列表页的商品顺序与品牌详情页不一致或仍待确认一致性。用户从不同入口查看相同或相近商品集合时，可能看到不稳定的排序结果。

本次缺陷范围明确不包含首页“全部产品”列表，首页列表排序保持现状。

## 复现步骤

1. 准备多条公开 SKU，确保这些 SKU 在发布时间、品牌详情页现行排序字段或其他排序依据上存在差异。
2. 在微信小程序进入品牌详情页，查看商品列表排序。
3. 在微信小程序搜索商品结果页输入可命中同类商品的关键词，查看搜索结果排序。
4. 在微信小程序分类商品列表页进入同一或相近商品集合，查看分类列表排序。
5. 对比品牌详情页、搜索商品结果页、分类商品列表页的排序规则与分页加载后的顺序稳定性。

## 期望结果

- 搜索商品结果页与品牌详情页使用一致的商品排序方式。
- 分类商品列表页与品牌详情页使用一致的商品排序方式。
- 分页加载更多后排序稳定，不出现重复、漏项或顺序跳动。
- 首页“全部产品”列表排序保持不变。

## 实际结果

- 搜索商品结果页、分类商品列表页的排序方式与品牌详情页不一致或缺少明确一致性保障。
- 用户在不同入口查看商品时，可能感知到商品展示顺序不稳定。

## 影响范围

- 微信小程序搜索商品结果页。
- 微信小程序分类商品列表页。
- 小程序商品列表接口及搜索、类目、品牌等相关查询参数。
- 与 `BUG-0087-miniapp-brand-detail-product-tab-sort-order` 修正后的品牌详情页排序策略存在一致性关联。

## 严重等级说明

严重等级为 `medium`。该问题不阻断用户浏览商品，也不涉及数据丢失、权限绕过或支付交易风险；但会造成同一商品集合在不同入口的展示顺序不一致，影响用户查找体验、运营展示稳定性和后续商品列表公共组件复用的一致性验收。

## 备注

- 后续修复应优先复用品牌详情页现行排序策略，避免为搜索页和分类页手写另一套排序逻辑。
- 若搜索结果页存在相关性排序策略，需要在 `/bug-complete` 或评审阶段明确该策略是否被品牌详情页排序规则覆盖。
