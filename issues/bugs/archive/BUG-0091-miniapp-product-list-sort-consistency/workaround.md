# 临时规避

正式修复前，可通过运营和验收约束降低排序不一致带来的体验影响：

1. 体验版验收时优先以品牌详情页商品列表作为排序基准。
2. 对搜索商品结果页和分类商品列表页，记录与品牌详情页不同序的 SKU 样本、入口、筛选条件和分页页码。
3. 避免在运营说明中承诺搜索页或分类页的展示顺序具备明确业务含义，直到排序契约完成修复与验收。
4. 若必须演示固定商品顺序，优先从品牌详情页入口进入，避免混用搜索和分类入口对比展示。

# 注意事项

- 不建议通过手动调整 SKU 创建时间、发布时间或排序字段来规避该问题；这会影响其他入口和历史数据解释。
- 不建议在小程序搜索页或分类页单独硬编码排序规则；后续应复用品牌详情页现行排序策略或统一后端查询排序。
- 首页“全部产品”列表明确不在本 BUG 范围内，临时规避和验收均不应要求首页列表排序同步变化。
