# BUG Review

## 评审结论

确认修复，状态通过为 `approved`。

小程序搜索商品结果页、分类商品列表页与品牌详情页商品排序不一致，属于已交付商品列表能力的跨入口一致性缺陷。该问题不阻断浏览和交易链路，但会影响用户查找体验、运营展示稳定性和商品列表公共组件复用验收，因此严重等级 `medium` 合理。

## 评审清单

- [x] 可复现或根因充分：已提供品牌详情页、搜索结果页、分类商品列表页三入口对比复现路径；根因分析明确为跨入口排序契约缺失。
- [x] 严重等级合理：`medium`，不涉及数据丢失、权限绕过或系统不可用，但影响用户体验和展示一致性。
- [x] 回归验收明确：已覆盖搜索结果页、分类商品列表页、品牌详情页基准、分页稳定性、首页“全部产品”不变和搜索相关性优先级确认。
- [x] 是否需 hotfix 路径：无需 hotfix；可进入常规 BUG 修复流程。

## 范围确认

- 修复范围：微信小程序搜索商品结果页、分类商品列表页、商品列表接口或查询排序契约。
- 不纳入范围：首页“全部产品”列表排序。
- 后续实现需复用品牌详情页现行排序策略，避免搜索页和分类页各自维护独立排序逻辑。
- 若搜索结果页存在相关性排序，需要在 OpenSpec Change 中明确相关性排序与品牌详情页排序规则的优先级。
