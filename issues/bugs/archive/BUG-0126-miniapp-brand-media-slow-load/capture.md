# 现象

用户反馈微信小程序品牌列表页、从品牌列表页进入的分类商品列表页、品牌详情页图片加载速度慢。

初步倾向为小程序品牌链路媒体性能问题，涉及品牌 Logo、品牌列表 Banner、品牌详情 Logo、品牌下商品卡片图、品牌证书图片等资源展示。

# 复现步骤

1. 打开微信小程序品牌列表页。
2. 观察品牌列表页 Banner 与品牌 Logo 的加载速度。
3. 从品牌列表页点击某品牌下的类目，进入分类商品列表页。
4. 观察商品卡片图片加载速度。
5. 从品牌列表页进入品牌详情页。
6. 观察品牌详情页 Logo、商品卡片图和证书图片加载速度。

# 期望 vs 实际

期望：品牌链路图片应优先使用可访问、体积合理的缩略图，并结合小程序懒加载与缓存策略，让首屏和列表滚动图片快速出现。

实际：用户体感上述页面图片加载慢。探索阶段发现可能与缩略图体积未限制、历史缩略图缺失或回退原图、部分品牌链路图片未启用小程序懒加载、`/media` 后端代理链路缺少生产侧缓存/CDN 有关。
