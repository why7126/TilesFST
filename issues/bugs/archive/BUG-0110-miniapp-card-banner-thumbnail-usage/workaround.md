# 临时规避方案

## 当前结论

暂无可完全替代修复的临时规避方案。该问题的核心是小程序展示组件对媒体 URL 字段的选择逻辑，需要通过代码核查和统一修复闭环。

## 可选临时措施

- 运营侧优先上传尺寸合理、体积较小的原图，降低未命中缩略图时的加载成本。
- 验证小程序体验版时优先检查商品列表、品牌列表、证书列表和首页 Banner 的图片加载体感与资源 URL。
- 若发现某一场景明显加载原图，可临时降低该场景展示图片尺寸或减少同屏图片数量，但这只能缓解性能问题，不能替代字段选择修复。

## 风险

- 临时压缩原图可能影响详情页或图片预览清晰度。
- 仅依赖运营侧控制图片体积无法保证历史数据和后续上传数据稳定符合性能要求。
- 若后端没有返回缩略图字段，前端无法单独完成完整降级链路。
