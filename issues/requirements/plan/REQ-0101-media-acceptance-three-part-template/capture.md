# 一句话

媒体类需求与 BUG 验收模板应强制拆分列表展示字段、生成策略、历史对象维护或重生成三段证据，并明确 API、Orval、DB 与对象存储影响。

# 原始描述

标题：媒体类需求三段验收模板

背景：sprint-020 同时覆盖列表缩略图展示、缩略图生成策略和历史对象维护入口，验收证据容易分散。

影响范围：需求模板、BUG 验收、media upload、object storage、admin web 列表。

建议验收或复现要点：模板应强制拆分“列表展示字段”“生成策略”“历史对象维护/重生成”三段证据，并明确 API/Orval/DB/对象存储影响。

# 背景与关联

- 关联 Sprint：`sprint-020`
- 涉及端与模块：需求模板、BUG 验收、media upload、object storage、admin web 列表
- 业务价值：减少媒体类需求在列表缩略图展示、缩略图生成策略、历史对象维护入口之间的验收证据分散，提升评审与验收闭环一致性
- 预期后续：在需求与 BUG 验收模板中沉淀三段式证据结构，并要求每段说明 API、Orval、DB、对象存储和前端列表展示影响

# 待澄清

- [ ] 三段式验收模板优先应用于所有媒体类 REQ/BUG，还是仅应用于缩略图、上传、对象维护相关条目
- [ ] “列表展示字段”段是否需要固定列出原图 URL、缩略图 URL、fallback 字段、尺寸或体积字段
- [ ] “生成策略”段是否需要固定覆盖触发时机、失败降级、体积上限、格式转换、重试和可观测日志
- [ ] “历史对象维护/重生成”段是否需要固定覆盖入口权限、批量范围、幂等性、执行结果与失败明细
- [ ] API/Orval/DB/对象存储影响说明是否作为模板必填字段，还是仅在涉及变更时填写“不涉及”

# 建议验收要点

- [ ] 列表展示字段：验收证据必须说明 admin web 列表使用的媒体字段、缩略图字段、fallback 规则、空值状态和展示截图或接口样例。
- [ ] 生成策略：验收证据必须说明缩略图或衍生对象的生成触发、尺寸与体积策略、失败降级、日志或任务追踪，以及 media upload 入口影响。
- [ ] 历史对象维护/重生成：验收证据必须说明历史对象扫描范围、重生成入口、权限边界、幂等性、失败回填和对象存储 key/prefix 影响。
- [ ] 影响矩阵：每条媒体类需求或 BUG 验收必须明确 API、Orval、DB、对象存储、admin web 列表是否受影响；不涉及时需写明“不涉及”。
