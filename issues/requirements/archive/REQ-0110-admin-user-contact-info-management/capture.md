# 用户管理页支持维护用户联系邮箱和手机号码

# 原始描述

用户管理页支持维护用户联系邮箱和手机号码。

# 待澄清

- [ ] 需要维护的是管理后台用户、店主账号用户，还是平台全部用户类型。
- [ ] 邮箱与手机号码是否为必填、是否允许为空，以及格式校验规则。
- [ ] 联系邮箱和手机号码是否用于登录、通知、找回密码或仅作为备注联系信息。
- [ ] 是否需要展示、搜索、筛选、导入导出或操作日志记录这些字段。
