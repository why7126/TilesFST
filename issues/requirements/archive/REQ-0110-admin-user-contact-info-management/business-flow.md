# 业务流程

## 1. 主流程

```text
后台管理员
  |
  v
进入 /admin/users
  |
  +-- 添加用户 -----------------------------+
  |                                        |
  | 填写用户名/头像/昵称/邮箱/手机/角色     |
  |                                        |
  | 前端基础校验 + 后端业务校验             |
  |                                        |
  | 保存成功：创建账号 + 联系信息入库       |
  |                                        |
  +--------------------> 列表刷新/Toast 成功
  |
  +-- 编辑用户 -----------------------------+
                                           |
                         回填邮箱/手机号   |
                                           |
                         修改或清空字段     |
                                           |
                         保存成功：更新入库 |
                                           |
                         列表刷新/Toast 成功
```

## 2. 搜索流程

```text
管理员输入关键词
  |
  v
GET /api/v1/admin/users?keyword=...
  |
  v
后端匹配 username / display_name / email / phone
  |
  v
返回分页列表 + summary
  |
  v
前端展示符合条件的用户
```

## 3. 异常流程

| 场景 | 系统行为 |
|---|---|
| 邮箱为空 | 允许保存为空值 |
| 邮箱格式非法 | 返回业务错误，前端在字段附近展示提示 |
| 手机为空 | 允许保存为空值 |
| 手机包含不允许字符 | 返回业务错误，前端在字段附近展示提示 |
| 邮箱或手机号与其他用户重复 | 允许保存，不提示冲突 |
| 已删除用户编辑 | 沿用既有规则，不允许编辑 |
| 受保护账号编辑 | 沿用既有规则，不允许编辑 |
| 非管理员访问用户管理接口 | HTTP 403，权限边界不变 |

## 4. 与父需求差异

| 项 | REQ-0005 基线 | REQ-0110 变化 |
|---|---|---|
| 添加/编辑字段 | 用户名、头像、昵称、角色 | 增加联系邮箱、手机号码 |
| 列表字段 | 用户、角色、状态、最后登录、创建时间、操作 | 在状态后新增联系邮箱、手机号码独立列；空值显示 `-` |
| 搜索范围 | 历史优化曾收窄为用户名/昵称 | 扩展为用户名、昵称、邮箱、手机号 |
| 数据字段 | `users.email`、`users.phone` 已存在 | 建立管理端维护闭环 |
| 权限模型 | 仅 admin 可管理用户 | 不变 |
| 账号体系 | 用户名登录 | 不变；联系信息不参与登录 |
