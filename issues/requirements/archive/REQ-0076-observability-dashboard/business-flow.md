# 业务流程

## 1. 总体流程

```text
管理员进入 SYSTEM / 日志审计或链路观测
  ↓
系统按默认时间范围加载统一观测摘要
  ↓
管理员查看指标卡、分布图、排行和明细入口
  ↓
按时间 / 客户端 / 日志类型 / 任务类型 / 接口路径筛选
  ↓
发现异常指标
  ├─ 接口错误 / 慢请求 → 查看请求排行 → 打开日志详情
  ├─ 慢任务 / 失败任务 → 查看任务排行 → 打开 Task Trace 时间线
  ├─ 最慢 span → 查看 span 详情 → 跳转关联 task_trace_id
  └─ 客户端异常 → 查看客户端分布 → 下钻相关日志集合
  ↓
复制或输入 request_id / task_trace_id
  ↓
系统展示同链路日志、行为、审计和任务节点
  ↓
管理员完成排障、记录问题或进入后续 BUG / REQ 流程
```

## 2. 追踪 ID 查询流程

```text
用户输入追踪 ID
  ↓
识别 ID 类型
  ├─ request_id
  │   ├─ 查询请求日志
  │   ├─ 查询同 request_id 行为事件 / 审计操作
  │   └─ 查询关联 task_trace_id
  └─ task_trace_id
      ├─ 查询任务主记录
      ├─ 查询任务 span 时间线
      └─ 查询关联 request_id 日志
  ↓
返回结果
  ├─ 单条主记录 → 打开详情或时间线
  ├─ 多条相关记录 → 展示关联记录集合
  └─ 无结果 → 展示无匹配空态
```

## 3. 与父需求的差异

| 项 | 父需求 REQ-0024 | 本需求 REQ-0076 |
|---|---|---|
| 页面定位 | 日志审计、列表查询、详情查看 | 日志审计 + 链路观测，强调聚合指标和排障下钻 |
| 核心对象 | 请求日志、行为事件、审计操作 | 请求、行为、审计、Task Trace 和 span |
| 主要能力 | 筛选、分页、详情、复制 `request_id` | 成功率、错误率、失败原因、客户端分布、慢任务、最慢 span、一键追踪 |
| 数据口径 | 单条日志与基础摘要 | 聚合指标、分布、排行和关联链路 |
| 交互重点 | 从列表进入详情 | 从指标发现异常，再下钻到日志或 Task Trace |

## 4. 异常与边界流程

| 场景 | 处理要求 |
|---|---|
| 无观测数据 | 指标返回零值，分布和排行展示空态。 |
| 聚合接口失败 | 页面展示加载失败反馈，可重试，不影响已有日志列表基础查询。 |
| 无权限访问 | 管理端返回无权限页或 403，不展示任何日志指标。 |
| 追踪 ID 未命中 | 展示无匹配空态，并保留当前输入便于复制或调整。 |
| 数据口径不支持分位值 | 使用平均耗时、最大耗时或固定分桶，并在 design 中说明。 |
| 敏感字段存在 | 聚合结果和详情均只展示脱敏摘要，不输出原始敏感值。 |
