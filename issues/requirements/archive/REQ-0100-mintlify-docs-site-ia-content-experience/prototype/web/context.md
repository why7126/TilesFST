# 原型上下文

## 目标

本原型用于描述 Mintlify 文档站首页、导航和角色入口的信息架构，不生成应用源码。后续 OpenSpec Change 实现时可将其转化为 `mintlify/index.mdx`、Mintlify 配置和必要的页面聚合入口。

## 首页结构

```text
┌──────────────────────────────────────────────┐
│ 瓷砖信息管理平台文档                         │
│ 面向企业员工、店主、导购和实施团队的产品手册 │
│ [查看当前版本] [浏览发布公告]                │
├──────────────────────────────────────────────┤
│ 角色入口                                     │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐ │
│ │ 企业员工   │ │ 店主/导购   │ │ 系统管理员 │ │
│ │ 管理端指南 │ │ 小程序指南  │ │ 治理指南   │ │
│ └────────────┘ └────────────┘ └────────────┘ │
├──────────────────────────────────────────────┤
│ 常用任务                                     │
│ 商品资料维护 | 品牌证书 | 媒体上传 | FAQ      │
├──────────────────────────────────────────────┤
│ 当前版本：latest -> v0.3.4                   │
│ 最近发布：v0.3.4 / v0.3.3                   │
└──────────────────────────────────────────────┘
```

## 导航结构

```text
开始
├── 产品简介
├── 快速开始
└── 当前版本总览

当前版本
├── 管理端
├── 小程序
├── 公开浏览
└── 常见问题

历史版本
├── v0.3.4
└── v0.3.3

发布公告
├── v0.3.4
└── v0.3.3
```

## 视觉与内容约束

- 使用 Mintlify 原生 MDX 组件表达入口，优先 CardGroup、Card、Accordion、Steps 和提示块。
- 不复刻参考项目品牌和色彩，文案应体现瓷砖资料、品牌证书、SKU、媒体和小程序浏览场景。
- 首页图片如使用系统截图，必须引用 `/assets/screenshots/<file>` 并能追溯来源。
- 所有链接必须在站点源目录中存在，不保留模板链接。
- 历史版本入口必须避免让用户误以为历史页面代表最新能力。
