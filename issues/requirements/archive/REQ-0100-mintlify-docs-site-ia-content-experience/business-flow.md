# 业务流程

## 1. 文档站访问流程

```text
用户打开文档站
    |
    v
首页 / 产品简介
    |
    +-- 企业员工
    |       |
    |       v
    |   管理端指南
    |       +-- 商品资料维护
    |       +-- 品牌 / 证书 / Banner / 媒体
    |       +-- 账号 / 日志 / 系统设置
    |
    +-- 店主 / 导购
    |       |
    |       v
    |   小程序指南
    |       +-- 首页与分类
    |       +-- 商品浏览与收藏
    |       +-- 品牌与证书
    |
    +-- 公开访客
    |       |
    |       v
    |   公开浏览指南
    |
    +-- 实施 / 客服
            |
            v
        当前版本 / 历史版本 / 发布公告
```

## 2. 导航维护流程

```text
release usage docs 已生成或更新
    |
    v
读取 releases/<version>/usage-docs/manifest.json
    |
    v
确认站点页面清单
    |
    +-- latest 当前版本
    |       |
    |       v
    |   挂载 overview、admin、miniapp、public、faq
    |
    +-- 历史版本
    |       |
    |       v
    |   保留版本固定路径和版本上下文
    |
    +-- 发布公告
            |
            v
        挂载 releases/<version>/announcement
    |
    v
校验导航缺页、broken links、图片引用和公开安全
```

## 3. 首页内容编排流程

```text
确定 latest 指向版本
    |
    v
读取当前版本页面与截图资产
    |
    v
生成首页信息结构
    |
    +-- 产品定位
    +-- 角色入口
    +-- 常用任务卡片
    +-- 当前版本说明
    +-- 最近发布公告
    |
    v
检查每个卡片链接是否存在
    |
    +-- 存在：保留入口
    +-- 不存在：移除入口或标记待后续版本，不创建空链接
```

## 4. 版本上下文流程

```text
用户进入页面
    |
    v
判断路径类型
    |
    +-- docs/latest/*
    |       |
    |       v
    |   显示当前 latest 实际版本
    |
    +-- docs/vX.Y.Z/*
    |       |
    |       v
    |   显示固定历史版本上下文
    |
    +-- releases/vX.Y.Z/*
            |
            v
        显示发布公告版本上下文
```

## 5. 与父需求 REQ-0094 的差异

| REQ-0094 已完成 | REQ-0100 增强 |
|---|---|
| 定义 `mintlify/` 源目录、多版本投影和共享截图资产 | 优化文档站首页、导航层级、角色入口和内容体验 |
| 关注 release 快照到站点目录的治理边界 | 关注用户如何理解、查找和使用文档 |
| 建立 `latest` 指针和版本目录 | 让 `latest` 完整挂载已有页面并解释当前版本上下文 |
| 提供站点 manifest 与投影一致性 | 增加导航缺页、空链接、页面表达和参考项目裁剪校验 |

## 6. 异常流程

| 异常 | 处理 |
|---|---|
| 首页卡片链接不存在 | 校验失败；修复链接或移除卡片，不保留空入口。 |
| `latest` 只挂载 overview | 校验 warning 或 blocker；补齐当前版本页面导航。 |
| 历史版本页面被改写为新版本语义 | 校验 blocker；回滚内容性改写或补充授权记录。 |
| 参考项目品牌、外部域名或 analytics 被照搬 | 校验 blocker；替换为本项目配置或删除。 |
| 文档站包含 `.DS_Store` 或构建产物 | 校验 blocker；清理并补充忽略规则。 |
| 公开文档包含敏感信息 | 发布门禁阻断，必须移除或脱敏。 |
