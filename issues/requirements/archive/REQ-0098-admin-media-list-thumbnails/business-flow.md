# 业务流程

## 1. 列表图片资源选择流程

```text
运营进入管理端图片密集列表
        |
        v
后端查询列表数据与媒体 object key
        |
        v
后端派生列表缩略图 URL
        |
        v
前端接收列表项
        |
        v
┌───────────────────────────────┐
│ 是否存在 thumbnail URL？        │
└───────────────┬───────────────┘
                │是
                v
        尝试加载缩略图
                |
                v
┌───────────────────────────────┐
│ 缩略图是否加载成功？            │
└───────┬───────────────────────┘
        │是                      │否
        v                        v
   展示缩略图              回退原图 URL
                                 |
                                 v
                       原图失败则展示既有占位
```

## 2. 详情与编辑资源边界

```text
列表快速识别
  使用缩略图
      |
      v
点击编辑 / 详情 / 放大预览
      |
      v
使用原图或原文件
      |
      v
保持清晰度检查、文件查看和业务操作不变
```

## 3. 与关联需求差异

| 关联项 | 差异 |
|---|---|
| REQ-0092 | REQ-0092 关注品牌与证书图片真实缩略图生成；本需求关注管理端列表消费缩略图，并补齐 SKU/Banner 响应字段。 |
| REQ-0095 | REQ-0095 是管理端列表 adapter 检查表；本需求是其中 image adapter 的具体落地项。 |
| REQ-0006 | REQ-0006 是 SKU 管理能力；本需求只调整 SKU 列表图片展示资源，不改变 SKU 业务流程。 |
| REQ-0016 | REQ-0016 是 Banner 管理能力；本需求只调整 Banner 列表图片展示资源，不改变投放配置流程。 |

## 4. 异常流程

- 缩略图字段为空：前端直接使用原图或既有占位。
- 缩略图 404 或加载失败：前端隐藏失败缩略图并尝试原图。
- 原图也失败：展示既有缺图占位，不影响查看、编辑、上下架、删除等行操作。
- 后端无法派生缩略图：列表仍返回原图字段，新增缩略图字段为空，不阻塞列表接口。
