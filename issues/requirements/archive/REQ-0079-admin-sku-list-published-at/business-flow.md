# 业务流程

## 1. 总体流程

```text
后台运营进入管理端
  |
  v
打开瓷砖 SKU 列表页
  |
  v
前端请求管理端 SKU 列表接口
  |
  v
后端返回 SKU 列表数据
  |-- 包含发布时间字段：前端直接映射展示
  |-- 不包含发布时间字段：后续 Change 需补充接口契约
  |
  v
前端渲染表格列
  |-- 业务核心字段
  |-- 状态字段
  |-- 发布时间
  |-- 更新时间
  |-- 操作
  |
  v
运营在列表中对比发布时间与更新时间
```

## 2. 空值展示流程

```text
读取 SKU 发布时间
  |
  +-- 有合法时间
  |     |
  |     v
  |   使用更新时间同款格式化函数展示
  |
  +-- null / missing / invalid
        |
        v
      展示统一占位，例如 "-"
        |
        v
      不影响该行其他字段和操作
```

## 3. 接口影响判断流程

```text
进入实现设计
  |
  v
检查管理端 SKU 列表响应 Schema
  |
  +-- 已有发布时间字段
  |     |
  |     v
  |   前端复用字段 -> 补充前端列与测试
  |
  +-- 无发布时间字段
        |
        v
      确认数据模型是否已有发布时间来源
        |
        +-- 已有数据来源 -> 后端响应补字段 -> OpenAPI/Orval/docs/tests
        |
        +-- 无数据来源 -> OpenSpec Change 明确新增字段或兼容兜底 -> DB/API/docs/tests
```

## 4. 列表交互保持流程

```text
用户执行搜索 / 筛选 / 分页 / 行操作
  |
  v
列表按现有逻辑请求与刷新
  |
  v
新增发布时间列随数据重新渲染
  |
  v
默认排序、分页、筛选条件和操作按钮行为保持不变
```

## 5. 与父需求差异

父需求 `REQ-0006-tile-sku-management` 定义瓷砖 SKU 管理主能力，包含 SKU 维护、列表、状态和基础管理流程。本需求是父能力下的列表字段展示 refinement，只补充管理端 SKU 列表的“发布时间”可见性，不改变 SKU 发布流程、编辑流程或公开端展示。

| 项 | 父需求能力 | REQ-0079 变化 |
|---|---|---|
| SKU 列表 | 展示 SKU 基础信息、状态、更新时间和操作 | 在“更新时间”前新增“发布时间”列 |
| SKU 发布语义 | 由现有发布流程或状态字段维护 | 只读取并展示发布时间，不改发布流程 |
| API / DB | 既有 SKU 管理契约 | 仅在缺字段时补充列表响应或数据字段 |
| 公开端 | 可能展示商品信息 | 本期不涉及店主 Web 或小程序 |
