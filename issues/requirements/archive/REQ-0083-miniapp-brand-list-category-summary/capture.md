# 一句话

小程序品牌列表页下半部调整为每行一个品牌，并在品牌行右侧展示该品牌所有商品对应的末级类目名称。

# 原始描述

小程序品牌列表页中，上半部的轮播图不变，下半部的品牌列表调整如下：

1. 每行显示一个品牌
2. 每行分两部份显示
   - 左侧是品牌logo+品牌名称+商品数量
   - 右侧是该品牌下所有商品对应的类目，展示最后一层级的类目名称

# 背景与关联

- 父需求：`REQ-0060-brand-list-page`
- 涉及端：微信小程序品牌列表页
- 业务价值：让店主在浏览品牌时直接判断品牌商品覆盖的末级类目范围，减少进入品牌详情页后再筛选和查找的步骤。
- 页面边界：品牌列表页上半部轮播图保持不变，本次仅调整下半部品牌列表。
- 预期后续：需要确认当前品牌列表接口是否已返回品牌商品数量及末级类目集合；如接口缺字段，后续 OpenSpec Change 需同步 API、Orval 或小程序 API 类型与测试。

# 待澄清

- [ ] 商品数量是否统计该品牌下全部已上架商品，还是包含未上架/草稿商品
- [ ] 右侧类目名称是否需要去重，以及展示顺序按类目层级、商品发布时间、后台排序还是字典序
- [ ] 当类目数量过多时，右侧展示是否折行、截断、省略为“等 N 类”，或支持横向滚动
- [ ] 当品牌无商品或无类目时，商品数量和类目区域的空态文案如何显示
- [ ] 末级类目名称是否只取商品绑定类目路径的最后一层，若商品只绑定一级/二级类目时是否直接展示该层名称

# 建议验收要点

- [ ] 品牌列表页顶部轮播图布局、数据和交互保持不变
- [ ] 下半部品牌列表每行仅展示一个品牌
- [ ] 每个品牌行左侧展示品牌 Logo、品牌名称和商品数量
- [ ] 每个品牌行右侧展示该品牌下所有商品对应类目的最后一层级类目名称
- [ ] 同一品牌下重复末级类目不重复展示
- [ ] 无 Logo、无商品、无类目及类目名称较长时页面不重叠、不溢出，保持小程序端可读
