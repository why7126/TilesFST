# 业务流程

## 1. 总流程

```text
用户打开微信小程序
  |
  v
进入品牌列表页
  |
  +-- 上半部品牌轮播
  |       |
  |       +-- 保持既有轮播数据、视觉与点击行为
  |
  +-- 下半部品牌列表
          |
          v
    加载公开品牌聚合数据
          |
          +-- 品牌有公开商品
          |       |
          |       v
          |  单行品牌信息
          |  左侧：Logo / 名称 / 商品数量
          |  右侧：公开商品末级类目集合
          |
          +-- 品牌无公开商品或无类目
          |       |
          |       v
          |  商品数量与类目区展示空态
          |
          +-- 网络失败 / 接口失败
                  |
                  v
             错误态 / 重试
```

## 2. 品牌行数据聚合流程

| 步骤 | 输入 | 处理 | 输出 |
|---|---|---|---|
| 1 | 品牌列表公开数据 | 过滤未公开、禁用或不可访问品牌 | 可展示品牌集合 |
| 2 | 品牌关联商品 | 按小程序公开可见商品口径统计 | `productCount` |
| 3 | 商品绑定类目路径 | 取每个商品类目路径最后一层名称 | 原始末级类目名称集合 |
| 4 | 原始末级类目名称集合 | 去重并按稳定规则排序 | `leafCategoryNames` |
| 5 | 品牌基础信息与聚合字段 | 渲染单行品牌信息 | 左侧品牌信息 + 右侧类目汇总 |

## 3. 页面展示流程

| 场景 | 页面行为 | 用户感知 |
|---|---|---|
| 首次加载 | 保留轮播区域，列表区域展示加载态或骨架态 | 页面结构稳定，不白屏 |
| 加载成功 | 每行一个品牌，左侧展示品牌信息，右侧展示末级类目 | 可快速扫读品牌覆盖类目 |
| 品牌无 Logo | 使用品牌占位策略 | 不出现破图或布局跳动 |
| 品牌无公开商品 | 商品数量展示 0，类目区展示空态或隐藏 | 不误解为数据错误 |
| 类目数量过多 | 按折行、限行省略或“等 N 类”策略处理 | 不遮挡品牌信息 |
| 网络失败 | 展示错误态和重试入口 | 可恢复，不停留空白页 |

## 4. 点击与跳转流程

```text
用户点击品牌行
  |
  +-- 品牌公开且目标有效
  |       |
  |       v
  |  进入品牌主页/详情页或品牌商品列表
  |
  +-- 品牌不可访问 / 目标无效
          |
          v
     阻止无效跳转并展示轻量提示
```

## 5. 与父 REQ 差异

| 关联需求 | 已有规则 | 本需求差异 |
|---|---|---|
| `REQ-0060-brand-list-page` | 品牌列表页上半部轮播 + 下半部双列品牌卡片 | 轮播保持不变，下半部改为每行一个品牌的信息行。 |
| `REQ-0058-brand-detail-home-page` | 品牌卡片进入品牌主页/详情页 | 本需求不改详情页，只沿用点击目标。 |
| `REQ-0054-brand-card-common-component` | 品牌卡片通用展示 | 本需求可能需要扩展为单行列表态或新增小程序品牌行组件。 |
| `REQ-0005-brand-management` | 品牌主数据维护 | 本需求仅消费品牌公开数据，不新增管理端维护能力。 |

## 6. 非目标流程

- 不修改品牌列表页顶部轮播配置、跳转和视觉。
- 不进入管理端品牌新增、编辑、上下架、Logo 上传或排序流程。
- 不修改类目层级管理、商品绑定类目流程或类目命名规则。
- 不新增品牌搜索、类目筛选、收藏、询价或下单流程。
- 不新增 Web 展示端品牌列表页面。
