# 用户故事

## US-001 用户浏览品牌列表时快速识别品牌覆盖类目

作为装修业主或普通访客，我希望在品牌列表页下半部直接看到每个品牌覆盖的商品末级类目，以便不用逐个进入品牌详情页也能判断品牌是否符合选材方向。

验收要点：

- 品牌列表页上半部轮播图保持现有展示和交互不变。
- 下半部品牌列表每行只展示一个品牌。
- 每个品牌行右侧展示该品牌公开商品对应的末级类目名称集合。
- 同一品牌下重复末级类目只展示一次。
- 类目较多或名称较长时页面不重叠、不横向溢出。

## US-002 用户通过品牌基础信息判断品牌规模

作为室内设计师，我希望品牌行左侧展示品牌 Logo、品牌名称和商品数量，以便快速判断品牌识别度和可选商品规模。

验收要点：

- 左侧品牌信息区展示品牌 Logo、品牌名称和商品数量。
- 商品数量统计口径与小程序公开可见商品集合一致。
- 品牌 Logo 缺失或加载失败时展示可识别占位，不出现破图。
- 品牌名称较长时保持可读，不挤压商品数量和右侧类目汇总。

## US-003 门店销售向客户介绍品牌商品范围

作为门店销售，我希望在同一行中同时看到品牌、商品数量和类目范围，以便向客户快速解释不同品牌分别覆盖哪些瓷砖品类。

验收要点：

- 品牌行左右信息分区清晰，左侧为品牌基础信息，右侧为类目汇总。
- 右侧类目展示使用短标签、短文本或等价视觉样式，便于扫读。
- 无商品或无类目时展示明确空态，不让用户误解为页面加载失败。
- 在 320、375、430 pt 宽度下，门店销售可正常展示页面给客户查看。

## US-004 用户继续进入品牌主页或商品列表

作为对某个品牌感兴趣的用户，我希望点击品牌行后沿用现有品牌列表页跳转规则，以便继续查看品牌主页、品牌详情或品牌商品列表。

验收要点：

- 品牌行整体可点击，并有小程序原生按压反馈。
- 点击后沿用 `REQ-0060` 与 `REQ-0058` 已定义的品牌详情页/主页跳转规则。
- 已下架、未公开或缺少有效跳转目标的品牌不得进入无效页面。
- 点击埋点如已存在，应继续记录品牌 ID、位置索引和来源入口。

## US-005 产品团队验证小程序设备适配

作为产品团队，我希望在常见小程序视口下验证品牌单行列表的布局，以便上线前发现类目标签拥挤、导航遮挡或底部 TabBar 遮挡问题。

验收要点：

- DevTools 至少覆盖 320、375、430 pt 视口。
- 首屏轮播、品牌行、加载态、空态和错误态不被自定义导航或 TabBar 遮挡。
- 真机验收不可用时明确标记 blocked 或 follow_up，不写作真机通过。
- 验收记录不得包含真实客户数据、token、Cookie 或本机绝对路径。
