# Web 原型上下文

## 1. 原型目标

本原型用于说明管理端 SKU 列表默认排序后的可验收状态，不新增排序控件、不新增筛选项、不改变 SKU 列表现有视觉结构。

核心表达：

- 未上架 SKU 显示在列表前段。
- 未上架 SKU 按创建时间降序。
- 已上架 SKU 显示在未上架 SKU 后。
- 已上架 SKU 按发布时间降序。
- 分页、筛选区、表格和操作列保持管理端列表页一致性。

## 2. 页面结构

```text
Admin Shell
  |
  +-- Page head：瓷砖 SKU
  |
  +-- Metrics：SKU 总数 / 已上架 / 未上架 / 待完善
  |
  +-- Filters：关键词 / 品牌 / 类目 / 状态 / 素材完整度
  |
  +-- Table card
        |
        +-- SKU 信息
        +-- 品牌 / 类目
        +-- 状态
        +-- 创建时间
        +-- 发布时间
        +-- 更新时间
        +-- 操作
  |
  +-- Pagination：page-summary + page-right
```

## 4. 验收关注

- 截图或 Playwright 验收时优先检查行顺序，而不是新增 UI。
- 表格宽度不足时沿用现有横向滚动策略。
- 筛选下拉、分页 DOM、fixed toast 和确认弹窗遵守 `admin-list` 横切 AC。
- PNG Golden Reference 可在后续 `/req-opsx` 或 UI 设计确认阶段导出，本阶段 HTML/context 足以表达排序策略。
