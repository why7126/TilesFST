# 业务流程

## 1. 总体流程

```text
后台运营进入管理端
  |
  v
打开 SKU 列表页
  |
  v
应用当前搜索 / 筛选条件
  |
  v
获取匹配的 SKU 结果集
  |
  v
按默认排序规则处理完整结果集
  |
  +-- 先分组：未上架 SKU 在前，已上架 SKU 在后
  |
  +-- 未上架组：created_at DESC，次级稳定排序
  |
  +-- 已上架组：published_at DESC，次级稳定排序
  |
  v
按分页参数切分当前页
  |
  v
渲染 SKU 表格、分页与行操作
```

## 2. 状态分组流程

```text
读取 SKU 状态
  |
  +-- 状态 = 已上架
  |     |
  |     v
  |   进入已上架分组
  |     |
  |     v
  |   使用 published_at 降序
  |
  +-- 状态 != 已上架
        |
        v
      进入未上架分组
        |
        v
      使用 created_at 降序
```

## 3. 空值与稳定排序流程

```text
计算分组内排序字段
  |
  +-- 时间字段合法
  |     |
  |     v
  |   按时间降序排序
  |
  +-- 时间字段为空 / 缺失 / 不可解析
        |
        v
      使用明确兜底顺序
        |
        v
      再使用稳定次级字段排序（如 id DESC）
        |
        v
      保证刷新、翻页、筛选后顺序稳定
```

## 4. 搜索筛选分页流程

```text
用户输入关键词 / 选择品牌 / 选择类目 / 选择状态 / 调整素材条件
  |
  v
提交查询或触发列表刷新
  |
  v
先得到满足条件的完整结果集
  |
  v
应用 REQ-0087 默认排序规则
  |
  v
再根据 page / page_size 切分当前页
  |
  v
渲染页面
```

## 5. 与父需求差异

父需求 `REQ-0006-tile-sku-management` 定义 SKU 管理页的列表、筛选、维护、素材与上下架能力。本需求是父能力下的列表默认排序 refinement，只改变 SKU 列表默认展示顺序，不改变 SKU 新建、编辑、上下架、删除、素材维护或公开端展示流程。

| 项 | 父需求能力 | REQ-0087 变化 |
|---|---|---|
| SKU 列表 | 展示 SKU 信息、品牌类目、规格、价格、素材、状态、时间和操作 | 优化默认排序规则 |
| 未上架 SKU | 可通过状态识别和管理 | 默认排在已上架 SKU 前，按创建时间降序 |
| 已上架 SKU | 可查看并执行管理操作 | 在未上架 SKU 后，按发布时间降序 |
| 筛选分页 | 支持列表搜索、筛选和分页 | 排序必须在分页前对完整结果集生效 |
| UI 控件 | 管理端列表页既有结构 | 不新增排序控件或说明卡片 |
| API / DB | 既有 SKU 管理契约 | 仅在排序字段或分页排序能力不足时同步契约 |
