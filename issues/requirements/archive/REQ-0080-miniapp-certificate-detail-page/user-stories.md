# 用户故事

## US-001 查看证书完整信息

作为装修客户，我希望从证书列表或品牌主页进入证书详情页后，能看到证书名称、品牌、类型、编号、发证机构、有效期和说明，以便判断品牌资质是否可信。

验收要点：

- 详情页可根据 `certificateId` 加载并展示公开证书信息。
- 证书名称、所属品牌和证书类型必须展示。
- 可选字段存在时展示，不存在时隐藏或使用约定占位，不出现 `null`、`undefined` 或接口字段名。

## US-002 浏览证书图片和文件

作为设计师，我希望在详情页顶部查看证书主图和多张证书图片，并能进入图片预览或打开 PDF，以便向业主说明证书内容。

验收要点：

- 主图位于媒体区首项，多图按后台排序展示。
- 图片支持小程序原生预览，多图可左右切换。
- PDF 或未知文件类型使用稳定占位和可恢复打开策略，不显示破图。

## US-003 进入品牌主页

作为品牌访客，我希望能从证书详情页进入所属品牌主页，以便继续查看品牌介绍、商品和其他证书。

验收要点：

- 详情页展示品牌名称和清晰品牌入口。
- 品牌入口使用 `brandId` 或既有品牌路由参数跳转。
- 品牌不可公开时证书详情默认不可公开，避免暴露品牌内部资料。

## US-004 分享证书详情

作为门店导购，我希望能通过微信分享证书详情给客户，以便对方直接打开同一张证书。

验收要点：

- 分享标题包含证书名称和品牌名称。
- 分享路径携带 `certificateId` 与来源参数。
- 分享图优先使用证书主图，无主图时使用稳定兜底图。

## US-005 处理异常与边界状态

作为小程序用户，我希望证书不存在、网络失败、图片失败或文件不可打开时页面有明确提示，以便知道是否重试或返回。

验收要点：

- 缺少或非法 `certificateId` 展示参数错误或证书暂不可查看状态。
- 网络失败提供重新加载入口。
- 单个媒体失败不阻断证书文字信息和品牌入口展示。

## US-006 分享直达与返回兜底

作为从微信群或好友分享进入的用户，我希望证书详情页能正常加载，并在没有上一页页面栈时仍能安全返回首页或证书列表。

验收要点：

- 分享直达路径可加载同一详情页能力。
- 自定义导航返回按钮在有页面栈时返回上一页，无页面栈时进入安全兜底入口。
- 加载态、错误态和空状态下返回按钮仍可用。
