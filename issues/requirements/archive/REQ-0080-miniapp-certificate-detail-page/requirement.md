# REQ-0080 微信小程序新增证书详情页

## 1. 需求背景

菲尚特瓷砖微信小程序已通过证书列表页向访客展示公开证书资料，后台也已支持品牌证书管理、多图上传与主图设置。当前证书列表侧重聚合浏览与文件预览，但缺少承载单个证书完整信息、证书图片组、品牌关联和分享路径的详情页。

本需求新增小程序证书详情页，参照商品详情页的信息层级和浏览体验，让装修客户、设计师、门店导购和品牌访客能够在移动端完整查看证书内容，并将证书作为品牌资质背书进行分享。

## 2. 目标用户

1. 装修客户：希望查看品牌资质、检测报告、环保认证等证书细节，辅助信任判断。
2. 设计师：需要向业主展示可验证的证书资料，便于沟通产品可信度。
3. 门店导购：需要从小程序快速打开并分享证书详情，辅助现场介绍。
4. 品牌访客：从品牌主页或证书列表进入后，希望继续了解单张证书的完整信息。

## 3. 产品目标

1. 新增小程序证书详情页，补齐证书列表到单证书浏览的闭环。
2. 复用商品详情页的大媒体区、信息分区、分享、品牌入口和错误态体验。
3. 支持证书多图与主图规则，默认以主图作为详情页首屏视觉。
4. 仅展示允许公开访问的证书信息，不暴露后台备注、审计字段或对象存储原始 Key。
5. 为后续品牌详情页证书区域、商品详情页品牌资质入口和微信分享承接提供稳定路由。

## 4. 范围

### 4.1 包含

- 小程序新增证书详情页，建议路由为 `pages/certificate-detail/index`。
- 证书列表页证书卡片点击进入详情页，详情页内提供图片预览或 PDF 打开能力。
- 支持从证书列表页、品牌详情页证书区域和微信分享路径进入详情页。
- 顶部媒体区展示证书主图、多图轮播或 PDF/未知文件占位。
- 详情信息展示：证书名称、所属品牌、证书类型、证书编号、发证机构、有效期或有效状态、说明等公开字段。
- 品牌入口：展示品牌信息并支持跳转品牌主页。
- 分享能力：分享标题、路径和分享图围绕当前证书生成。
- 加载态、空状态、错误态、图片失败、文件不可预览、证书不可公开等状态。
- 详情页曝光、媒体切换、图片预览、文件打开、品牌点击、分享点击和加载失败埋点。

### 4.2 不包含

- 管理端证书新增、编辑、上传、删除、显示/隐藏或主图设置能力。
- 证书审批、真伪校验、OCR 识别、电子签章或防伪查询。
- 小程序端新增、编辑或删除证书。
- 商品收藏、购物车、立即购买、在线下单、支付、库存、优惠券或询价承诺。
- 证书与 SKU 的强绑定管理；若商品详情页需要展示证书入口，可在后续需求或 Change 中明确。
- 前端直连未授权对象存储、展示对象 Key、后台备注、审计字段或内部用户字段。

## 5. 功能要求

### FR-001 页面入口与路由

- 证书详情页必须通过 `certificateId` 或等价稳定 ID 加载单个证书。
- 证书列表页卡片点击应进入证书详情页，而不是直接预览文件；详情页内再提供预览入口。
- 支持来源参数，例如 `source=certificate_list|brand_detail|share`，用于返回策略和埋点。
- 缺少、非法或不存在的 `certificateId` 应展示可恢复错误状态，提供返回上一页或返回证书列表入口。

### FR-002 公开证书数据范围

- 详情页仅展示未删除、`is_visible=true` 且所属品牌允许公开的证书。
- 不可公开、已隐藏或已删除的证书不得返回完整详情。
- API 响应不得包含后台备注、审计字段、内部用户字段、对象存储原始 Key 或本机路径。
- 文件 URL 必须由后端控制，遵守 MinIO 单桶和受控访问策略。

### FR-003 顶部媒体区

- 页面顶部采用参照商品详情页的大媒体区布局，优先展示证书主图。
- 多图证书按主图优先、其余图片按排序值展示；仅一张图时不强制自动轮播。
- 图片支持小程序图片预览能力，预览从当前图片开始，并支持多图左右切换。
- PDF 证书或未知文件类型使用稳定占位，不显示破图。
- 图片加载失败时展示证书占位和可理解提示，不影响详情文字信息浏览。

### FR-004 证书信息展示

- 详情页必须展示证书名称、所属品牌和证书类型。
- 证书编号、发证机构、有效期、有效状态、说明等字段存在时展示。
- 空字段按规则隐藏或显示“—”，不得出现 `null`、`undefined`、接口字段名或空白异常模块。
- 有效期需覆盖长期有效、起止日期、仅到期日期、已过期、未设置等状态。
- 说明文案支持换行展示，但不得执行脚本或渲染不安全内容。

### FR-005 品牌入口

- 详情页应展示所属品牌信息，并提供清晰品牌主页入口。
- 品牌入口参数使用 `brandId` 或既有品牌路由参数。
- 品牌不可公开或已停用时，证书详情默认不可公开；若后续业务允许例外展示，必须在 OpenSpec 设计阶段明确。

### FR-006 分享

- 点击分享调起微信分享能力。
- 分享标题优先包含证书名称和品牌名称。
- 分享路径携带 `certificateId` 与来源参数，从分享进入后页面能力与普通进入一致。
- 分享图优先使用证书主图；无主图时使用证书占位或品牌兜底图。
- 分享不包含内部备注、后台状态或不可公开字段。

### FR-007 状态与错误处理

- 首次加载展示稳定骨架屏，媒体区高度不因加载状态变化产生明显跳动。
- 网络失败时展示重试入口，不白屏。
- 证书不存在、已隐藏、品牌不可公开或无权限访问时展示“证书暂不可查看”类提示。
- 文件缺失、图片失败、PDF 打开失败时不阻断证书文本信息展示。
- 重复点击预览、品牌入口或分享时应有防重复触发策略。

### FR-008 埋点

- 页面曝光：记录证书 ID、品牌 ID、来源入口和请求 ID。
- 媒体切换：记录证书 ID、媒体索引、媒体类型。
- 图片预览或 PDF 打开：记录文件类型、是否成功和失败原因。
- 品牌点击：记录证书 ID、品牌 ID 和来源模块。
- 分享点击：记录证书 ID、品牌 ID 和分享来源。
- 加载失败：记录错误类型、来源入口和是否可恢复。

## 6. UI 约束

- 视觉风格延续小程序“工业石材 · 暗色旗舰风”，与商品详情页、证书列表页保持一致。
- 页面使用全局自定义导航栏，标题建议为“证书详情”或证书名称的安全截断版本。
- 首屏顶部为证书主视觉，不使用小卡片包裹主媒体。
- 信息分区可参照商品详情页的 `summary`、品牌卡、参数面板和底部操作区结构，但字段语义必须围绕证书。
- 品牌金仅用于重点 Badge、激活态或主操作，不作为大面积背景色。
- 长证书名称、长品牌名、长发证机构需截断或换行，不撑破页面。
- 适配 320-430px 逻辑宽度和底部安全区，主要点击目标不小于 44x44px。
- 页面不得出现购物车、购买、询价、价格、库存或促销相关视觉元素。

## 7. 接口建议

```http
GET /api/v1/miniapp/certificates/{certificateId}
```

响应建议包含：

| 字段 | 说明 |
|---|---|
| `certificate_id` | 证书 ID |
| `certificate_name` | 证书名称 |
| `certificate_type` / `certificate_type_label` | 证书类型 |
| `brand_id` / `brand_name` | 所属品牌 |
| `certificate_number` | 证书编号，可为空 |
| `issuer` | 发证机构，可为空 |
| `valid_from` / `valid_to` | 有效期，可为空 |
| `validity_status` | 有效状态 |
| `description` | 公开说明，可为空 |
| `images` | 证书图片组，含 URL、排序、主图标记 |
| `file` | PDF 或旧单文件证书信息 |
| `share` | 分享标题、路径、图片 |

接口要求：

- 必须复用统一响应 envelope。
- 若新增或调整 API，必须同步 OpenAPI、Orval 或小程序服务层、接口文档和后端集成测试。
- 若详情页复用列表接口字段不足，后续 OpenSpec Change 需明确扩展策略。

## 8. 数据与权限约束

- 数据事实源为后台品牌证书主数据。
- 小程序端只读公开证书，不提供维护操作。
- 后端必须过滤隐藏、软删除和不可公开品牌证书。
- 证书多图、主图和文件 URL 必须遵守后端媒体与对象存储策略。
- 前端不得根据本地过滤替代后端权限控制。
