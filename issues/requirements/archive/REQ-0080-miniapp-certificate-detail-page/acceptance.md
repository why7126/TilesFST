# 验收标准

## 功能 AC

- [ ] AC-001 证书详情页可通过 `certificateId` 加载单个证书，并支持 `source` 等来源参数用于返回策略和埋点。
- [ ] AC-002 证书列表页卡片点击进入证书详情页，不再直接把卡片主点击绑定为文件预览；详情页内保留图片预览或 PDF 打开入口。
- [ ] AC-003 支持从证书列表页、品牌详情页证书区域和微信分享卡片进入详情页。
- [ ] AC-004 详情页仅展示未删除、`is_visible=true` 且所属品牌允许公开的证书。
- [ ] AC-005 API 响应和页面均不暴露后台备注、审计字段、内部用户字段、对象存储原始 Key、本机路径或未授权直连地址。
- [ ] AC-006 顶部媒体区优先展示证书主图；多图证书按主图优先、其余图片按排序值展示。
- [ ] AC-007 仅一张图片时不强制自动轮播；多张图片可切换并显示当前媒体状态。
- [ ] AC-008 图片支持小程序图片预览能力，预览从当前图片开始，多图可左右切换。
- [ ] AC-009 PDF 证书或未知文件类型使用稳定占位，并通过受控打开、复制提示或等价方式处理。
- [ ] AC-010 图片加载失败、PDF 打开失败或文件缺失时展示可理解提示，不阻断证书文字信息浏览。
- [ ] AC-011 详情页展示证书名称、所属品牌和证书类型。
- [ ] AC-012 证书编号、发证机构、有效期、有效状态和说明字段存在时展示；空字段隐藏或显示“—”，不出现 `null`、`undefined` 或接口字段名。
- [ ] AC-013 有效期展示覆盖长期有效、起止日期、仅到期日期、已过期和未设置。
- [ ] AC-014 详情页展示品牌入口，点击后进入对应品牌主页，参数使用 `brandId` 或既有品牌路由参数。
- [ ] AC-015 分享标题包含证书名称和品牌名称；分享路径携带 `certificateId` 和来源参数。
- [ ] AC-016 分享图优先使用证书主图；无主图时使用稳定占位或品牌兜底图。
- [ ] AC-017 缺少、非法或不存在的 `certificateId` 展示可恢复错误状态，提供返回上一页或安全入口。
- [ ] AC-018 证书隐藏、品牌不可公开或无权限访问时展示“证书暂不可查看”类状态，不返回完整详情。
- [ ] AC-019 重复点击预览、品牌入口和分享操作不会触发并发重复请求或重复跳转。
- [ ] AC-020 埋点覆盖详情曝光、媒体切换、图片预览、文件打开、品牌点击、分享点击和加载失败。

## UI AC

- [ ] AC-021 页面视觉延续小程序“工业石材 · 暗色旗舰风”，与商品详情页和证书列表页保持一致。
- [ ] AC-022 页面使用全局自定义导航栏，标题为“证书详情”或证书名称安全截断版本。
- [ ] AC-023 顶部媒体区采用大图布局，不使用小卡片包裹主视觉。
- [ ] AC-024 信息分区参照商品详情页结构，但字段语义围绕证书，不出现价格、收藏、推荐、购物车、购买、询价、库存或促销模块。
- [ ] AC-025 品牌金仅用于重点 Badge、激活态或主操作，不作为大面积背景色。
- [ ] AC-026 长证书名称、长品牌名、长发证机构和长说明在 320/375/430 pt 视口下不撑破页面，不产生横向滚动。
- [ ] AC-027 主要点击目标不小于 44x44 pt，底部安全区不遮挡分享或品牌入口。
- [ ] AC-028 加载态骨架屏、错误态、空状态和网络失败状态均不被自定义导航栏遮挡。
- [ ] AC-029 分享直达详情页时返回按钮可用；无页面栈时可返回首页或证书列表。
- [ ] AC-030 原型 `prototype/miniapp/certificate-detail.html` 可在 Chromium、Chrome 和 Safari 移动端模式直接预览；PNG Golden Reference 待后续导出。

## API / 数据 AC

- [ ] AC-031 若新增 `GET /api/v1/miniapp/certificates/{certificateId}` 或调整现有接口，必须同步 OpenAPI、Orval 或小程序服务层、接口文档和后端集成测试。
- [ ] AC-032 详情接口必须复用统一响应 envelope，错误码遵循项目统一错误规范。
- [ ] AC-033 详情接口必须由后端过滤隐藏、软删除和不可公开品牌证书，前端不得依赖本地过滤作为唯一安全边界。
- [ ] AC-034 文件读取遵守 MinIO 单桶和后端受控 URL 策略，不暴露真实 AccessKey、SecretKey、对象 Key 或本机路径。
- [ ] AC-035 若新增证书详情字段、证书图片组字段或分享字段，必须同步 Pydantic Schema、SQLite/MySQL 文档或迁移、API 文档和测试。
- [ ] AC-036 旧单文件证书与多图证书均可在详情页稳定展示；主图字段缺失时有确定兜底规则。

## 非功能 AC

- [ ] AC-037 4G 网络下首屏可交互时间目标不超过 2.5 秒，首屏只预加载主图或首个文件占位。
- [ ] AC-038 图片优先使用适合小程序的压缩资源，并提供兼容降级。
- [ ] AC-039 说明文案仅按安全文本或受控富文本展示，不执行脚本、不暴露内部路径或未授权资源。
- [ ] AC-040 DevTools 320/375/430 pt evidence 必须覆盖正常、加载、错误、无图/PDF、分享直达状态；真机不可用时标记 blocked 或 follow_up，不得写作真机通过。
