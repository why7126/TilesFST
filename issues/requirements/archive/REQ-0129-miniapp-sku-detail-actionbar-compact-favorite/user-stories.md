# 用户故事

## US-001 装修客户减少底部遮挡

作为装修客户，我希望商品详情页底部固定操作栏更紧凑，这样我浏览商品图片、参数和推荐商品时，屏幕下方不会被过高的操作区域占用。

验收要点：

- [ ] 商品详情页底部收藏按钮不显示第二行“收藏 / 已收藏”文字。
- [ ] 底部操作栏高度相比现状压缩，页面底部内容不被遮挡。
- [ ] 常见窄屏视口下无横向滚动、无按钮重叠。

## US-002 设计师快速识别收藏状态

作为室内设计师，我希望收藏按钮虽然去掉文字，但仍能清楚看出当前 SKU 是否已收藏，这样我可以快速维护备选商品清单。

验收要点：

- [ ] 未收藏与已收藏状态通过心形图标形态和颜色区分。
- [ ] 点击收藏、取消收藏后仍有 toast 反馈。
- [ ] 收藏失败时状态回滚，不出现页面状态与实际保存结果不一致。

## US-003 门店销售突出分享动作

作为门店销售，我希望“分享给客户”按钮在底部操作栏中保持主操作地位，这样演示商品时可以更顺手地发送给客户。

验收要点：

- [ ] “分享给客户”按钮仍保持清晰可见、可点击。
- [ ] 收藏按钮作为次级图标按钮，不抢占分享按钮视觉权重。
- [ ] 微信分享能力和既有分享事件不被改动。

## US-004 深层浏览时返回首页不被干扰

作为从列表、收藏或分享进入详情页的用户，我希望返回首页悬浮按钮仍然避开底部操作栏，这样不会误触或遮挡关键按钮。

验收要点：

- [ ] 商品详情页底部栏压缩后，返回首页悬浮按钮 actionbar offset 同步调整。
- [ ] 悬浮按钮不遮挡收藏按钮、分享按钮、推荐商品卡片和底部安全区。
- [ ] 返回首页跳转语义与原能力保持一致。
