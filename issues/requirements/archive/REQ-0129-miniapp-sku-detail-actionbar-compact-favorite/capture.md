# 一句话

小程序商品详情页底部收藏按钮应去掉下方文字，仅保留心形状态表达，并压缩底部操作栏高度，同时同步调整返回首页悬浮按钮的 actionbar offset。

# 原始描述

小程序商品详情页底部收藏按钮去掉下方文字，压缩底部操作栏高度，并同步调整首页悬浮按钮 offset。

# 背景与关联

- 关联父需求：`REQ-0044-miniapp-sku-detail-page`
- 关联需求：`REQ-0085-miniapp-global-home-floating-button`
- 涉及端与模块：微信小程序商品详情页、底部操作栏、收藏按钮、返回首页悬浮按钮
- 业务价值：减少商品详情页底部固定区域占高，降低次级操作的视觉噪音，让用户更专注于商品内容浏览和“分享给客户”主操作。
- 分类结论：需求；属于已交付页面的体验增强，不按 BUG 处理。
- 拆分结论：不拆分；收藏按钮精简和首页悬浮按钮 offset 调整属于同一底部栏高度优化闭环。

# 影响范围

- 微信小程序：本期涉及。
- Web 管理端：不涉及。
- 店主 Web 展示端：不涉及。
- API / Orval：不涉及，收藏接口契约不变。
- 数据库：不涉及，收藏状态存储模型不变。
- Docker Compose：不涉及。
- 产品数据采集与链路观测：N/A；仅调整小程序静态 UI 高度、按钮文案与悬浮按钮位置，不新增或修改 API、DB、请求封装、行为事件、请求日志或 Task Trace 字段。

# 建议验收要点

- [ ] 商品详情页底部收藏按钮不再显示“收藏 / 已收藏”下方文字，仅通过空心 / 实心心形和激活颜色表达状态。
- [ ] 点击收藏与取消收藏仍正常调用既有收藏逻辑，并保留成功 / 失败 toast 反馈。
- [ ] 底部操作栏高度相比当前实现明显压缩，安全区适配正常，不遮挡页面内容。
- [ ] “分享给客户”主按钮仍保持清晰可点，收藏按钮作为次级动作不抢占主按钮视觉优先级。
- [ ] 返回首页悬浮按钮在商品详情页 actionbar 场景下同步下移或重算 offset，避免因操作栏变矮后悬浮按钮距离底栏过大。
- [ ] 在至少一个常见手机视口完成视觉验收，确认底部栏、分享按钮、收藏按钮、首页悬浮按钮无重叠、无文字裁切。

# 待澄清

- [ ] 收藏按钮是否完全无文字，还是在无障碍或长按提示层保留语义说明。
- [ ] 底部操作栏目标高度是否按“紧凑但保留 88rpx 主按钮触控高度”执行，还是进一步压缩主按钮高度。

# 探索结论

`/explore` 已判断当前收藏按钮下方文字主要用于解释图标，状态表达已有空心 / 实心心形、激活颜色、toast 与收藏列表反馈兜底；该文字会增加底部操作栏纵向高度和视觉噪音，建议进入体验优化需求。
