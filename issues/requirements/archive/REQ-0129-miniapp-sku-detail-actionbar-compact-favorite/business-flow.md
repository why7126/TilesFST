# 业务流程

## 1. 主流程

```text
用户进入商品详情页
  |
  v
页面加载 SKU 详情、收藏状态和分享数据
  |
  v
底部展示紧凑操作栏
  |
  +-- 收藏图标按钮
  |     |
  |     +-- 点击收藏 / 取消收藏
  |     |     |
  |     |     +-- 请求成功：切换心形状态并展示 toast
  |     |     |
  |     |     +-- 请求失败：回滚状态并展示失败 toast
  |     |
  |     +-- 无可见第二行文字
  |
  +-- 分享给客户主按钮
  |     |
  |     +-- 调起微信原生分享
  |
  +-- 返回首页悬浮按钮
        |
        +-- 按 actionbar 高度避让底部栏和安全区
```

## 2. 与父需求差异

| 项 | `REQ-0044` 原始能力 | `REQ-0129` 调整 |
|---|---|---|
| 商品详情主体 | 展示媒体、品牌、参数、推荐、收藏和分享 | 不调整主体信息架构 |
| 收藏能力 | SKU 粒度收藏，底部操作栏可收藏 / 取消收藏 | 收藏逻辑不变，仅移除底部按钮可见文字 |
| 分享能力 | 底部主入口调起微信分享 | 分享入口能力和文案保持稳定 |
| 底部操作栏 | 固定操作栏承载底部动作 | 压缩操作栏高度，减少内容遮挡 |
| 返回首页悬浮按钮 | 由 `REQ-0085` 提供非首页返回首页入口 | 同步调整商品详情页 actionbar offset |

## 3. 状态流

```text
未收藏
  |
  | 点击心形
  v
请求中
  |
  +-- 成功 --> 已收藏 + toast
  |
  +-- 失败 --> 未收藏 + 失败 toast

已收藏
  |
  | 点击心形
  v
请求中
  |
  +-- 成功 --> 未收藏 + toast
  |
  +-- 失败 --> 已收藏 + 失败 toast
```

## 4. 边界流程

| 场景 | 处理 |
|---|---|
| 分享直达详情页 | 底部栏与返回首页悬浮按钮仍按详情页布局展示，返回兜底沿用既有策略。 |
| 收藏请求中 | 收藏按钮保持可识别 loading / busy 状态，不造成操作栏高度变化。 |
| 底部安全区存在 | 操作栏 padding 和首页悬浮按钮 offset 均需包含安全区避让。 |
| 收藏接口失败 | 状态回滚，toast 提示失败，不新增错误页或额外说明文案。 |
| 无障碍说明不足 | 实现阶段优先补充 `aria-label` 或等价语义，不恢复可见第二行文字。 |
