# 一句话

管理后台主题切换入口应从侧边栏移入用户菜单，并将主题模式收敛为暗色旗舰与跟随系统两种，通过切换按钮完成切换。

# 原始描述

管理后台主题切换入口移入用户菜单，并收敛为暗色旗舰与跟随系统两种模式。

补充约束：不需要显示开关文案，支持切换按钮即可。

# 背景与关联

- 需求类型：管理后台体验优化 / 用户偏好设置
- 涉及端与模块：Web 管理后台、用户菜单、主题偏好、登录前主题初始化、账号主题同步
- 业务价值：将主题偏好归入用户个人操作区域，减少侧边栏导航噪音，并降低多主题选择带来的认知成本
- 预期后续：明确两种主题模式的交互、持久化、API contract 与兼容策略后进入 PRD 生成

# 待澄清

- [ ] 切换按钮是否只在用户菜单展开层内展示，还是用户菜单触发区域也需要直接可见入口
- [ ] “跟随系统”在系统浅色时展示亮色、系统深色时展示暗色是否符合预期
- [ ] 已保存为“浅色”或“舒适暗色”的历史用户偏好应迁移到“跟随系统”还是“暗色旗舰”

# 建议验收要点

- [ ] 管理后台侧边栏不再展示独立主题选择器，用户菜单内提供无额外开关文案的主题切换按钮。
- [ ] 管理后台仅允许在“暗色旗舰”和“跟随系统”两种模式间切换，不再暴露“舒适暗色”和独立“浅色”选项。
- [ ] 主题偏好在本机与已登录账号中保持一致；同步失败时本机主题仍立即生效，并保留可理解的错误反馈。
- [ ] 登录前初始化脚本、前端主题枚举、后端主题偏好校验、OpenAPI/Orval 与相关测试同步收敛到两种模式。
- [ ] “跟随系统”随操作系统浅色/深色偏好变化正确解析实际亮暗主题。
