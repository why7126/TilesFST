# 业务流程

## 1. 全局配置保存流程

```text
管理员
  │
  ▼
进入 系统设置 / 媒体与存储
  │
  ▼
查看 缩略图体积目标上限
  │
  ├─ 设置 0
  │    └─ 表示不限制，保持当前模式
  │
  └─ 设置 N KB
       └─ 后续新生成缩略图尽量不超过 N KB
  │
  ▼
点击保存设置
  │
  ├─ 校验失败
  │    └─ 字段下方展示错误，不保存
  │
  └─ 校验通过
       └─ 后端保存 media 设置，固定 toast 提示成功
```

关键边界：

- 保存配置不自动扫描历史对象。
- 保存配置不改变 `.thumb` Key / URL 规则。
- 恢复默认、dirty Tab 切换等确认交互必须使用 DS modal。

## 2. 新上传缩略图生成流程

```text
上传图片
  │
  ▼
后端校验 MIME / 原图大小
  │
  ▼
写入原图对象
  │
  ▼
读取全局 thumbnail_max_size_kb
  │
  ├─ 0 / 不限制
  │    └─ 按现有尺寸与默认质量生成缩略图
  │
  └─ N KB
       ├─ 先按现有尺寸与默认质量生成
       ├─ 超过目标则递减质量
       ├─ 仍超过则可收缩尺寸
       └─ 仍未达标则记录 warning
  │
  ▼
写入同目录 .thumb 缩略图对象
  │
  ▼
返回 object_key / url / thumbnail_key / thumbnail_url
```

适用资源：

- SKU 图片。
- SKU 暂存图片正式化补生成。
- 品牌 Logo。
- Banner 图片。
- 品牌证书图片。

## 3. 历史缩略图受控重生成流程

```text
运维 / 管理员提出历史应用新策略
  │
  ▼
运行维护任务 dry-run
  │
  ├─ 统计候选对象
  ├─ 统计已符合、缺失、失败、跳过
  └─ 输出脱敏摘要
  │
  ▼
人工确认风险与窗口
  │
  ▼
运行维护任务 apply
  │
  ├─ 读取原图
  ├─ 按当前全局策略重生成 .thumb
  ├─ 写入对象存储
  └─ 记录成功、失败、跳过、重试候选
  │
  ▼
二次审计 / 抽样验证
```

关键边界：

- 历史重生成是独立维护动作，不由系统设置保存自动触发。
- dry-run、apply、二次审计结果应形成可复核摘要。
- 媒体路径中的业务“暂存目录”语义不得被误判为 Issue 生命周期中间态。
