# 一句话

将小程序 DevTools 与体验版网络面板验证纳入 release/miniapp 发布准备清单，确保小程序发布前能人工确认实际请求环境、接口可达性和关键资源加载表现。

# 原始描述

将小程序 DevTools/体验版网络面板验证纳入 release/miniapp 准备清单。

# 背景

当前 release 与 miniapp 准备流程已经覆盖环境切换、静态检查和生产接口 smoke 等发布前动作，但小程序真实运行链路仍需要在微信开发者工具和体验版环境中观察网络面板，确认请求域名、环境策略、接口状态码、静态资源与媒体资源加载符合预期。

该需求属于发布准备与小程序验收清单增强，不是现有功能缺陷。后续进入开发或文档治理调整前，应通过 OpenSpec Change 明确要更新的 release/miniapp 命令清单、验收记录格式和人工确认证据要求。

# 影响范围

- 小程序发布前准备流程和人工验证清单。
- `/miniapp-prepare`、`/miniapp-confirm` 或 release 准备相关命令的输出清单。
- 小程序 DevTools 与体验版验证证据记录方式。
- 发布前接口、静态资源、媒体资源、请求域名和环境策略确认。
- release/miniapp 使用文档、发布治理文档和验收报告模板。

# 待澄清

- [ ] 网络面板验证是否要求同时覆盖微信开发者工具、本地预览码和体验版。
- [ ] 必验页面范围是否包括首页、品牌列表、SKU 列表、SKU 详情、证书详情和视频播放。
- [ ] 验证项是否需要记录截图、导出 HAR/日志，还是仅记录人工确认结论。
- [ ] 失败时是否阻断发布，还是允许记录豁免原因后继续。
- [ ] release 准备清单与 miniapp 准备清单是否共用同一验收模板。

# 建议验收要点

- [ ] 小程序发布准备清单中明确包含 DevTools 网络面板验证。
- [ ] 小程序发布准备清单中明确包含体验版网络面板验证。
- [ ] 验证项覆盖请求域名、API 环境、HTTP 状态、接口错误响应、静态资源和媒体资源加载。
- [ ] 关键页面或关键路径的网络验证范围明确，且可被发布负责人逐项勾选。
- [ ] 验证结果能记录通过、失败、豁免和证据入口。
- [ ] 若网络面板发现请求环境错误、生产接口不可达或资源加载失败，发布准备流程能给出阻断或人工确认说明。
- [ ] 相关 release/miniapp 命令、文档或模板更新后，通过对应校验命令确认清单可用。
