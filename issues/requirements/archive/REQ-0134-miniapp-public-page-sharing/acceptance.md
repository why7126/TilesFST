# 公开页面分享验收清单

## 1. 验收范围与方法

本清单对应 [需求说明](requirement.md) FR-001 至 FR-008。所有复选框表示实现后的功能验收，自动化与DevTools验收已执行，真机接收已豁免，图片异常已补证；文档齐备不代表功能通过。

每个 AC-001 至 AC-011 均分别执行朋友与朋友圈两种渠道。接收使用独立客户端或清理测试缓存后的会话，记录正常打开、标题、图片、参数与内容，不能仅以回调存在判为通过。

## 2. 逐页双渠道验收

- [x] AC-001 首页：朋友和朋友圈分享均形成有效卡片与入口；接收后公开首页；标题和图片有安全兜底。
- [x] AC-002 商品详情：朋友和朋友圈分享均形成有效卡片与入口；接收后同一 skuId，读取最新公开对象。
- [x] AC-003 商品列表：朋友和朋友圈分享均形成有效卡片与入口；接收后全部有效筛选及排序恢复，第一页加载。
- [x] AC-004 品牌列表：朋友和朋友圈分享均形成有效卡片与入口；接收后已生效关键词恢复，不跳全局搜索。
- [x] AC-005 品牌详情：朋友和朋友圈分享均形成有效卡片与入口；接收后同一 brandId，默认内容 Tab。
- [x] AC-006 证书列表：朋友和朋友圈分享均形成有效卡片与入口；接收后已生效关键词恢复，第一页加载。
- [x] AC-007 证书详情：朋友和朋友圈分享均形成有效卡片与入口；接收后同一 certificateId，图片或文件占位正确。
- [x] AC-008 门店信息：朋友和朋友圈分享均形成有效卡片与入口；接收后当前公开门店资料，不携带个人数据。
- [x] AC-009 分类：朋友和朋友圈分享均形成有效卡片与入口；接收后有效一级分类优先于旧本机状态。
- [x] AC-010 搜索：朋友和朋友圈分享均形成有效卡片与入口；接收后无词分享入口；有词恢复已提交关键词、scope 和 tab。
- [x] AC-011 发现/找砖：朋友和朋友圈分享均形成有效卡片与入口；接收后开始搜索按钮可用，TS/JS 行为一致。

## 3. 状态、安全与异常

- [x] AC-012 商品列表同时设置分类、品牌、关键词、规格、价格区间和排序，接收方逐项一致；从第二页发送仍从第一页读取，不恢复滚动、结果数组或发送时价格快照。
- [x] AC-013 参数往返覆盖中文、空格、百分号、连接符、空值、畸形百分号编码、未知键、非法 ID 和枚举；无白屏、无重复解码、无未知字段透传。实现设计记录关键词/query 上限及边界样例；超限按 business-flow.md §2 降级，标题与实际默认入口一致。
- [x] AC-014 发送方预置不同的最近搜索、收藏及测试会话数据，检查双渠道参数和图片均不携带这些数据；接收分享搜索前后最近搜索保持一致，用户随后主动搜索仍可写历史。
- [x] AC-015 覆盖数据未返回、空结果、图片 404/过期/不可渲染及网络失败；标题无空值占位文案，图片安全兜底，不请求原始大图。搜索首页卡片不显示历史内容。
- [x] AC-016 覆盖商品下架、品牌不可见、证书删除、分类失效、加载失败；详情不显示其他对象或非公开缓存，分类可降级到默认浏览，重试和返回可用。
- [x] AC-017 覆盖冷启动、热启动及朋友圈单页入口；不依赖发送者数据或前置页面栈。受平台限制的操作有可用替代入口，并记录限制与验证边界。
