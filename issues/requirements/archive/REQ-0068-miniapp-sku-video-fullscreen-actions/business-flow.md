# 业务流程

## 1. 主流程：视频全屏播放与长按菜单

```text
用户进入商品详情页
  |
  v
页面加载 SKU 媒体列表
  |
  +-- 无视频 ----------------------+
  |                                |
  |                                v
  |                        仅展示图片媒体能力
  |
  +-- 有视频
       |
       v
用户滑动到视频媒体项
       |
       v
展示视频播放控件与全屏入口
       |
       v
用户点击全屏入口
       |
       v
进入微信 video 支持的全屏播放态
       |
       v
用户长按视频
       |
       +-- 平台支持菜单/等价交互 -----> 展示操作菜单
       |                                  |
       |                                  +-- 转发给朋友 -> 复用商品详情分享 -> 返回/继续浏览
       |                                  |
       |                                  +-- 保存视频 -> 权限/下载/保存 -> 成功或失败提示
       |                                  |
       |                                  +-- 取消 -> 关闭菜单 -> 继续播放或停留全屏
       |
       +-- 平台不支持完全自定义 --------> 展示替代入口或记录 N/A 降级说明
```

## 2. 保存视频异常流程

```text
用户选择保存视频
  |
  v
检查视频 URL 与平台能力
  |
  +-- URL 不可下载 / 格式不支持 -> 提示“视频暂不可保存”
  |
  +-- 需要相册权限
        |
        +-- 用户授权 -> 下载到临时文件 -> 保存到相册
        |
        +-- 用户拒绝 -> 提示权限说明，不反复打扰
```

## 3. 与父需求 REQ-0044 的差异

| 项 | REQ-0044 已有能力 | REQ-0068 增强点 |
|---|---|---|
| 视频播放 | 用户主动播放、播放时轮播不自动切换、页面隐藏暂停 | 增加明确全屏入口和全屏态退出后的上下文保持 |
| 图片全屏 | 图片支持全屏预览和交互 | 视频全屏交互尽量对齐图片全屏长按操作理解 |
| 分享 | 商品详情页支持微信分享 | 视频全屏态可触发“转发给朋友”，复用商品详情分享路径 |
| 媒体保存 | 未定义视频保存 | 增加保存视频意图、权限、失败提示与平台降级 |
| 验收证据 | 商品详情页基础媒体验收 | 增加 DevTools / 真机 evidence、平台限制说明、`.ts` / `.js` 运行入口同步 |

## 4. 影响范围

| 领域 | 影响 |
|---|---|
| 小程序 | 商品详情页视频组件、全屏控制、长按菜单、保存视频、分享触发和埋点。 |
| API | 默认不影响；若后续需要签名下载 URL，需单独在 OpenSpec 阶段确认。 |
| 数据库 | 默认不影响。 |
| 对象存储 | 不放宽权限，不暴露 object key，仍使用后端安全媒体 URL。 |
| Web / 管理端 | 默认不影响。 |
| 测试 | 需要小程序静态测试、页面运行入口同步检查、DevTools / 真机 evidence。 |
