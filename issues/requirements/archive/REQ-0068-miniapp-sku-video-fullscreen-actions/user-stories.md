# 用户故事

## US-001 装修客户全屏查看视频

作为装修客户，我希望在商品详情页看到明确的视频全屏播放入口，以便更沉浸地查看瓷砖纹理、铺贴效果和空间表现。

验收要点：

- [ ] 当商品详情页存在视频媒体时，视频区域展示可感知的全屏入口。
- [ ] 点击全屏入口后，当前视频进入微信小程序支持的全屏播放态。
- [ ] 退出全屏后回到当前商品详情页和当前媒体上下文，不丢失 SKU 数据。

## US-002 设计师长按转发视频相关商品

作为设计师，我希望在视频全屏播放时长按唤起操作菜单，并选择“转发给朋友”，以便把当前 SKU 商品详情发给客户确认。

验收要点：

- [ ] 全屏态长按视频可唤起操作菜单或平台允许的等价交互。
- [ ] 菜单包含“转发给朋友”或微信原生等价入口。
- [ ] 转发路径保留当前 `skuId` 和分享来源参数，打开后回到对应商品详情页。
- [ ] 分享埋点失败不阻断微信分享。

## US-003 门店导购保存商品视频

作为门店导购，我希望在全屏播放视频时选择“保存视频”，以便把可公开的商品素材保存到相册用于后续沟通。

验收要点：

- [ ] 菜单包含“保存视频”或等价保存入口。
- [ ] 保存成功后展示明确成功提示。
- [ ] 权限拒绝、远程视频不可下载、格式不支持或平台限制导致失败时，展示明确失败提示。
- [ ] 保存失败不影响继续播放视频或浏览商品详情页。

## US-004 用户取消菜单操作

作为任意浏览用户，我希望长按菜单中可以选择“取消”，以便不执行转发或保存并继续观看视频。

验收要点：

- [ ] 点击“取消”后菜单关闭。
- [ ] 取消操作不触发分享、保存、页面跳转或异常退出全屏。
- [ ] 取消操作可记录为菜单动作埋点；埋点失败不影响用户操作。

## US-005 测试人员验证平台降级

作为测试人员，我希望需求明确微信平台能力限制和降级路径，以便在原生视频全屏态不支持自定义长按菜单时仍能给出可验收结论。

验收要点：

- [ ] OpenSpec / 实现阶段明确原生 `video` 全屏、长按、自定义菜单和保存视频的能力边界。
- [ ] 若全屏态无法自定义长按菜单，存在可发现的替代入口或明确 N/A 说明。
- [ ] 验收记录区分 DevTools、静态测试和真机结论，不把自动化静态检查写成真机通过。
