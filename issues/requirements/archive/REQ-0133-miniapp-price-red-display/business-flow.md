# 价格展示业务流程

## 展示流程

```text
进入首页／列表／搜索／详情／收藏
  → 获取既有商品数据（原 API 或本机收藏）
  → 判断商品是否可公开查看
      ├─ 不可查看 → 既有失效文案＋中性色（不显示历史金额为有效报价）
      └─ 可查看 → 按现有价格契约识别展示状态
          ├─ 有效正数金额 → 原格式金额＋独立价格红色
          └─ 无价／非正／无法识别 → 既有无价处理＋中性色
  → 参考价格／单位／门店确认说明使用辅助色
  → 数据更新时重新判定，清除旧颜色状态
```

## 输入与输出边界

输入沿用 `price_display`、既有公开可见状态及收藏失效状态。展示判断不新增价格计算、币种转换或 API 字段。不得用“字符串非空”替代有效金额判断，也不得基于本机缓存绕过公开可见状态。

输出为展示文案及价格状态对应样式。有效价格保留后端精度与分隔符；无价内容遵循既有处理，不在本需求建立新业务定价规则。

## 与关联能力的差异

本需求无父 REQ。复用 REQ-0049 的共享商品卡片与 REQ-0044 的详情能力，只统一价格颜色和展示状态，不修改商品数据、图片布局或交互流程。REQ-0134 的分享扩展独立推进。

## 失败与恢复

网络失败及加载中沿用页面既有状态，不用红色价格占位；刷新、分页复用、切换商品和收藏失效后需重新计算展示状态。测试通过受控数据覆盖有效→无价→有效与有效→失效路径。
