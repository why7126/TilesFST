# 价格展示用户故事

## US-001 浏览时快速识别参考金额

作为店主或选购客户，我希望在首页、商品列表、品牌商品列表与搜索结果中快速找到有效金额，以便比较瓷砖选项。

验收要点：有效金额及货币符号使用统一价格红色；各卡片密度保持一致；“参考价格”和单位保留辅助色。对应 FR-001、FR-003、FR-005；验收 AC-001、AC-002、AC-005。

## US-002 区分有价、无价与不可查看商品

作为浏览者，我希望“暂无”和失效商品信息与有效金额有明确区别，避免把占位信息或历史金额当作当前参考报价。

验收要点：仅可公开查看的正数金额使用红色；无价及失效状态使用中性色；数据切换后颜色同步更新。对应 FR-002、FR-003；验收 AC-003、AC-004、AC-006。

## US-003 在详情、推荐与收藏中获得一致体验

作为选型人员，我希望详情主价格、推荐价格与收藏价格遵循相同规则，且价格调整不会改变原有浏览、收藏和分享操作。

验收要点：独立价格节点均纳入；推荐区小字号及长金额保持可读；其他品牌和状态元素维持既有样式。对应 FR-003、FR-004、FR-005；验收 AC-005、AC-007、AC-008。
