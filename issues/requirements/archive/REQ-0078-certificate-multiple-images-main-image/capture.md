# 一句话

证书资料支持上传多张图片，并允许运营设置其中一张作为主图。

# 原始描述

证书允许上传多张图片，也支持设置主图

# 背景与关联

- 父需求：`REQ-0038-brand-certificate-management`
- 涉及端：管理端品牌证书新增/编辑弹窗、证书列表展示；公开 Web 或小程序证书展示需按后续范围评估
- 业务价值：支持一个证书资料包含多页图片、补充页或细节页，提升证书信息完整度；主图用于列表缩略图、卡片首图和默认预览入口
- 预期后续：需要评估后端数据模型、上传接口、MinIO 对象关联、主图字段、前端回显排序、公开端展示与测试夹具是否需要同步调整

# 待澄清

- [ ] 单个证书最多允许上传多少张图片，是否仅限图片还是继续兼容 PDF/文档类证书。
- [ ] 主图是否必选；未手动设置时是否默认第一张成功上传图片为主图。
- [ ] 删除主图时的兜底规则：自动切换下一张、阻止删除，还是要求用户重新选择。
- [ ] 多图排序是否需要支持拖拽或上下移动，公开端是否按同一顺序展示。
- [ ] 管理端列表、证书弹窗、小程序证书列表页是否都以主图作为缩略图。
- [ ] 上传大小、MIME Type、扩展名、对象存储前缀和签名 URL 策略是否沿用现有证书上传约束。
