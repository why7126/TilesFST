# Business Flow

## 1. 管理端新增证书流程

```text
后台运营
  |
  +-- 进入 /admin/brand-certificates
        |
        +-- 点击「新增证书」
              |
              +-- 填写品牌、证书名称、类型、编号、有效期等元数据
              |
              +-- 添加证书图片
                    |
                    +-- 第一张上传成功 -> 自动设为主图
                    +-- 继续上传图片 -> 保留当前主图
                    +-- 上传失败 -> 图片控件内展示错误，可重试
              |
              +-- 可选：点击非主图「设为主图」
                    |
                    +-- 新主图移动到第一位
                    +-- 原主图取消主图标记
              |
              +-- 保存证书
                    |
                    +-- 前端提交图片数组、is_main、sort_order
                    +-- 后端校验主图唯一性与上传文件引用
                    +-- 保存成功 -> fixed toast + 列表主图缩略图回显
```

## 2. 管理端编辑证书流程

```text
后台运营
  |
  +-- 在证书列表点击「编辑」
        |
        +-- 加载证书详情与图片列表
              |
              +-- 有主图 -> 主图排在第一位
              +-- 有图片但无主图 -> 按顺序兜底第一张为主图
              +-- 单文件 PDF -> 沿用 PDF 占位，图片多图区可为空
        |
        +-- 删除图片
              |
              +-- 删除非主图 -> 当前主图保持
              +-- 删除主图 -> 下一张或第一张剩余图片成为主图
              +-- 删除全部 -> 图片空状态
        |
        +-- 保存
              |
              +-- 图片顺序与主图标记持久化
              +-- 再次打开弹窗回显一致
```

## 3. 主图兜底规则

```text
当前图片列表：[A(main), B, C]

删除 B -> [A(main), C]
删除 A -> [B(main), C]
设置 C 为主图 -> [C(main), A, B]
删除 C -> [A(main), B]
删除全部 -> []
```

## 4. 与父需求差异

| 维度 | REQ-0038 品牌证书管理 | REQ-0078 多图与主图 |
|---|---|---|
| 文件形态 | 单个证书文件，支持图片或 PDF | 图片列表 + 唯一主图；PDF/文档兼容策略待设计确认 |
| 列表缩略图 | 单文件缩略图或 PDF 占位 | 优先展示主图缩略图，失败时占位 |
| 编辑弹窗 | 单文件上传与回显 | 多张图片上传、删除、设主图、排序回填 |
| 数据模型 | 证书记录持有文件字段 | 可能新增证书图片关联表或图片数组 Schema |
| 展示边界 | 管理端维护，前台展示控制 | 本期管理端为主，为公开端多图展示预留结构 |

## 5. 异常流程

### 5.1 上传非法文件

```text
选择文件
  |
  +-- MIME / 扩展名 / 大小不符合规则
        |
        +-- 后端返回业务错误
        +-- 控件内展示失败原因
        +-- 不写入图片列表
```

### 5.2 保存时主图状态异常

```text
保存证书
  |
  +-- 图片列表存在，但没有 is_main=true
        |
        +-- 前端保存前兜底第一张为主图
        +-- 后端二次校验并拒绝多主图或无主图异常 payload
```

### 5.3 主图加载失败

```text
证书列表加载
  |
  +-- 主图 URL 加载失败
        |
        +-- 展示稳定图片占位
        +-- 不出现破图或表格行高跳动
        +-- 预览入口提示证书图片暂时无法预览
```

## 6. 数据与安全边界

- 上传仍走后端 API 和对象存储适配层。
- 前端保存业务数据前必须拿到后端认可的文件引用。
- 对象存储 Key 不作为公开端可直接访问地址暴露。
- 删除图片默认解除业务关联，不触发对象存储物理删除。
- 旧单文件证书需要兼容展示或由后续 migration 设计转换。
