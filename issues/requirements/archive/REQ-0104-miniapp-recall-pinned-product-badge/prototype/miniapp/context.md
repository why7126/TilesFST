# 小程序原型策略

## 1. 原型范围

本需求为小程序商品卡片轻量标识增强，不需要新增页面。后续实现应在现有 `components/product-card/` 商品卡片结构内展示“置顶”标识。

## 2. 展示策略

```text
商品卡片
├─ 商品图片区域
│  └─ 左上角角标：置顶
└─ 商品信息
   ├─ 商品名称
   ├─ 品牌
   ├─ 规格
   └─ 参考价格
```

要求：

- 文案固定为“置顶”。
- 优先复用现有角标位置，避免新增复杂布局。
- 普通商品列表和搜索 SKU 结果中，后端字段为 true 时展示。
- 新品商品列表和热销商品列表不应用置顶逻辑，不展示“置顶”。
- 若同一普通列表商品同时具备置顶与新品 / 热销属性，优先展示“置顶”。

## 3. 视觉约束

- 标识应与现有深色卡片风格一致，使用低高度、小字号、近直角角标。
- 标识不得遮挡商品主图核心信息。
- 列表密度、紧凑卡片、搜索结果卡片中均需保持文字可读。
- 不新增弹窗、说明卡片、教学文案或排序控件。

## 4. 待实现阶段确认

- 响应字段命名与默认值。
- 现有商品卡片 `badge` 字段与“置顶 / 新品 / 热销”的优先级实现。
- 小程序 TS 与 JS 构建产物同步策略。
