# 业务流程

## 1. 主流程

```text
用户进入小程序商品列表 / 搜索 SKU 结果
  |
  v
小程序请求后端商品列表 API
  |
  v
后端按 REQ-0103 判断当前列表是否应用召回置顶逻辑
  |
  +-- 普通商品列表 / 搜索 SKU 结果
  |      |
  |      v
  |   后端计算实际生效的召回置顶商品
  |      |
  |      v
  |   API 返回商品顺序 + 置顶展示状态字段
  |      |
  |      v
  |   小程序商品卡片渲染“置顶”标识
  |
  +-- 新品商品列表 / 热销商品列表 / 其他不适用列表
         |
         v
      不应用置顶逻辑，API 不触发置顶展示
         |
         v
      小程序不展示“置顶”标识
```

## 2. 与父需求 REQ-0103 的差异

| 项 | REQ-0103 | REQ-0104 |
|---|---|---|
| 目标 | 让少量召回商品在普通列表和搜索 SKU 结果中优先排序。 | 让实际生效的置顶商品在小程序卡片上展示“置顶”标识。 |
| 事实源 | 后端排序层。 | 后端返回的置顶展示状态字段。 |
| 小程序职责 | 直接渲染后端返回顺序，不做本地重排。 | 根据后端字段展示或隐藏“置顶”标识，不做本地推断。 |
| 新品 / 热销 | 不应用置顶排序。 | 不展示“置顶”标识。 |
| 数据配置 | 复用 SKU 召回置顶排序值和有效期。 | 不新增运营配置。 |

## 3. 异常与边界流程

| 场景 | 期望行为 |
|---|---|
| 商品配置了召回排序值，但当前是新品榜或热销榜 | 不应用置顶逻辑，不展示“置顶”。 |
| 商品配置已过期或未到生效时间 | 不视为实际生效置顶，不展示“置顶”。 |
| 商品未进入少量置顶上限 | 按普通商品渲染，不展示“置顶”。 |
| 商品不满足当前筛选条件 | 不出现在列表中，也不涉及标识展示。 |
| API 缺少置顶字段 | 小程序默认不展示“置顶”，保持兼容。 |
| 加载更多合并分页 | 不做跨页重排，不遗留错误标识。 |
