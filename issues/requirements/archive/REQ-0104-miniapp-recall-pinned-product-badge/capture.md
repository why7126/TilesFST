# 一句话

微信小程序商品召回列表中的置顶商品需要展示“置顶”标识。

# 原始描述

小程序召回置顶商品展示“置顶”标识。

# 背景与关联

- 关联父需求：`REQ-0103-product-recall-list-pin-priority`
- 涉及端与模块：微信小程序商品列表 / 召回结果 / 置顶商品展示
- 业务价值：让用户在小程序列表中明确识别置顶商品，避免只看到排序变化却无法理解商品被优先展示的原因。
- 预期后续：明确标识样式、展示位置、仅召回列表生效还是所有置顶商品列表生效后，生成 PRD 并进入评审。

# 待澄清

- [ ] “置顶”标识展示在哪个区域：商品卡片标题旁、角标、标签区或列表排序信息区。
- [ ] 标识是否只在小程序召回列表展示，还是所有小程序商品列表中置顶商品都展示。
- [ ] 标识文案是否固定为“置顶”，是否需要区分运营置顶、召回置顶或推荐置顶。
- [ ] 标识是否需要与现有促销、标签、库存、品牌等信息共存，避免遮挡商品图或关键信息。

# 建议验收要点

- [ ] 小程序召回列表中被置顶的商品展示清晰的“置顶”标识。
- [ ] 非置顶商品不展示“置顶”标识。
- [ ] 标识不影响商品卡片主要信息、点击行为、列表滚动和既有排序逻辑。
- [ ] 当置顶状态取消或列表刷新后，标识状态与后端数据保持一致。
