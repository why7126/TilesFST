# REQ-0092 业务流程

## 1. 上传与生成流程

```text
运营人员选择品牌/证书图片
  ↓
管理端上传控件进入 uploading
  ↓
后端 uploads/media API 校验 MIME、大小、图片可读性
  ↓
原图写入 MinIO 单桶标准前缀
  ↓
图片处理器生成真实缩略图
  ├─ 成功：写入同源可追溯缩略图对象
  └─ 失败：记录失败原因，业务保存保留原图并标记可回退
  ↓
业务记录保存 object_key / media URL / 缩略图引用策略
  ↓
管理端同会话即时回显缩略图或文件卡片
```

## 2. 展示读取流程

```text
管理端 / 小程序 / 店主 Web 请求品牌或证书数据
  ↓
后端返回受控媒体 URL 或可解析 object_key
  ↓
小图场景优先请求缩略图
  ├─ 缩略图 200：展示缩略图
  ├─ 缩略图缺失/损坏：回退原图
  └─ 原图也失败：展示占位图或文件类型占位
  ↓
用户点击预览
  ↓
打开原图或原文件
```

## 3. 存量补齐流程

```text
管理员执行 dry-run
  ↓
脚本扫描品牌图片与证书图片对象
  ↓
输出待处理数量、跳过原因、风险提示
  ↓
管理员确认 apply
  ↓
脚本按批次生成缩略图
  ├─ 已有且有效：跳过
  ├─ 缺失：生成
  ├─ 异常输入：记录失败
  └─ 可重试对象：进入重试或下次 apply
  ↓
输出成功/失败/跳过/重试统计
```

## 4. 与父需求差异

| 关联需求 | 已有能力 | 本需求差异 |
|---|---|---|
| REQ-0005-brand-management | 品牌 Logo 上传、品牌列表、品牌编辑 | 本需求不改变品牌 CRUD，仅补齐品牌图片真实缩略图生成与小图读取策略。 |
| REQ-0038-brand-certificate-management | 证书图片/文件上传、证书列表、卡片、预览 | 本需求不改变证书业务字段，仅补齐图片类证书缩略图生成、回退和跨端消费策略。 |
| BUG-0100 | SKU 商品图片真实缩略图生成 | 本需求把已验证的缩略图能力扩展到品牌与证书图片，并补充存量补齐与跨端验收。 |

## 5. 关键业务规则

- 小图展示优先缩略图，大图预览优先原图或原文件。
- 缩略图失败不得阻断原图上传成功，但必须可观测、可回退。
- 前端不得拼接未授权对象存储地址，仍走后端受控媒体读取链路。
- 存量补齐必须 dry-run 先行，apply 可审计、可重入。
- PDF 首页渲染缩略图不在本需求范围；图片类证书缩略图在范围内。
