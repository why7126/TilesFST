# REQ-0092 用户故事

## US-001 品牌图片上传后生成真实缩略图

作为企业内部运营人员，我希望新增或编辑品牌 Logo、品牌封面等品牌图片后，系统自动生成真实缩略图，以便品牌列表和小图预览不再加载原图。

验收要点：

- 新上传品牌图片成功后，存在与原图可追溯的缩略图对象。
- 缩略图像素尺寸或文件体积明显低于原图，且不是原图 bytes 复制品。
- 上传失败、缩略图生成失败和缩略图读取失败都有明确回退，不阻断原图保存。

## US-002 证书图片上传后生成真实缩略图

作为企业内部运营人员，我希望新增或编辑证书图片后，系统自动生成真实缩略图，以便证书列表、卡片和默认主图展示更轻量。

验收要点：

- 图片类证书生成真实缩略图。
- PDF 或非图片证书继续使用文件类型占位或既有策略，不被错误当作图片处理。
- 证书预览仍可打开原图或原文件。

## US-003 管理端列表与卡片优先使用缩略图

作为管理端用户，我希望品牌列表、证书列表和证书卡片在小图区域优先使用缩略图，以便页面滚动和刷新更流畅。

验收要点：

- 品牌列表 Logo、证书列表封面、证书卡片默认图优先消费缩略图。
- 缩略图缺失时回退原图或占位图，不显示浏览器破图。
- 列表分页、筛选、行内操作和 toast 行为不因缩略图改造发生布局回归。

## US-004 小程序和店主 Web 展示端使用轻量资源

作为店主或公开访客，我希望小程序和店主 Web 中品牌与证书列表优先加载轻量缩略图，以便移动端访问更快，流量更低。

验收要点：

- 小程序品牌与证书列表、卡片、默认主图优先使用缩略图。
- 店主 Web 品牌与证书列表、卡片、默认主图优先使用缩略图。
- 大图预览和原文件查看仍使用原图或原文件。

## US-005 存量品牌与证书图片可审计补齐

作为管理员或运维人员，我希望对存量品牌图片和证书图片执行 dry-run / apply 形式的缩略图补齐，以便在不破坏历史数据的前提下完成媒体治理。

验收要点：

- dry-run 输出待处理对象数量、预计生成数量、跳过原因和风险提示。
- apply 输出成功、失败、跳过、重试统计，并支持重入。
- 输出不得泄露真实密钥、本机绝对路径、真实客户数据或 Authorization 信息。

## US-006 异常图片输入可控

作为测试人员，我希望系统对小图、横图、竖图、PNG 透明图、WebP、损坏图片和超大图片都有明确策略，以便缩略图能力可回归、可定位。

验收要点：

- 横图和竖图缩略图保持比例，不拉伸变形。
- PNG 透明图处理不产生明显黑底或白底误差，除非后续明确转码策略。
- 损坏图片、超大图片和非允许 MIME 按上传校验或缩略图失败策略处理。
