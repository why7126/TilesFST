# 用户故事

## US-001 装修客户从证书详情快速回到首页

作为装修客户，我从证书列表、品牌详情或分享路径进入证书详情后，希望能通过清晰的【返回首页】悬浮按钮回到首页，继续浏览品牌、分类和推荐商品。

验收要点：

- 证书详情页展示复用 `home-floating-button` 的首页入口。
- 点击后返回 `/pages/index/index`。
- 加载失败、空态或分享直达时仍有可恢复的回首页路径。

## US-002 设计师在资质浏览后切换资料路径

作为设计师，我查看某张证书后，希望不必逐级返回，就能回到首页切换其他品牌、商品或资料入口。

验收要点：

- 悬浮按钮在证书详情正常态可见且可点击。
- 返回首页不破坏证书详情原有左上返回能力。
- 连续点击不会产生重复跳转或异常页面栈。

## US-003 门店导购保持演示操作一致

作为门店导购，我希望证书详情页和商品详情页、品牌详情页的回首页入口位置一致，这样给客户演示时不需要记忆不同页面的操作差异。

验收要点：

- 证书详情页按钮默认使用 `offset="list"`。
- 视觉、触控反馈和失败兜底复用现有 `home-floating-button`。
- 按钮不遮挡证书主图、品牌入口或错误态按钮；证书信息字段被按钮局部覆盖可接受。

## US-004 测试人员统一验证小程序深层页面导航

作为测试人员，我希望用既有组件、统一 offset 和导航 best practice 验收证书详情页，避免新增页面私有样式或遗漏分享直达返回场景。

验收要点：

- 页面组件声明、WXML 挂载和 `.ts` / `.js` 同步通过静态检查。
- DevTools 320 / 375 / 430 pt 截图或摘要确认品牌入口同宽、证书信息非避让排版和按钮位置一致。
- 按小程序自定义导航 best practice 覆盖页面栈返回兜底和分享直达回首页。
