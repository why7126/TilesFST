# 验收标准

## 功能 AC

- [ ] AC-001 小程序首页不展示返回首页悬浮按钮。
- [ ] AC-002 搜索结果页、分类列表页、分类商品列表页、品牌列表页、品牌详情页、证书列表页、收藏列表页、商品详情页等主要非首页业务页面展示统一返回首页悬浮按钮。
- [ ] AC-003 登录页、授权页、错误页、全屏视频页、图片预览页等特殊页面在 `/req-opsx` 阶段明确展示或豁免理由。
- [ ] AC-004 点击悬浮按钮后可快速进入小程序首页。
- [ ] AC-005 返回首页过程不出现空白页、死循环跳转、重复堆叠首页或多次连续跳转。
- [ ] AC-006 首页为 TabBar 页面时，导航策略必须使用 `wx.switchTab` 或项目确认的等价方式；首页非 TabBar 或需重置页面栈时，必须明确 `wx.reLaunch` 或等价策略。
- [ ] AC-007 分享直达、收藏入口或外部入口进入深层页面时，悬浮按钮仍可用，且无页面栈时可安全回首页。
- [ ] AC-008 页面加载、空态、错误态、网络失败状态下，悬浮按钮展示策略清晰，不阻断当前页面恢复或重试。
- [ ] AC-009 首页路径不可达或导航 API 返回失败时，页面保持在当前页并可恢复，不进入异常空白页。
- [ ] AC-010 连续点击悬浮按钮时，系统通过防抖、状态锁或等价策略避免重复触发。

## UI AC

- [ ] AC-011 悬浮按钮视觉延续小程序“工业石材 · 暗色旗舰风”，图标或短文案具备明确首页语义。
- [ ] AC-012 悬浮按钮在覆盖页面中的位置、尺寸、触控热区、按压反馈和视觉层级保持一致。
- [ ] AC-013 按钮触控热区不小于 44x44 pt 或项目确认的等价标准。
- [ ] AC-014 320/375/430 pt 常见视口下，按钮不遮挡商品图片、商品价格、品牌信息、筛选入口、列表内容、空态按钮或主 CTA。
- [ ] AC-015 商品详情页如存在底部咨询、收藏、分享、询价或其他固定操作区，悬浮按钮必须避让，不覆盖底部安全区。
- [ ] AC-016 品牌列表页、品牌详情页、分类列表页、分类商品列表页、证书列表页、收藏列表页和搜索结果页中，悬浮按钮不得遮挡列表加载更多、筛选栏、Tab、横向滚动区、底部 TabBar 或页面主要内容。
- [ ] AC-017 页面滚动时按钮保持稳定，不因内容加载、图片懒加载或列表分页发生跳动。
- [ ] AC-018 如页面存在客服、分享或咨询悬浮入口，必须在设计和验收中明确避让、合并或隐藏策略。
- [ ] AC-019 原型 `prototype/miniapp/home-floating-button.html` 可在 Chromium、Chrome 和 Safari 移动端模式直接预览；PNG Golden Reference 待后续导出。

## 小程序导航与设备 AC

- [ ] AC-020 遵守 `docs/knowledge-base/best-practices/miniapp-custom-navigation.md`，验收状态栏、安全区、微信原生胶囊 reserve、页面 offset 和返回/首页兜底。
- [ ] AC-021 不自绘模拟微信分享按钮、关闭按钮或系统胶囊，不把悬浮按钮放入原生胶囊区域。
- [ ] AC-022 DevTools 320/375/430 pt evidence 覆盖首页隐藏、搜索结果页显示、分类列表页显示、分类商品列表页显示、品牌列表页显示、品牌详情页显示、证书列表页显示、收藏列表页显示、商品详情页显示和至少一个错误态。
- [ ] AC-023 真机 evidence 至少覆盖 iPhone 刘海屏、iPhone 非刘海屏或 Android 常见机型中的可用设备；真机不可用时标记 blocked 或 follow_up，不得写作真机通过。
- [ ] AC-024 evidence 记录不得包含本机绝对路径、token、Cookie、Authorization header、`.env` 内容、真实密钥、数据库 DSN、MinIO 凭据或真实客户数据。

## 非功能 AC

- [ ] AC-025 悬浮按钮组件应统一封装或统一配置，避免多个页面复制不同的样式和跳转逻辑。
- [ ] AC-026 接入悬浮按钮不得引入额外接口请求，不影响页面首屏数据加载。
- [ ] AC-027 悬浮按钮资源应使用小程序可控本地图标、字体图标或项目确认资源，不依赖未授权外链。
- [ ] AC-028 不新增管理端配置、Web 展示端能力、数据库字段或后端 API。
- [ ] AC-029 若后续实现发现必须调整小程序页面结构、TabBar、路由配置或全局组件架构，必须在 OpenSpec Change 中明确影响范围和回归策略。
