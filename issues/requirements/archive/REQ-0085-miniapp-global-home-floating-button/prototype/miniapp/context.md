# 原型说明

## 原型目标

- 表达首页不展示返回首页悬浮按钮。
- 表达非首页主要业务页面右下侧展示统一悬浮按钮。
- 表达悬浮按钮避让底部安全区、TabBar、固定操作区和页面核心内容。
- 表达按钮点击后的“返回首页”语义，不替代真实小程序路由实现。

## 页面状态

| 状态 | 原型表达 |
|---|---|
| 首页 | 页面底部仅保留 TabBar，不展示悬浮按钮。 |
| 商品详情页 | 页面右下侧展示圆形首页按钮，并上移避让底部固定操作区。 |
| 分类列表页 | 页面右下侧展示圆形首页按钮，并避让列表加载更多和底部安全区。 |
| 错误态 | 页面可展示错误提示，同时保留返回首页入口。 |

## 视觉策略

- 按钮使用深色半透明底、品牌金首页图标或短文字，保持“工业石材 · 暗色旗舰风”基调。
- 按钮触控热区按不小于 44x44 pt 表达。
- 按钮固定在右下侧，默认距离右侧 16 pt，距离底部安全区或固定操作区至少 16 pt。
- 若页面存在底部商品操作条，按钮需上移，不覆盖主 CTA。

## 非目标

- 不作为最终 WXML / WXSS 代码。
- 不验证真实小程序安全区、胶囊或设备差异。
- 不确认最终图标资产、动画、阴影和路由 API。
- 不新增 Web、管理端或后端能力。

## 后续实现提示

- `/req-opsx` 阶段需确认首页路径是否为 TabBar 页面。
- 若首页为 TabBar 页面，优先使用 `wx.switchTab` 或项目确认等价策略。
- 若需要清理页面栈，必须说明为何使用 `wx.reLaunch`。
- 接入页面清单和例外页面清单必须进入 Change 设计与验收。
