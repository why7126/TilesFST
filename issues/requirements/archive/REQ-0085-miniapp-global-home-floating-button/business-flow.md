# 业务流程

## 1. 用户导航流程

```text
用户进入小程序
  |
  +-- 当前页面是首页
  |     |
  |     +-- 不展示返回首页悬浮按钮
  |
  +-- 当前页面是非首页业务页面
        |
        +-- 判断页面是否在例外清单
        |     |
        |     +-- 是 -> 不展示按钮或使用页面专属策略
        |     |
        |     +-- 否 -> 展示统一返回首页悬浮按钮
        |
        +-- 用户浏览、滚动、筛选、分享或加载更多
        |
        +-- 用户点击悬浮按钮
              |
              +-- 首页为 TabBar 页面 -> wx.switchTab 或项目确认等价策略
              |
              +-- 首页非 TabBar 或需重置页面栈 -> wx.reLaunch 或项目确认等价策略
              |
              +-- 导航失败 -> 保留当前页 + 可恢复提示
```

## 2. 页面覆盖判定流程

```text
小程序页面接入悬浮按钮组件
  |
  +-- 识别页面类型
        |
        +-- 首页 / 首页 Tab -> hide
        +-- 搜索结果页 -> show
        +-- 分类商品列表页 -> show
        +-- 品牌详情页 -> show
        +-- 商品详情页 -> show
        +-- 登录 / 授权 / 全屏预览 / 特殊流程 -> review exception
```

## 3. 异常流程

### 3.1 连续点击

```text
用户连续点击悬浮按钮
  |
  +-- 第一次点击进入 navigating
  |
  +-- 后续点击被防抖或忽略
  |
  +-- 跳转成功后恢复默认状态
```

### 3.2 首页路径不可达

```text
首页路径配置异常或导航 API fail
  |
  +-- 停留当前页
  |
  +-- 展示短提示或静默恢复
  |
  +-- 不清空页面内容、不进入空白页
```

### 3.3 页面状态特殊

```text
页面加载中 / 空态 / 错误态 / 网络失败
  |
  +-- 页面允许用户离开 -> 按钮可用
  |
  +-- 页面存在不可中断操作 -> 按钮隐藏或禁用，并说明实现理由
```

## 4. 与父 REQ 差异

本需求暂无父需求，是小程序跨页面导航增强能力。它与既有品牌、类目、商品详情需求的关系如下：

| 维度 | 既有页面需求 | REQ-0085 |
|---|---|---|
| 目标 | 完成具体页面的信息展示与跳转 | 提供跨页面快速回首页入口 |
| 终端 | 微信小程序页面局部能力 | 微信小程序全局导航辅助能力 |
| 覆盖 | 品牌、类目、商品、搜索等单页能力 | 多个非首页页面统一接入 |
| 主要风险 | 页面信息完整、接口数据正确 | 安全区、遮挡、页面栈、特殊页面例外 |

## 5. UI 与原型策略

- 原型位于 `prototype/miniapp/`，包含 HTML 静态原型和上下文说明。
- 原型表达按钮在首页隐藏、非首页显示、底部安全区避让和详情页固定操作区避让。
- 后续实现需结合真实小程序页面路径、TabBar 配置和首页路由确定导航 API。
- 小程序验收应引用 `docs/knowledge-base/best-practices/miniapp-custom-navigation.md`，重点覆盖安全区、胶囊、返回/首页兜底和 DevTools/真机 evidence。
