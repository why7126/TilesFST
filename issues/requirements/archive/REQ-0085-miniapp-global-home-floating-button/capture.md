# 一句话

微信小程序除首页外新增全局悬浮按钮，用户可在各业务页面快速返回首页。

# 原始描述

小程序：新增主页全局悬浮按钮（除了首页不加），支持快速返回首页。

# 背景与关联

- 涉及端：微信小程序。
- 业务价值：用户从搜索结果、分类列表、品牌详情、商品详情等深层页面浏览后，可快速回到首页，提高跨页面导航效率。
- 页面边界：首页不展示该悬浮按钮；其他页面默认展示，除非后续评审明确例外。

# 待澄清

- [ ] 悬浮按钮图标、文案、位置和样式是否沿用现有小程序视觉规范。
- [ ] 返回首页使用 `switchTab`、`reLaunch` 还是其他导航方式，是否需要保留页面栈。
- [ ] 哪些特殊页面需要例外，例如登录页、授权页、全屏视频页、图片预览页、错误页。
- [ ] 是否需要规避底部 TabBar、客服按钮、分享按钮、表单提交按钮等已有固定元素。

# 建议验收要点

- [ ] 小程序首页不展示返回首页悬浮按钮。
- [ ] 搜索结果页、分类商品列表页、品牌详情页、商品详情页等非首页页面展示返回首页悬浮按钮。
- [ ] 点击悬浮按钮后能快速返回首页，且不会进入异常空白页或重复堆叠首页。
- [ ] 悬浮按钮不遮挡页面主要内容、底部操作区和系统安全区域。
- [ ] 不影响页面原有滚动、分享、收藏、筛选、加载更多等交互。
