# 业务流程

## 1. 新增类目主流程

```text
后台用户打开类目管理页
  |
  v
点击「新增类目」
  |
  v
系统打开新增类目弹窗
  |-- 上级类目：沿用既有规则
  |-- 类目名称：必填，中文/英文/数字，最多 15 个字符
  |-- 排序权重：沿用既有正整数规则
  |-- 类目描述 / 状态：沿用既有规则
  |
  v
用户输入 1-15 字符类目名称并点击「保存类目」
  |
  +-- 前端校验失败 --> 字段下方展示错误，弹窗保持打开
  |
  +-- 前端校验通过
        |
        v
      POST /api/v1/admin/tile-categories
        |
        |-- 后端校验名称长度 <= 15
        |-- 后端继续校验字符集、同层级唯一、层级、排序权重
        |
        +-- 成功 --> 关闭弹窗，刷新类目树 / 列表 / 统计
        |
        +-- 失败 --> 返回统一 envelope，弹窗展示字段级或表单级错误
```

## 2. 编辑类目主流程

```text
后台用户在类目行点击「编辑」
  |
  v
系统打开编辑类目弹窗
  |-- 回显既有类目名称
  |-- 允许把名称修改为 1-15 个字符
  |-- 不改变编码、上级类目、层级和排序权重既有规则
  |
  v
用户保存
  |
  +-- 名称长度 16 字符或以上 --> 前端字段级错误
  |
  +-- 名称长度 1-15 字符
        |
        v
      PUT /api/v1/admin/tile-categories/{id}
        |
        +-- 后端校验通过 --> 更新名称，刷新类目树 / 列表 / 统计
        |
        +-- 后端校验失败 --> 弹窗保持打开，展示可读错误
```

## 3. 展示回归流程

```text
测试或验收准备 15 字符类目样例
  |
  +--> 管理端类目列表：名称列 + 编码副行不重叠
  |
  +--> 管理端类目树：层级缩进 + 数量徽标不重叠
  |
  +--> 小程序分类页：分类入口不撑破容器
  |
  +--> Web 展示端分类 / 筛选入口：文字不重叠、不遮挡操作
```

## 4. 异常与兜底流程

| 场景 | 前端行为 | 后端兜底 | 推荐提示 |
|---|---|---|---|
| 类目名称为空 | 阻止保存 | 拒绝 | 类目名称不能为空 |
| 类目名称 1-15 字符 | 允许保存 | 接受并继续其他规则校验 | - |
| 类目名称 16 字符或以上 | 阻止保存 | 拒绝 | 类目名称最多 15 个字符 |
| 类目名称含空格或符号 | 沿用既有前端拦截 | 沿用既有拒绝规则 | 类目名称只能包含中文、英文和数字 |
| 同层级名称重复 | 可选前端预检；保存后处理 API 错误 | 沿用既有拒绝规则 | 同一层级下已存在同名类目 |
| API envelope 异常 | 展示表单级错误 | 返回稳定错误码和 message | 保存失败，请重试 |

## 5. 与父需求 / 相关需求差异

| 维度 | REQ-0005 基线 | REQ-0067 当前规则 | REQ-0077 调整 |
|---|---|---|---|
| 类目名称长度 | 1-30 字符 | 最多 10 个字符 | 最多 15 个字符 |
| 类目名称字符集 | 未明确限制 | 仅中文、英文、数字 | 不变 |
| 同层级唯一 | 主要约束编码唯一 | 同一上级类目下名称唯一 | 不变 |
| 类目编码 | 用户填写编码 | 后端自动生成编码 | 不变 |
| 弹窗宽度 / 样式 | 类目弹窗基线 | 沿用 `CategoryFormModal` | 不变，仅回归宽度和矮视口滚动 |
| 展示端 | 类目树 / 列表 / 前台分类 | 不直接调整小程序 | 增加 15 字符展示兼容回归 |

## 6. 系统边界

- Web 管理端：调整 `CategoryFormModal` 类目名称长度校验、错误提示、测试样例，并回归类目树 / 列表展示。
- Backend/API：调整创建 / 更新类目名称长度校验，确保 15 字符可通过、16 字符被拒绝。
- OpenAPI/Orval：如 schema 暴露 `maxLength`，必须同步生成。
- 数据库：确认 `tile_categories.name` 支持至少 15 字符；如已有约束小于 15，后续 Change 必须包含迁移。
- 小程序 / Web 展示端：不新增能力，只使用 15 字符样例回归布局。
