# 用户故事

## US-001 用户进入品牌列表页时快速理解页面定位

作为装修业主，我希望进入小程序品牌页后先看到清晰的页面标题和品牌氛围区，以便快速确认这里是按品牌浏览瓷砖商品的入口。

验收要点：

- 页面标题展示为“品牌”。
- 顶部导航避让状态栏和微信原生胶囊，不遮挡标题和返回按钮。
- Hero 区展示“BRAND GALLERY”“全球严选瓷砖品牌”等品牌氛围文案或确认后的等价文案。
- Hero 区与下方品牌矩阵保持清晰层级和稳定间距。

## US-002 用户扫读品牌矩阵时识别品牌与商品规模

作为室内设计师，我希望品牌矩阵中的每张卡片都清楚展示品牌标识、品牌名称和商品数量，以便快速判断品牌是否值得进一步介绍给客户。

验收要点：

- 品牌矩阵标题展示为“品牌矩阵”，不展示“按类目快速识别”辅助提示。
- 每张品牌卡片只展示一个品牌。
- 品牌上行展示 Logo 或首字母占位、品牌名称、商品数量和进入指示。
- 长品牌名、无 Logo、商品数量为 0 时仍保持卡片结构稳定。

## US-003 用户按品牌类目进入对应商品列表

作为对某一类瓷砖感兴趣的用户，我希望在品牌卡片下方直接点击类目标签，以便查看该品牌下对应类目的商品列表。

验收要点：

- 卡片下行不展示“全部类目 · 点击查看该品牌下的类目商品”等说明文案。
- 末级类目以胶囊标签展示，重复类目去重。
- 类目胶囊字号比品牌名称小 2rpx，移动端可清晰扫读。
- 类目标签点击携带 `brandId` 与 `categoryId` 进入商品列表页。
- 点击类目标签不会触发品牌详情页跳转。

## US-004 用户进入品牌详情页时不被类目入口干扰

作为门店销售，我希望点击品牌卡片上方品牌信息区域时稳定进入品牌详情页，以便向客户展示品牌主页，不被下方类目标签误导或误触。

验收要点：

- 品牌上行信息区作为独立品牌入口。
- 点击品牌 Logo、名称、商品数量或进入指示进入品牌详情页。
- 品牌入口和类目入口都有可感知的按压反馈。
- 品牌入口与类目入口事件边界清晰，连续点击不串跳。

## US-005 产品团队验证新版小程序视觉稿落地

作为产品团队，我希望根据附件原型和截图检查页面视觉、导航、安全区和底部 TabBar，以便评审时确认实现不会偏离新版设计方向。

验收要点：

- `prototype/miniapp/prototype.html` 作为后续实现和验收参考。
- DevTools 至少覆盖 320、375、390、430 pt 视口。
- 真机不可用时必须标记 `blocked` 或 `follow_up`，不得写作真机通过。
- 验收 evidence 不记录真实客户数据、密钥、token、Cookie 或本机绝对路径。
