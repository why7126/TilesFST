# 业务流程

## 1. 总流程

```text
用户打开微信小程序
  |
  v
进入品牌 Tab / 品牌列表页
  |
  +-- 自定义导航
  |       |
  |       +-- 状态栏安全区 / 标题“品牌” / 返回入口 / 微信胶囊 reserve
  |
  +-- 品牌氛围 Hero
  |       |
  |       +-- 展示品牌主题文案，保持既有品牌页能力兼容
  |
  +-- 品牌矩阵
          |
          v
    加载公开品牌聚合数据
          |
          +-- 加载成功
          |       |
          |       v
          |  渲染单品牌卡片
          |       |
          |       +-- 上行品牌入口 → 品牌详情页
          |       |
          |       +-- 下行类目标签 → 品牌 + 类目商品列表页
          |
          +-- 无品牌 / 无商品 / 无类目
          |       |
          |       v
          |  展示对应空态与兜底样式
          |
          +-- 网络失败 / 接口失败
                  |
                  v
             错误态 / 重试 / 下拉刷新
```

## 2. 品牌卡片数据处理流程

| 步骤 | 输入 | 处理 | 输出 |
|---|---|---|---|
| 1 | 品牌公开数据 | 过滤未公开、禁用或不可访问品牌 | 可展示品牌集合 |
| 2 | 品牌基础信息 | 读取品牌名称、Logo、排序和公开状态 | 品牌卡片上行基础信息 |
| 3 | 品牌 Logo | 成功时展示图片；缺失或失败时取品牌首字母 / 缩写 / 统一占位 | 稳定品牌标识 |
| 4 | 品牌关联公开商品 | 按小程序公开可见商品统计 | `productCount` |
| 5 | 商品绑定类目路径 | 取每个商品实际绑定路径最后一层 | 原始末级类目集合 |
| 6 | 原始末级类目集合 | 去重并按稳定排序输出，保留 `categoryId` 与 `categoryName` | `leafCategories[]` |
| 7 | 品牌与类目聚合数据 | 渲染品牌矩阵卡片 | 上行品牌入口 + 下行类目标签 |

## 3. 点击与跳转流程

```text
用户点击品牌卡片
  |
  +-- 点击上行品牌入口
  |       |
  |       +-- 品牌可公开访问 → navigateTo 品牌详情页
  |       |
  |       +-- 品牌不可访问 / 参数缺失 → 阻止无效跳转并提示
  |
  +-- 点击下行类目标签
          |
          +-- brandId + categoryId 有效 → navigateTo 商品列表页并携带筛选参数
          |
          +-- 参数缺失 → 阻止无效跳转并提示
```

## 4. 页面状态流程

| 场景 | 页面行为 | 用户感知 |
|---|---|---|
| 首次加载 | 保持导航、Hero 和底部 TabBar 框架稳定，品牌矩阵展示加载态 | 页面有反馈，不白屏 |
| 加载成功 | 展示品牌卡片、商品数量、类目标签和进入指示 | 可按品牌或类目继续浏览 |
| 品牌无 Logo | 展示品牌首字母或统一占位 | 品牌仍可识别，不出现破图 |
| 品牌无公开商品 | 商品数量展示 0，类目区展示空态或留空说明 | 不误以为接口异常 |
| 类目很多 | 类目标签自动换行，卡片高度自然增长 | 可完整查看全部类目 |
| 网络失败 | 展示错误文案和重试能力 | 可恢复浏览 |

## 6. 非目标流程

- 不进入管理端品牌新增、编辑、Logo 上传、上下架或排序流程。
- 不修改品牌详情页内部结构。
- 不重构商品列表页自身视觉。
- 不修改类目层级、商品绑定类目或后台类目排序规则。
- 不新增品牌搜索、筛选、收藏、询价或下单流程。
- 不新增 Web 展示端或管理端品牌列表页。
