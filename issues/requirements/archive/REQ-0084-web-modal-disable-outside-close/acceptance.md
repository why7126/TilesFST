# 验收标准

## 功能 AC

- [ ] AC-001 Web 端管理端标准 Dialog / Modal 点击遮罩或弹窗外空白区域时不自动关闭。
- [ ] AC-002 Web 展示端标准 Dialog / Modal 点击遮罩或弹窗外空白区域时不自动关闭。
- [ ] AC-003 表单弹窗外部点击后，已输入字段、已选择项、上传状态和弹窗滚动位置保持不变。
- [ ] AC-004 确认弹窗外部点击后仍保持打开，用户必须通过明确的取消或确认按钮结束本次确认。
- [ ] AC-005 详情、预览类弹窗外部点击后仍保持打开，弹窗内滚动、图片切换和链接点击不受影响。
- [ ] AC-006 每个可关闭弹窗均存在可见、可点击、语义明确的关闭入口，例如取消按钮、关闭图标或业务完成后的关闭路径。
- [ ] AC-007 保存成功、确认成功等业务完成场景继续沿用现有关闭逻辑；保存失败、确认失败或上传失败时弹窗保持打开并展示错误反馈。
- [ ] AC-008 统一 Dialog / Modal 封装如存在，默认禁用外部点击关闭；页面级例外必须在 OpenSpec Change 中列出组件、原因和验收方式。
- [ ] AC-009 历史未复用统一弹窗组件的 Web 弹窗在实现阶段完成盘点，并补齐外部点击不关闭策略。
- [ ] AC-010 Esc 键关闭策略在评审阶段明确；未明确前不得把 Esc 键行为作为本需求已验收范围。
- [ ] AC-011 Popover、Dropdown、Tooltip、Select 下拉层、日期选择器等轻量浮层默认不纳入本需求；如纳入必须补充例外清单和专门验收。
- [ ] AC-012 前端自动化测试至少覆盖一个表单弹窗和一个确认弹窗：触发外部点击后弹窗仍在文档中且关键输入状态保留。
- [ ] AC-013 明确关闭入口测试覆盖取消、关闭图标或等价入口，确保禁用外部点击后不会形成无法退出的弹窗。
- [ ] AC-014 禁用外部点击关闭不得引起遮罩穿透、页面滚动异常、焦点丢失、弹窗跳动或按钮不可点击。
- [ ] AC-015 管理端实现继续使用 Design System semantic token 和既有组件封装，不新增裸 Hex 或独立弹窗视觉体系。

## 横切 AC（knowledge-base）

> 来源：`docs/knowledge-base/best-practices/admin-modal-width-css-cascade.md`、`docs/knowledge-base/best-practices/admin-media-upload-chain.md` — 预防 Sprint 002/003/013 复发类缺陷

- [ ] AC-XCUT-001 管理端弹窗 TSX 中不得同时挂载 `modal-card` 与 `{feature}-modal-card` 等专属类；若本需求改造触及弹窗 DOM class，必须验证无双类并存。
- [ ] AC-XCUT-002 管理端宽弹窗或窄弹窗的 computed width 必须在 1440px 视口验收，结果与既有 SKU / 设计规格一致，不仅检查源 CSS。
- [ ] AC-XCUT-003 管理端弹窗相关测试需覆盖可能冲突的 admin CSS 栈，确认目标弹窗宽度不被通用 `.modal-card` 规则覆盖。
- [ ] AC-XCUT-004 矮视口场景下弹窗 body 可滚动，禁用外部点击关闭后不得导致表单底部按钮、上传控件或关闭入口不可达。
- [ ] AC-XCUT-005 涉及上传控件的弹窗必须覆盖上传状态机 `idle → uploading → done/failed`，外部点击不关闭不得打断状态流转。
- [ ] AC-XCUT-006 涉及上传控件的弹窗必须验证同会话即时回显：上传成功后缩略图、文件卡片或已上传状态在弹窗内立即可见。
- [ ] AC-XCUT-007 涉及上传控件的弹窗必须验证失败态在控件附近展示，用户可重试或取消，失败不得只依赖全局 toast。
- [ ] AC-XCUT-008 若实现触及上传链路，必须经 `http://localhost:3000` 的 Docker Web 边界验收上传文件，不得只用后端 `:8000` 直连验证；若本 Change 仅修改弹窗关闭策略且不改上传链路，可标记为 N/A — 未触及上传传输、后端、Nginx 或对象存储边界。
- [ ] AC-XCUT-009 若弹窗内无上传控件，本需求对应上传横切项可标记为 N/A — 该弹窗不涉及媒体选择、上传、回显或保存。

## 验收证据建议

| 证据 | 要求 |
|---|---|
| 单元 / 组件测试 | 覆盖外部点击不关闭、明确关闭入口可关闭、表单状态保留。 |
| 手工或 Playwright 验证 | 覆盖管理端典型表单弹窗、确认弹窗、展示端详情或预览弹窗。 |
| CSS 验收 | 管理端弹窗 computed width、矮视口滚动和关闭入口可达。 |
| 上传验收 | 仅在触及上传控件或上传链路时执行 Docker `:3000` 边界验证。 |
