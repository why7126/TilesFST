# 一句话

Web 端（电脑端）所有弹窗取消“点击空白区域自动关闭”，避免误触导致编辑内容或确认流程中断。

# 原始描述

Web端（电脑端）：所有弹窗取消点击空白区域自动关闭。

# 背景与关联

- 涉及端：Web 端（电脑端），包括管理端和展示端中使用弹窗的页面。
- 业务价值：减少用户编辑 SKU、品牌、类目、证书、Banner 等资料时因误点遮罩或空白区域导致弹窗关闭、输入中断或数据丢失。
- 交互边界：弹窗仍应保留明确关闭入口，例如取消按钮、关闭图标或完成操作后的关闭。

# 待澄清

- [ ] “所有弹窗”是否包含确认弹窗、图片预览弹窗、下拉菜单/Popover/Tooltip 等轻量浮层。
- [ ] 点击 Esc 键是否也需要禁止关闭，或仅禁用鼠标点击空白区域关闭。
- [ ] 表单有未保存改动时，点击取消或关闭图标是否需要二次确认。
- [ ] 是否需要制定 Design System 级 Dialog 默认配置，后续所有新弹窗默认继承。

# 建议验收要点

- [ ] Web 端所有标准弹窗点击遮罩或弹窗外空白区域时不自动关闭。
- [ ] 用户仍可通过明确的取消、关闭、保存成功等路径关闭弹窗。
- [ ] 表单弹窗、确认弹窗、详情弹窗均遵循一致策略，除非评审明确例外。
- [ ] 弹窗内交互、滚动、上传、选择器等功能不受影响。
- [ ] 新增或复用弹窗组件时默认遵循该关闭策略。
