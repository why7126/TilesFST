# Prototype 策略

本需求是跨端媒体规格消费矩阵治理，不新增 Web 管理端、店主 Web 或微信小程序 UI，因此不需要 HTML / PNG 原型。

后续若基于本矩阵实现具体页面修正，应由对应 Change 或子需求按实际端侧范围补充原型或截图验收：

- Web 管理端列表、弹窗或上传回显变更：遵守 `rules/ui-design.md` 与命中的 knowledge-base 横切 AC。
- 小程序商品详情、证书详情或列表展示变更：补充 DevTools、真机或体验版截图证据。
- 店主 Web 展示端接入真实页面时：先从预留规范转为真实页面矩阵，再按页面设计要求验收。
