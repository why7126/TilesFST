# 业务流程

## 1. 总体流程

```text
用户打开页面
  |
  v
Web / 小程序端记录页面进入时间
  |
  v
关键生命周期、接口、资源或首屏节点完成
  |
  v
端侧生成脱敏性能事件
  |
  v
采样 / 节流 / 批量缓冲
  |
  v
POST 性能上报接口
  |
  v
后端 Schema 校验与敏感字段拦截
  |
  v
写入性能事件存储
  |
  v
聚合 P50 / P75 / P95 / P99、慢页面排行、版本对比
  |
  v
管理端性能观测或研发排障查询
```

## 2. Web 端流程

```text
路由进入 / 页面加载
  |
  +--> 采集 Navigation Timing / 自定义首屏节点
  |
  +--> 记录首屏关键 API 耗时
  |
  +--> 记录关键资源耗时或受控资源 key
  |
  +--> 生成 RUM event: web_admin / web_catalog + page_key + metric
  |
  +--> 按采样策略上报；失败则静默降级
```

Web 管理端和店主展示端必须区分 `client_type`，不得把管理端页面性能数据暴露给未授权公开端用户。

## 3. 微信小程序流程

```text
App / 页面进入
  |
  +--> 标记 route_start、onLoad、onShow、onReady
  |
  +--> 标记首个关键业务接口完成
  |
  +--> 标记首屏渲染就绪或页面可交互
  |
  +--> 生成 RUM event: wechat_miniapp + page_key + metric
  |
  +--> 批量或节流上报；失败则不影响页面主流程
```

小程序端不得依赖 Web 浏览器专属 API；涉及网络类型、设备类别等字段时使用小程序可用能力，并做最小化归类。

## 4. 后端处理流程

```text
接收上报
  |
  +--> 校验 client_type / page_key / metric_name / duration_ms
  |
  +--> 拦截敏感字段和超长字段
  |
  +--> 记录 server_received_at
  |
  +--> 写入 SQLite / MySQL 兼容存储
  |
  +--> 聚合查询读取统计结果
```

后端不得信任客户端上报的身份、权限或用户标识。公开端和小程序上报只作为匿名性能事件；管理端查询能力必须鉴权。

## 5. 管理端观测流程

```text
管理员进入性能观测页
  |
  +--> 选择时间范围、端类型、页面、版本、网络
  |
  +--> 查看摘要指标和慢页面排行
  |
  +--> 对比版本趋势
  |
  +--> 定位慢页面 / 慢指标 / 样本不足项
```

管理端页面是否纳入首期实现可在评审时确认；若延期，后端聚合接口和数据结构仍需为后续页面预留。

## 6. 与相关需求差异

| 关联项 | 差异 |
|---|---|
| `REQ-0072-client-request-identity-standard` | 关注跨端请求归因和请求标识；本需求关注真实用户页面性能事件和加载体验指标。 |
| `REQ-0076-observability-dashboard` | 关注日志审计、请求日志和 Task Trace 观测；本需求新增端侧 RUM 采集与页面性能聚合。 |

## 7. 异常与降级

- 上报接口不可用：端侧静默丢弃或延后批量上报，不阻断页面。
- payload 校验失败：后端返回统一错误响应，端侧不展示内部错误。
- 样本不足：管理端标记“样本不足”，不展示误导性趋势结论。
- 采样关闭：端侧不生成或不上报性能事件，业务功能不受影响。
- 权限不足：管理端查询返回权限错误，不泄露性能数据明细。
