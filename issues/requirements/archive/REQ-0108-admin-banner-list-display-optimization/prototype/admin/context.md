# Prototype Context

## 页面

Web 管理后台 Banner 管理列表页。

## 目标布局

表格保留现有页面结构、摘要卡、筛选区、分页和操作列，仅调整字段呈现：

| 列 | 目标 |
|---|---|
| Banner | 仅显示主图/缩略图；不显示标题、内部识别、位置、状态、排序等文本。 |
| 展示位置 | 保留现有展示位置文案。 |
| 展示端 | 保留现有展示端 Badge。 |
| 跳转类型 | 保留现有跳转类型 Badge。 |
| 跳转对象 | 新增独立列，显示品牌名 / SKU 名 / 专题名 / 外部链接 / `-`。 |
| 状态 / 有效期 / 排序 / 更新时间 / 操作 | 保留现有列与行为。 |

## 交互约束

- 长跳转对象单行截断，不撑宽整表。
- 外部链接完整值可通过 title tooltip 或等价方式查看。
- 新增列后操作列仍可见、可点击。
- 不新增页面说明文字或营销式卡片。
- 无需本阶段提供 PNG；OpenSpec 设计阶段可根据实际表格宽度补充 Skeleton 或截图证据。
