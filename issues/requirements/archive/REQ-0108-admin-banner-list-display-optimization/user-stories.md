# User Stories

## US-001 运营查看 Banner 主图

作为后台运营，我希望 Banner 列只显示主图或缩略图，以便我能快速通过图片识别当前 Banner 素材。

验收要点：

- Banner 列不展示标题、内部识别、展示位置、状态、排序等文本。
- 图片加载失败时仍有现有 fallback 展示。
- 行高和图片尺寸保持可扫描，不撑乱列表。

## US-002 运营查看跳转对象

作为后台运营，我希望列表中有独立“跳转对象”列，以便不用进入编辑弹窗也能知道 Banner 点击后会跳到哪里。

验收要点：

- 品牌详情显示品牌名称。
- SKU 详情显示 SKU 名称，不显示 SKU 编码。
- 专题页显示专题名称。
- 外部链接显示链接地址。
- 无跳转显示 `-`。

## US-003 运营保留现有列表操作习惯

作为后台运营，我希望这次优化不改变已有列表列和操作入口，以便继续使用现有筛选、分页、上下线、编辑和删除流程。

验收要点：

- 展示位置、展示端、跳转类型、状态、有效期、排序、更新时间、操作列继续保留。
- 展示端、状态、时间状态筛选不回退。
- 上线、下线、删除仍使用原有二次确认和 fixed toast。

## US-004 开发同步 API 展示字段

作为开发人员，我希望后端列表接口直接返回跳转对象展示字段，以便前端列表无需按行额外请求品牌、SKU 或专题接口。

验收要点：

- 管理端 Banner 列表响应新增只读 `jump_target_label` 或等价字段。
- OpenAPI、Orval 和前端类型同步。
- 创建/更新请求体不新增必填字段。
