# 管理端搜索体验原型上下文

## 目标

本上下文用于后续管理端列表搜索统一设计，不提供独立 HTML 原型。后续实现应优先复用 `AdminListPage` 或既有筛选卡片样式，避免每个列表页私有化搜索交互。

## 页面范围候选

| 页面 | 搜索对象 |
|---|---|
| 品牌管理 | 品牌名称、简称、英文名称 |
| 类目管理 | 类目名称、层级、状态 |
| SKU 管理 | SKU 名称、编码、品牌、类目、规格 |
| 规格管理 | 尺寸名称、宽度、长度、备注 |
| Banner 管理 | 展示位置、跳转对象、链接 |
| 证书管理 | 证书名称、编号、发证机构、品牌 |
| 用户管理 | 用户名、昵称、邮箱、手机 |
| 日志审计 | 操作者、路径、请求 ID、任务链路 ID |

## 交互原则

- 关键词、筛选项、重置按钮、表格和分页顺序应保持一致。
- 搜索或筛选变化后页码应回到第一页。
- 空态需区分“暂无数据”和“当前条件无结果”。
- 状态类操作仍遵守 DS confirm，不因搜索改造回退为原生确认。
- 搜索成功/失败反馈不得造成页面纵向位移。

## 待后续确认

- 最终纳入哪些管理端列表页。
- 哪些列表需要新增后端关键词参数，哪些只统一前端控件。
- 是否需要为 `AdminListPage` 扩展受控关键词输入能力。
- 是否需要在 `/design-system` 增加搜索/筛选统一示例。
