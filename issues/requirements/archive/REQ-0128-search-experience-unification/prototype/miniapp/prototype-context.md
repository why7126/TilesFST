# 小程序搜索体验原型上下文

## 目标

本原型上下文用于后续 OpenSpec 设计和 UI 验收，不提供最终视觉稿。目标是统一小程序搜索入口、跳转参数和完整搜索页承接方式。

## 页面入口建议

| 页面 | 入口形态 | 默认范围 |
|---|---|---|
| 首页 | 高权重搜索入口，位于自定义导航下方首屏区域 | `all` |
| 全部分类页 | 不展示搜索入口，保持分类双栏浏览 | N/A |
| 品牌列表页 | 当前页品牌名称、简称、英文名输入过滤；搜索态隐藏 Banner | `brand` |
| 证书列表页 | 当前页证书名称、品牌名称、证书类型输入过滤 | `certificate` |
| 商品列表页 | 当前列表上下文搜索入口 | 保留 `categoryId` / `brandId` / `section` |
| 收藏页 | 当前收藏范围输入过滤 | `favorites` |

## 交互原则

- 全局搜索跳转 `/pages/search/index` 承接完整搜索体验。
- 列表内搜索仅过滤当前列表范围，不替代完整搜索页；品牌、证书和收藏列表页搜索结果必须保持当前页卡片布局，不跳完整搜索结果页。
- 入口点击和搜索提交必须携带 `sourcePage`。
- 搜索入口文案需说明可搜索对象或当前范围。
- 异常态下尽量保留搜索入口作为恢复路径。

## 待后续确认

- 商品列表页是否直接内嵌输入框，还是只提供跳转完整搜索页的入口。
- 收藏页已定稿为当前收藏范围搜索，不进入完整搜索结果页。
- 搜索页是否需要把品牌、证书、类目结果卡片抽成轻量组件。
- 是否需要导出 PNG 或小程序截图作为 UI 验收基准。
