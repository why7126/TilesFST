# REQ-0128 验收清单

## 功能 AC

- [ ] AC-001 小程序首页展示高权重搜索入口，点击进入 `/pages/search/index`，并携带首页来源信息。
- [ ] AC-002 首页搜索入口不遮挡自定义导航栏、Banner、快捷入口、新品推荐、热销推荐和全部产品区。
- [ ] AC-003 小程序统一搜索入口支持入口模式和输入模式，具备关键词、placeholder、scope、sourcePage、disabled 等契约或等价能力。
- [ ] AC-004 品牌页、证书页、商品列表页和收藏页具备统一搜索入口或等价搜索路径；品牌、证书、收藏搜索保持当前页卡片布局；底部 Tab「全部分类」页不展示搜索入口，保持纯分类浏览。
- [ ] AC-005 完整搜索页继续承接搜索首页、热门词、历史搜索、关键词联想、综合结果、分区结果、筛选、分页和无结果态。
- [ ] AC-005A 搜索结果页品牌卡片展示品牌图片或稳定占位、品牌名称和 `x 个 SKU`，不得展示“x 个公开 SKU”。
- [ ] AC-005B 搜索结果页证书卡片展示证书图片或稳定占位、证书名称、品牌和证书类型。
- [ ] AC-005C 搜索结果页在下滑到底且仍有下一页时自动加载更多，并避免 loading 中重复请求。
- [ ] AC-005D 综合 Tab 加载更多时按分区合并结果：首屏保留最佳匹配、品牌和证书分区，后续页只向 SKU 分区追加新 SKU，不得覆盖已展示卡片。
- [ ] AC-005E 搜索接口翻页请求应避免重复计算首屏摘要型数据；综合 Tab 与 SKU Tab 的后续页只返回继续展示所需的 SKU 数据、分页状态和必要计数。
- [ ] AC-005H 首页带关键词进入完整搜索页时不额外请求搜索首页；完整搜索首屏不通过 `get_search_home()` 同步生成推荐词或触发 `hot_score metadata LIKE` 慢查询分支。
- [ ] AC-005I 完整搜索首屏按 Tab 执行必要查询：综合 Tab 不查询未展示的 facets、类目 named、规格 named；品牌、证书、SKU 单独 Tab 不查询其他 Tab 数据。
- [ ] AC-005J 品牌关键词精确命中或高置信命中时，完整搜索页 SKU 查询使用品牌 ID 过滤，不走全字段 SKU `OR LIKE` 主路径。
- [ ] AC-005K 完整搜索接口提供服务端分段耗时观测信号，至少可定位品牌识别、SKU list、SKU count、品牌 named、证书查询和总构建耗时，且不输出敏感原文或结果明细。
- [ ] AC-005L 小程序列表型 SKU 卡片构建不逐卡片同步探测对象存储文件存在性；列表图片使用约定缩略图 / 展示图 URL，并由端侧图片 fallback 兜底缺失素材；详情主媒体、Banner、证书详情和品牌 Hero 保留存在性探测。
- [ ] AC-005F 搜索结果页自动加载下一页时不得用整页 loading 覆盖已展示结果，底部仅显示轻量加载状态或“已加载全部”，且不得展示黄色“加载更多”主按钮。
- [ ] AC-005G 综合 Tab 结果展示顺序为最佳匹配、品牌、证书、SKU；顶部 Tab 顺序保持综合、品牌、SKU、证书。
- [ ] AC-006 多页面跳转搜索页时，搜索页能正确识别来源页面、搜索范围和初始关键词。
- [ ] AC-007 商品列表支持结合当前分类、品牌、section 或关键词上下文进行搜索或进入搜索结果。
- [ ] AC-008 品牌列表支持按品牌名称、品牌简称和品牌英文名在当前页过滤；搜索结果保持品牌列表页卡片布局，搜索态隐藏 Banner 轮播，清空后恢复完整品牌列表和 Banner。
- [ ] AC-009 证书列表支持按证书名称、品牌名称、证书类型枚举或中文类型标签在当前页过滤，搜索结果保持证书卡片布局，不跳完整搜索结果页。
- [ ] AC-010 收藏页收敛为当前收藏范围内搜索，搜索结果保持收藏卡片布局，并移除或弱化去全局搜索调整入口。
- [ ] AC-011 列表内搜索空态必须说明当前搜索范围，并按页面策略提供调整关键词、清空当前搜索或进入全局搜索的适用路径。
- [ ] AC-012 管理端品牌、类目、SKU、规格、Banner、证书、用户、日志等主要列表按最终清单统一关键词搜索和筛选区体验。
- [ ] AC-013 管理端搜索、筛选、重置后分页状态正确，展示后端真实 total，不使用全量拉取后的伪分页作为验收结果。
- [ ] AC-014 管理端搜索结果只包含当前登录用户有权查看的数据，小程序搜索仅返回公开可见数据。
- [ ] AC-015 搜索请求失败时保留关键词和筛选条件，并提供重试反馈；联想失败时仍可直接提交搜索。

## UI / 体验 AC

- [ ] AC-016 小程序搜索入口在常见 320 到 430 pt 宽度下不与底部 TabBar、返回首页悬浮按钮、列表内容或错误态按钮发生不可接受遮挡。
- [ ] AC-017 小程序搜索入口视觉与现有暗色旗舰风一致，入口文案能区分全局搜索和当前列表搜索。
- [ ] AC-018 管理端列表搜索区优先复用 `AdminListPage` 或既有筛选卡片样式，关键词、筛选项、重置按钮、表格和分页顺序一致。
- [ ] AC-019 Web 管理端 UI 实现不得新增裸 Hex，必须使用 Design System semantic token 或既有共享样式。
- [ ] AC-020 后续 OpenSpec 设计需记录是否需要原型或截图验收；若涉及 prototype，需按 prototype UI 验收规则提供证据。

## 数据、接口与观测 AC

- [ ] AC-021 后续 Change 必须声明 `product_data_collection_observability.status=applicable`，并列出微信小程序行为事件、微信小程序请求封装、Web 管理端行为事件、Web 管理端请求封装和后端 API 请求日志影响。
- [ ] AC-022 搜索入口点击、搜索输入停顿、搜索提交、联想曝光、联想点击、结果曝光、结果点击、无结果、列表筛选和重置使用稳定事件名。
- [ ] AC-023 行为事件属性包含来源页面、搜索范围、关键词脱敏摘要、结果数量、选中 Tab、筛选条件摘要、请求 ID 或 N/A 原因。
- [ ] AC-024 小程序和 Web 管理端搜索请求按端请求封装透传行为链路字段，使行为事件可与后端 `request_logs` 关联。
- [ ] AC-025 搜索关键词、筛选条件和错误摘要不得保存 Authorization、Cookie、Token、密码、真实密钥、完整请求体、完整响应体、本机绝对路径或完整内部对象 key。
- [ ] AC-026 普通搜索默认不接入 Task Trace 的 N/A 原因需写入 Change；若后续判定为长耗时复杂查询，必须按 Task Trace 覆盖规则补充任务链路验收。
- [ ] AC-027 若新增或调整后端查询参数，必须声明请求参数、长度限制、枚举约束、响应字段、错误码、OpenAPI、Orval、API 文档和前后端测试影响。
- [ ] AC-028 若新增数据库索引或检索字段，必须同步 SQLite / MySQL schema、迁移、数据库文档和测试；若不改 DB，需记录不改原因。
- [ ] AC-029 请求日志和行为事件保留周期不因本需求改变；若后续改变，必须记录审批原因、影响范围、成本、隐私和合规影响。
