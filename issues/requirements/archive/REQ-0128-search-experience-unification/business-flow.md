# REQ-0128 业务流程

## 1. 总体流程

```text
用户进入小程序首页 / 品牌 / 证书 / 商品列表 / 收藏
  -> 看到统一搜索入口或列表内搜索路径
  -> 点击入口
      -> 携带 sourcePage / scope / keyword 等上下文进入 /pages/search/index
      -> 搜索页展示搜索首页或直接展示结果
      -> 用户输入关键词
          -> 触发联想
          -> 提交搜索
          -> 展示综合结果 / 分区结果 / 无结果推荐
          -> 点击商品、品牌、类目或证书进入详情

管理端用户进入主要列表
  -> 使用统一关键词搜索和筛选区
  -> 前端提交查询参数
  -> 后端按权限和查询条件返回真实分页结果
  -> 列表展示结果 / 空态 / 错误态
  -> 搜索、筛选、重置行为写入行为事件并关联请求日志
```

## 2. 全局搜索与列表内搜索分层

```text
全局搜索
  范围：SKU、品牌、类目、证书
  承接：/pages/search/index
  适用：用户不知道对象在哪个列表，或从任意页面快速找资料

列表内搜索
  范围：当前页面当前列表
  承接：当前列表页或当前列表 API
  适用：用户已在商品、品牌、证书、管理端列表等明确上下文中查找
```

## 3. 小程序入口流程

```text
首页
  -> 高权重搜索入口
  -> sourcePage=home
  -> scope=all

全部分类页
  -> 不展示搜索入口
  -> 保持一级 / 二级分类双栏浏览
  -> 进入对应商品列表

品牌列表
  -> 当前页输入品牌名称 / 简称 / 英文名
  -> 请求 /api/v1/miniapp/brands?keyword=...
  -> 保持品牌列表卡片布局
  -> 搜索态隐藏 Banner，清空后恢复完整品牌列表和 Banner

品牌详情
  -> 保留品牌商品与证书浏览入口

证书列表
  -> 当前页输入证书名称 / 品牌名称 / 证书类型
  -> 请求 /api/v1/miniapp/certificates?keyword=...
  -> 保持证书列表卡片布局
  -> 清空后恢复完整公开证书列表

商品列表
  -> 当前列表上下文搜索
  -> sourcePage=product-list
  -> 保留 categoryId / brandId / section / keyword 等上下文

收藏
  -> 当前收藏范围输入过滤
  -> 保持收藏卡片布局
  -> 搜索空态提供清空关键词，不展示显著全局搜索调整入口
```

## 4. 管理端列表流程

```text
进入管理端主要列表
  -> 加载默认分页数据
  -> 用户输入关键词或调整筛选项
  -> 页码重置到第一页
  -> 发起带 page/page_size/keyword/filter 的请求
  -> 后端校验查询参数并按权限过滤
  -> 返回 rows + total
  -> UI 展示表格、分页、空态或错误态
  -> 成功/失败反馈使用 fixed toast，危险状态变更使用 DS confirm
```

## 6. 异常与降级

- 搜索入口所在页面加载失败时，若页面仍可交互，应保留搜索入口或回到搜索页的恢复路径。
- 联想失败时不阻断搜索提交。
- 搜索请求失败时保留关键词和筛选条件，允许用户重试。
- 列表内搜索无结果时明确当前搜索范围，避免用户误以为全站无结果。
- 行为采集失败不得阻断搜索、跳转、筛选或结果点击。

## 7. 后续实现边界

- 不把完整搜索页嵌入所有列表页。
- 不新增外部搜索引擎。
- 不新增搜索词运营后台。
- 不默认新增 DB 表；普通索引是否需要由后续 OpenSpec 设计和性能证据决定。
- 管理端和小程序权限边界保持不变。
