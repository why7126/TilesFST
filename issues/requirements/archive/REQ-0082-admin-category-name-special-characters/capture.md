# 一句话

管理后台瓷砖类目名称允许使用特殊字符，同时保持最多 15 个字符限制。

# 原始描述

管理后台 瓷砖类目的类目名称命名规则调整，由【最多 15 个字符，只能包含中文、英文和数字】调整为【最多 15 个字符，只能包含中文、英文、数字和特殊字符】

# 背景与关联

- 父需求：`REQ-0005-tile-category-management`
- 关联需求：`REQ-0077-category-name-max-length-15`
- 涉及端：管理后台类目创建与编辑入口；后端类目名称校验；如店主端或小程序展示存在类目名称过滤/展示假设，需同步评估
- 业务价值：支持运营使用更贴近业务命名习惯的类目名称，例如带连接符、括号、斜杠等特殊字符的分类表达
- 预期后续：需要确认前端表单校验、后端 API Schema/Service 校验、错误提示、测试夹具与现有数据兼容性是否仍限制为中文、英文和数字

# 待澄清

- [ ] “特殊字符”是否允许全部可见符号，还是仅允许常见业务符号（如 `-`、`_`、`/`、`&`、`()`、`·` 等）
- [ ] 是否需要禁止空白控制字符、换行、前后空格或连续特殊字符
- [ ] 超出 15 个字符或包含不允许字符时，管理端与 API 错误提示文案是否统一
- [ ] 是否需要回归类目列表、类目选择器、商品筛选、小程序分类页等展示位置的排版与搜索行为
