# 媒体状态原型说明

## 1. 定位与边界

media-states.html 是已批准的局部交互策略，覆盖管理端、店主 Web 与小程序示意宽度。不是新页面、正式播放器或小程序实现，不修改导航、管理表格或实际图片裁切。示意符号和时间均为 Mock，无API、真实媒体、COS或存储请求。原型控制栏和状态核对侧栏属于评审工具，不进入产品。

## 2. 状态合同

| 状态 | 产品表现 | 可用操作 |
|---|---|---|
| 正常 | 媒体可读，保持布局 | 现有播放/暂停、原图预览或文件打开 |
| 加载中 | 固定区域显示正在加载 | 不重复发起读取 |
| 恢复中 | 固定区域提示恢复，保留播放意图和位置 | 等待有界恢复，退出取消 |
| 重试耗尽 | 区域内失败提示 | 手动重新加载，开启新的有界尝试 |
| 不可访问 | 不显示旧敏感媒体 | 无绕权重试或代理入口 |
| 规格降级 | 显示已授权可用图片 | 保留预览，实际是否提示按页面合同确定 |
| 网络中断 | 离线提示 | 网络恢复后有界重试 |

可通过状态选择器注入场景，失败/离线的“重新加载”演示800毫秒后回到正常，模拟延时不代表真实验收指标。播放/暂停意图在手动恢复中保留。视频时间仅作视觉标记，原型不能证明真实seek。

## 3. 样式与可访问性

沿用工业石材暗色语义；颜色取自 src/web/src/styles/globals.css 的semantic变量快照，不定义新色板。固定媒体比例、明显focus、原生button/select、aria-live与aria-busy支撑状态评审。桌面评审目标1440px，小程序示意390px；实施以各端现有媒体尺寸与权限为准，不将本演示侧栏搬入产品。

## 4. 后续UI证据

HTML优先于PNG，context限定原型适用区域；实际页面其他部分沿用现有设计。PNG尚未导出，为非阻塞补充。后续Change需先写UI Contract、完成Skeleton首轮确认，再做1440px、关键交互、低视口、小程序证据及computed style核对。原型不作为线上/真机或功能验收证据。
