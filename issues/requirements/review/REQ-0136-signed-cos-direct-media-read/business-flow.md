# 业务流程

## 1. 正常读取

```text
进入现有页面 / 打开预览 / 恢复页面
  → 取得业务媒体标识及规格
  → 判断缓存授权身份、资源版本与到期时间
      ├─ 有效且符合使用窗口 → 读取
      └─ 无效 / 临近到期 → 合并刷新请求
          → 后端按端、角色、业务可见性和归属鉴权
          → 解析受控历史引用与候选对象
          → 返回签名地址、到期时间、规格和模式
  → 客户端直接读取 COS
  → 可见媒体 / 播放 / 文件打开
  → 记录脱敏结果
```

## 2. 失败与恢复

```text
媒体加载失败
  → 已切换媒体或页面销毁？是 → 忽略晚到结果
  → 权限拒绝 / 下架 / 无可用对象？是 → 终止，显示不可用
  → 网络不可用？是 → 显示离线提示，恢复后按预算重试
  → 原因未知或可恢复？是 → 在统一预算内重新解析
      → 新授权成功 → 换地址并恢复状态
      → 重试耗尽 → 失败占位 + 人工重试
  → 仅批准的错误类型及灰度策略允许代理回退
      → 同等业务鉴权 → 限额代理 → 可观测结果
```

图片、视频和附件共享一次恢复预算，规格切换、续签及代理不能各自循环叠加。人工重试开启新的有界尝试，仍受后端限流与当前权限控制。用户取消、退出、切换媒体后停止恢复。

## 3. 视频与相册

视频更换地址前保存媒体身份、当前位置、播放/暂停状态；新资源就绪后恢复位置，遵循平台手动播放限制。错误后仅授权成功但未恢复画面或位置视为恢复失败。HEAD 探测、Range 与跳转需独立验证。

相册打开前刷新当前图及必要地址；浏览下一张、返回前台或预览原图时继续检查有效期。派生图缺失由后端在同一授权媒体内解析，原图降级按批准策略执行并记录。

## 4. 权限与回滚

公开端只为当前公开可见资源签发授权，管理端可按权限预览未发布媒体。下架或撤权后拒绝新授权；旧链接访问窗口以 requirement.md 的 D-002 为准。代理入口不得通过任意 Key 绕过业务鉴权。

灰度关闭影响新读取，页面中已发出的有效签名不会因开关自动失效。配置传播、页面刷新和在途请求均需记录验证边界；COS 不可用时代理同一存储不保证恢复。

## 5. 关联边界

无父需求，不存在父子差异。REQ-0135 管理上传申请、确认与派生处理；本需求消费已确认且符合业务权限的稳定媒体引用。读取过程不搬迁对象、不回写签名到数据库，也不重新生成派生图。

观测贯穿授权、候选解析、签名、端侧读取及恢复；普通 COS 文件传输不伪造后端 request log，参见 acceptance.md AC-014。
