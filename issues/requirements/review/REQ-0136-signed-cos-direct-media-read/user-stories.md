# 用户故事

本文件定义角色目标及 FR/AC 映射；验收事实由 acceptance.md 维护，策略与参数由 requirement.md 定义。

| 编号 | 用户故事 | 功能映射 | 验收要点 |
|---|---|---|---|
| US-001 | 作为管理人员，我希望已获权限的媒体直接加载并可预览，以便检查商品和品牌资料 | FR-001/002 | AC-001/002/011：授权归属、字段覆盖、同会话预览 |
| US-002 | 作为店主，我希望公开商品视频能首播、拖动和重播，以便查看产品细节 | FR-005 | AC-005/006：三端 GET/HEAD/Range 及播放位置 |
| US-003 | 作为长时间浏览者，我希望返回页面后媒体能自动恢复，失败时可手动重试 | FR-003/004 | AC-003/004/013：有效期、并发合并、终止与晚到请求 |
| US-004 | 作为图片浏览者，我希望列表保持轻量且可打开原图，相册中后续图片也可正常加载 | FR-006 | AC-007：各规格、相册续签及降级 |
| US-005 | 作为证书查看者，我希望文件可以下载或在小程序打开，失败时有明确提示 | FR-006/009 | AC-008：文件类型、授权到期与合法域名 |
| US-006 | 作为公开内容管理者，我希望下架或撤权后不再产生新授权，旧链接按批准策略处理 | FR-001/003/008 | AC-002/003/010：不可见媒体、撤权窗口及代理权限 |
| US-007 | 作为维护人员，我希望历史资料继续可读，回退不会跨业务对象或形成无限循环 | FR-007/008 | AC-009/010：历史候选、外部地址和回滚 |
| US-008 | 作为运维人员，我希望可分端灰度并量化直读收益，出错时能够定位授权和文件传输 | FR-009/010 | AC-012/014/015/016：分层证据、流量、日志与回退阈值 |

无父需求。REQ-0135 负责上传与确认，本需求不增加上传状态机；上传完成后媒体回显作为读取兼容回归。
