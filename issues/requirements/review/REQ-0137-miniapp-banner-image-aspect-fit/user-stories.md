# 用户故事

| 编号 | 用户故事 | 关联要求 | 验收入口 |
|---|---|---|---|
| US-001 | 作为浏览首页和品牌列表的店主，我希望看全 Banner 的宣传文字及画面边缘，以便准确了解品牌和产品。 | FR-001、002 | AC-001、002、005 |
| US-002 | 作为浏览品牌详情的客户，我希望看全品牌头图并读到品牌名称与简介，避免文字和图片互相遮挡。 | FR-001、003 | AC-003、006 |
| US-003 | 作为选型人员，我希望商品顶部图片等比完整呈现，并可继续预览和切换媒体，以便判断瓷砖纹理与边缘。 | FR-001、004 | AC-004、007 |
| US-004 | 作为移动端用户，我希望图片加载、回退和切换不引起页面跳动，失败时仍有清晰占位。 | FR-002、005 | AC-005、008、009 |

各故事仅覆盖四类大图位，视频、非 Banner 缩略图和媒体来源策略沿用既有规则。可勾选验收事实只在 acceptance.md 维护。
