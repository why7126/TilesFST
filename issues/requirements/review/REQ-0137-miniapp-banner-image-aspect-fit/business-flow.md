# 业务流程

```text
进入首页 / 品牌列表 / 品牌详情 / 商品详情
  |
  +-- 目标为视频或非 Banner 图片 --> 沿用既有展示和交互
  |
  +-- 目标为四类大图图片项
        |
        +-- 按既有规则取得展示图 / 缩略图 / 占位
        |     +-- 加载失败 --> 既有回退 --> 无可用图片时既有文案或占位
        |
        +-- 建立固定尺寸图片区
        |     +-- 品牌详情：在原头图总高度内预留独立文字区
        |
        +-- 等比完整适配、居中、允许留白
        |
        +-- 用户切换轮播 / 点击 Banner / 预览图片
              +-- 执行既有交互，切换后容器高度不变
```

## 状态与边界

| 状态 | 图片表现 | 布局与行为 |
|---|---|---|
| 加载中 | 既有骨架或占位 | 与加载成功态保持区域尺寸稳定 |
| 展示图成功 | 完整适配展示图 | 不改变 URL 来源和点击行为 |
| 展示图失败、缩略图成功 | 完整适配缩略图 | 回退不改变容器高度 |
| 全部失败 / 空数据 | 既有占位或文案 | 不显示破图；不新增跳转语义 |
| 商品图片与视频混排 | 图片完整适配，视频沿用现状 | 不通过共享 gallery-image 样式误改 video |

## 品牌详情局部布局方案

头图总高沿用 380rpx。原型在其中预留底部 160rpx 品牌文字区，上部 220rpx 图片区完整适配；两区不重叠。文字区保留品牌名、英文名和简介，沿用品牌名一行、简介两行的既有截断语义。缺少可选文案也保留区域高度以避免跳动。该尺寸是待评审局部方案，后续以真实长文案验证可读性。

## 与关联需求的差异

无父需求。REQ-0118 的图片消费矩阵继续作为 URL/变体契约；本需求只调整端侧展示。BUG-0148 负责 grid 商品卡片，与本需求四类大图位互不扩大范围。

## 数据及交互边界

不新增接口、字段、错误码、存储写入或埋点事件。原型中的宽度、比例和加载状态选择器仅为设计核对工具，不作为产品功能进入小程序。
