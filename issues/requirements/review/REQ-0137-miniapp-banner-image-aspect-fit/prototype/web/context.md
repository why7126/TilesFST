# 小程序 Banner 局部原型说明

## 入口与范围

打开同目录 `banner-fit.html`。使用浏览器 HTML 承载小程序四类局部大图设计，因此放入 prototype/web；不表示新增 Web 产品页面。原型控件可切换 320/375/430 pt、2:1/1:1/1:2 素材及正常、回退、加载中、空数据状态。

仅图框、完整适配、留白与品牌文字区域属于设计合同。页面导航和下方文字为上下文示意，不作为整页还原目标。首页 436rpx、品牌列表 348rpx、品牌详情 380rpx、商品详情 1.08×视口宽度来自现有 WXSS；HTML 使用 cqw 示意局部等价比例，最终小程序尺寸仍以既有页面实际视口和 padding 为准。

品牌详情采用 220rpx 图片区 + 160rpx 文字区，保留总高度，避免原叠层遮挡；图片区完整适配，不删除品牌字段，文字沿用一行名称与两行简介的截断策略。

## 视觉与样式

沿用工业石材暗色风格。HTML 的 CSS 变量从 `src/web/src/styles/globals.css` 现有 semantic token 投影；未修改共享 token。SVG 为本地比例测试素材，包含边缘边框与文字，素材色值不是产品 UI token。

## Mock / API 边界

所有标题、品牌、图片与状态为合成测试数据。回退状态复用同一测试图片，只示意容器不变，不证明错误处理或真实缩略图下载。无网络请求、身份认证、对象存储访问、视频播放或真实导航。原型中的选择器不进入产品。

## 证据策略

HTML 是局部设计事实源。PNG 尚未导出，标为非阻塞待补：本次浏览器 URL 安全策略拒绝打开本地文件，未完成浏览器渲染或视觉核验；已保留可独立打开的 HTML。需求评审不等同小程序验收。后续 Change 需建立 UI Contract，先完成 Skeleton 确认，提供 1440px 核对视口及小程序等价证据，并完成关键尺寸、背景和图片模式的样式检查及最终一致性验收。

## 无障碍与交互

选择器有可见标签及键盘焦点，图片有替代文本。原型允许键盘切换状态；不以虚构跳转冒充既有业务功能。
