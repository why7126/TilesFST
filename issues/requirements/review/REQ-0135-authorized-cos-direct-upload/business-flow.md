# 业务流程

## 正常路径

```text
选择文件 → 本地类型/大小提示 → 后端鉴权、归属检查、创建持久会话
    → 返回限定临时对象的短期授权 → 浏览器直接传至 COS
    → 文件传输完成（尚不可保存）→ 请求后端确认
    → 核对会话、实际对象大小/内容类型/完整性
    → 保护正式副本，隔离仍有效的上传权限
    → 视频/文档就绪；图片按既有规格派生并检查结果
    → 可关联 → 用户保存业务 → 原子校验归属、状态并绑定 → 已绑定
```

正式副本与业务 ID 目录的最终落位顺序由设计确定：新建业务的 pending 对象必须通过受控迁移绑定；现有业务也不能把可覆盖的临时对象作为已发布引用。外部复制与数据库事务不能假装处于同一个原子事务，需明确补偿记录及重试责任。

## 状态与操作

| 状态 | 用户可见含义 | 可用动作 / 约束 |
|---|---|---|
| 已申请/传输中 | 正在上传，展示字节进度 | 取消；分片失败时重试或重新鉴权 |
| 待确认/校验中 | 已传输，正在检查文件 | 查询状态；不得绑定；重复确认返回一致结果 |
| 待处理 | 正在生成图片展示版本 | 查询；服务端可重试；不重复传输原图 |
| 可关联 | 文件已准备好，尚未保存至业务 | 保存或移除；保存失败保留可重试状态 |
| 已绑定 | 业务引用有效 | 按原有业务编辑/删除权限处理 |
| 失败 | 标明传输、校验、处理或保存失败 | 可恢复则重试对应阶段；不可恢复则重新选择 |
| 取消/过期 | 本次会话不可继续发布 | 新建会话；晚到请求不可重新激活 |

客户端“传输中”与字节进度是提示，服务端持久状态及对象验证是发布依据。不得把客户端进度作为确认凭证。

## 异常与补偿

| 触发 | 处理 | 可验证不变量 |
|---|---|---|
| 授权过期 | 重新鉴权后按当前会话续期，或明确要求重选 | 无权用户不能通过续期恢复权限 |
| 浏览器关闭或后端重启 | 持久会话可查询；无跨浏览器续传承诺 | 重启不会失去对象归属和清理依据 |
| 取消与完成并发 | 通过状态条件更新决定唯一结果 | 取消不宣称立即撤销已发凭证，晚到对象只能待清理 |
| 确认后旧凭证再次写入 | 正式对象不可被客户端覆盖；验证复制源的一致性 | 被绑定对象与已验证对象一致 |
| 派生失败 | 保留原图、显示处理失败并允许受控重试 | 不默认以缺失派生版本发布，例外策略待评审 |
| 保存/复制/数据库写入失败 | 查询已有结果，幂等重试及补偿孤立副本 | 不重复绑定，不删除已被引用的文件 |
| 清理与绑定并发 | 清理前重新核对引用与状态，使用竞争保护 | 已绑定文件和正在合法绑定的对象不误删 |
| 灰度关闭 | 新会话按配置选择链路，已创建会话按原模式完成 | 不静默改用代理重复上传 |

## 边界与关联

无父 REQ；本需求仅负责上传授权有效期。展示签名刷新和历史 URL 回退归属 REQ-0136，避免复制其状态机。继承 REQ-0131 目录规则，不修改归档事实。API 路由、错误码编号及数据库字段由后续 OpenSpec 设计确定，需求只约束鉴权失败、超限、会话过期、对象不匹配、状态冲突、派生失败等语义。
