# 验收清单

所有项目为待执行，文档与原型检查不代表功能验收。范围依据 [PRD](requirement.md)，流程依据 [business-flow.md](business-flow.md)。

## 功能与非功能验收

- [ ] AC-001 授权申请、续期、查询、确认、取消、绑定均校验登录、角色和业务归属；跨用户/业务会话访问被拒绝，过期权限不能通过续期绕过。
- [ ] AC-002 授权仅允许受控临时对象及必要分片操作，不包含正式对象覆盖或无关列举/删除权限；后端验证真实类型、有效大小上限和分片聚合大小，MIME 伪装与超限失败可定位。
- [ ] AC-003 浏览器 Network 显示视频文件主体直达 COS；后端仅承担控制、必要校验及受控复制，不把完整视频重新下载上传作为正常确认步骤。
- [ ] AC-004 当前页面内分片失败重试、凭证过期续期、上传取消均可操作；100% 仍显示校验/处理阶段，只有服务端就绪才允许绑定；关闭浏览器后不虚假宣称自动续传。
- [ ] AC-005 确认核对对象存在性、真实大小、类型、完整性及归属；客户端声明、回调和 multipart ETag 不作为唯一内容证明；替换对象/错误对象/缺失分片被拒绝。
- [ ] AC-006 重复确认、重复回调和后端重启后查询得到一致持久状态，失败重试不重复创建有效媒体引用。
- [ ] AC-007 取消与确认并发仅产生一个合法终态；取消后的晚到传输/回调不能恢复可绑定状态，并有未完成分片清理证据。
- [ ] AC-008 使用原有仍有效的上传凭证尝试覆盖确认后的文件时，已发布正式对象不受影响；复制期间源对象变化被识别或版本锁定，新建与编辑入口均验证。
- [ ] AC-009 业务保存失败可重试而无需重复上传；模拟复制成功数据库失败、绑定成功响应丢失与清理并发，证明幂等及补偿且不误删已引用媒体。
- [ ] AC-010 图片原始格式/MIME 和既有缩略图、展示图尺寸/质量契约保持一致；派生失败保留原图、显示独立错误并可重试，不默认绕过必要派生发布。
- [ ] AC-011 未确认、未绑定、过期、失败副本和未完成分片按评审确定的保留期清理，记录结果；清理前验证引用及竞争状态，重跑幂等。
- [ ] AC-012 按媒体类别灰度启停，新会话遵循配置、已有会话保持原链路；直传失败不静默代理重传；回滚后保留已确认媒体和既有读取能力。
- [ ] AC-013 新建和编辑中的预览、保存后重新进入及列表展示均正确；形成脱敏对象指纹/存储存在性、API 媒体字段、读取响应头、实际 render 四联证据。
- [ ] AC-014 阶段一覆盖 SKU 视频；阶段二逐项覆盖 SKU 图片、品牌 Logo、Banner 图片、头像、证书图片及既有证书文档，记录入口与生效类型/大小限制，不能用单入口代替全覆盖。
- [ ] AC-015 同文件同网络对比旧代理和直传，覆盖约 19/59/63 MB 视频及有效上限/超限样本；记录样本数、p50/p95、成功率、阶段耗时与服务器出口流量；性能通过阈值依 requirement.md 第8节决策后执行，当前未通过。
- [ ] AC-016 product_data_collection_observability 覆盖 Web 行为事件、后端请求日志、任务及阶段：申请/续期/查询/确认/取消/绑定可关联同一任务；客户端和服务端耗时分别注明来源，嵌套/并行阶段不重复累加。
- [ ] AC-017 日志、事件、Trace 不含凭证、完整签名 URL、原始文件或完整内部 Key；采集失败不阻断上传；保留周期遵循观测规范，验证清理；实现同步 API/OpenAPI/错误码/Orval、SQLite/MySQL schema/migration/Pydantic 及契约测试。
- [ ] AC-018 Compose 经 Web :3000 验证授权/确认与上传入口，生产权限/CORS 和小程序真机展示分别留证；小程序与店主端不新增上传接口/事件，因此端侧上传封装 N/A；本地 Mock 不能标记生产或真机通过。

## 验收证据记录约定

每项记录环境、文件类别与脱敏样本大小、配置版本、操作、预期/实际、证据位置和结论。单元/Mock、Compose、生产、真机分别记录；敏感原始日志留受控环境，仓库仅保留脱敏摘要。安全与状态竞态使用失败注入及反例测试。性能参数、图片方案和失败发布规则未决时，相应项目保持 pending，不能以文档完整勾选通过。
