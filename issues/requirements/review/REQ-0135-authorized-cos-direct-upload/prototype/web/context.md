# 原型范围与交互契约

本原型为现有 SKU 编辑弹窗内上传组件的状态演示，入口为 [index.html](index.html)，不是新增管理页面。沿用 880px 弹窗与工业石材暗色语义 Token；实现应复用现有管理端组件。状态选择器和模拟按钮仅为原型工具，不进入产品。

| 状态 | 展示与操作 | 保存条件 |
|---|---|---|
| 上传中 | 文件名、进度、取消 | 禁用 |
| 校验中 | 100% 已传输、正在校验 | 禁用 |
| 图片处理中 | 正在生成展示版本 | 禁用 |
| 处理失败 | 文件旁错误、重试处理、移除 | 禁用 |
| 可保存 | 即时预览、移除 | 启用 |
| 保存失败 | 保留预览、就近错误、重试保存 | 启用 |
| 已取消 | 重新选择示意入口 | 禁用 |

## Mock / API 边界

所有文件、进度、缩略图为静态 Mock；不申请授权，不上传，不请求 COS，不调用业务接口。预览纹理由 CSS 生成，不能证明真实媒体播放/读取。点击取消立即进入演示取消态；真实实现需等待服务端状态并提示失败。重试处理进入处理中，模拟完成进入可保存；保存按钮演示失败，随后可重试成功。

## 实现与视觉验收计划

1. 对照现有 TileSkuFormModal 拆解上传卡片、错误、底部按钮，编写 UI Contract；其他入口保留各自专属宽度。
2. UI Skeleton 首轮确认后，在 1440px 与矮视口检查宽度、滚动和主要状态，留 computed style 及截图证据。
3. 验证真实图片预览、视频播放、焦点与键盘操作，完成最终一致性回填。

当前仅生成原型并做静态结构检查；PNG 待导出，视觉和交互用户确认未完成。以上不构成生产功能验收。
