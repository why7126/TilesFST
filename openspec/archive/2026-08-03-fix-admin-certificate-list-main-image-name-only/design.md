# Design

## 缺陷分析报告

- 现象：管理后台证书列表中，证书字段除证书主图和证书名称外，还显示图片名称、文件名称、对象 key 或原始 URL。
- 复现：登录管理后台，进入证书列表，观察证书字段是否显示上传资源名称或对象标识。
- 影响：影响管理端证书列表可读性，暴露上传实现细节；不阻断证书维护主流程。
- 严重等级：`low`。
- 关联缺陷：`BUG-0089-admin-certificate-edit-image-filename-noise`。

## 根因分析

证书列表字段的展示边界未与上传/编辑场景区分清楚。上传或编辑组件可以展示文件就绪、文件名或资源标识以辅助操作确认，但列表浏览场景只应展示业务信息。当前列表字段疑似复用或透出了上传态信息，导致文件名、对象 key 或 URL 进入列表。

## Fix Strategy

1. 定位 `/admin/brand-certificates` 证书列表中证书字段的渲染逻辑。
2. 将列表证书字段约束为“主图/占位 + 证书名称”的展示结构。
3. 保留主图缩略图、主图加载失败占位、证书名称、分页、筛选、排序和编辑入口。
4. 不在列表字段中渲染图片名称、证书文件名、对象 key、原始 URL、上传组件内部状态文案或文件就绪文案。
5. 保持新增/编辑弹窗上传信息展示与列表展示逻辑分离，避免回归 `BUG-0089`。

## 测试

- 增加或更新 Web 管理端品牌证书列表组件测试。
- 验证列表字段只展示证书主图和证书名称。
- 验证文件名、对象 key、原始 URL 和上传组件内部文案不出现在证书字段。
- 验证无主图时有稳定占位且证书名称仍可读。
- 验证列表分页、筛选和编辑入口保持可用。

## 非目标

- 不修改品牌证书 API Schema。
- 不修改数据库结构。
- 不修改上传接口、MinIO 对象 key 策略或缩略图生成策略。
- 不调整小程序证书列表或证书详情页。
