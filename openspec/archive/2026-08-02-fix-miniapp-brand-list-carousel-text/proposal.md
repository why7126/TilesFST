## Why

`BUG-0102-miniapp-brand-list-carousel-brand-gallery-text` 已评审通过。微信小程序品牌列表页轮播图区域当前会展示 `BRAND GALLERY` 与 `轮播图保持现有品牌页能力` 等多余说明文案，这些文案更像开发、原型或验收说明，不应作为正式用户可见内容出现在轮播图区域。

该问题不阻断品牌浏览，也不涉及 API、数据库或对象存储，但会影响品牌列表页视觉质量和已交付品牌页体验一致性。修复应清理多余文案，同时保持品牌页轮播图现有图片展示、切换、点击或跳转能力。

## What Changes

- 修改 `miniapp-brand-list-page` 能力规范，明确品牌列表页轮播图不得展示 `BRAND GALLERY` 与 `轮播图保持现有品牌页能力` 等开发/说明性文案。
- 要求修复保持轮播图现有数据来源、图片加载、自动/循环播放、指示点和点击跳转能力。
- 要求删除文案后布局稳定，不出现空白占位、遮挡、错位、高度异常或内容重叠。
- 要求补充小程序静态测试或等价验证，防止品牌列表页再次出现多余说明文案。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `miniapp-brand-list-page`: 修正品牌列表页轮播图展示约束，禁止多余说明文案进入用户可见 UI，并保持既有轮播能力。

## Impact

- 影响微信小程序品牌列表页轮播图展示层与相关静态测试。
- 不影响后端 API、数据库 schema、Web 管理端、店主 Web 展示端、对象存储或 Orval 生成客户端。
- 不需要 Docker Compose 验证；后续实现阶段应使用小程序静态测试和必要的开发者工具/真机回归验证。

## Rollback Plan

若修复导致轮播图图片、切换、点击或布局异常，可回滚本 Change 对小程序品牌列表页展示层的修改，恢复到修复前实现；回滚不得恢复 `BRAND GALLERY` 或 `轮播图保持现有品牌页能力` 作为正式用户可见文案。若必须临时回滚，应在 BUG trace 中记录回滚原因和后续修复计划。
