## 背景

微信小程序商品详情页底部固定操作栏目前在收藏按钮下方展示“收藏 / 已收藏”文字，纵向结构增加了底部固定区域高度，也让次级收藏动作占用过多视觉注意力。REQ-0129 已确认该文案可以由心形状态、颜色和 toast 反馈替代，需要在不改变收藏与分享能力的前提下压缩底部操作栏，并同步调整返回首页悬浮按钮的 actionbar offset。

## 变更内容

- 商品详情页底部收藏按钮移除可见第二行“收藏 / 已收藏”文字，仅保留心形图标状态和必要的语义说明。
- 压缩商品详情页底部固定操作栏高度，并同步调整页面底部内容留白，避免固定栏遮挡或产生过大空白。
- 保持“分享给客户”按钮作为底部主操作，微信 `open-type="share"` 能力、文案和点击热区不降级。
- 调整返回首页悬浮按钮在商品详情 actionbar 场景下的 offset，使其随压缩后的底部栏重新避让安全区。
- 实现阶段补充小程序静态测试与 320/375/430 pt 视觉证据；不新增或修改 API、DB、Orval、请求封装、行为事件或 Task Trace。

## 能力范围

### 新增能力

- 无。

### 修改能力

- `miniapp-sku-detail-page`: 修改 SKU 详情页底部收藏与分享操作栏的视觉与可用性要求，补充紧凑收藏按钮、操作栏高度、返回首页悬浮按钮 offset 和小程序视觉证据验收。

## 影响

- 微信小程序：影响 `pages/tile-detail` 底部 actionbar 的 WXML/WXSS/交互状态，以及 `home-floating-button` 在 actionbar 场景下的 offset 样式。
- 后端 API：不涉及。收藏 API、SKU 详情 API 和分享路径契约保持不变。
- 数据库：不涉及。收藏数据模型、SKU 数据模型和本地存储策略保持不变。
- Web / 管理端 / 店主端：不涉及。
- Orval：不需要重新生成。
- 行为埋点与请求日志：不新增、不删除、不重命名事件；实现 diff 需确认 track 调用未漂移。
- Docker Compose / 对象存储：不涉及。
