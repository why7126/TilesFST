## Overview

本变更聚焦品牌证书编辑弹窗的回显与展示状态修复，不改变品牌证书主数据模型。修复应先在前端确认已有证书详情对象到弹窗表单模型、文件卡片模型和图片卡片模型的映射是否完整；只有在接口响应缺少必要字段时，才扩大为 API 契约补齐。

## 缺陷分析报告

- BUG：`BUG-0108-admin-certificate-edit-file-ready-text-and-image-info`
- 现象：PDF/兼容文件区域显示冗余 `证书文件已就绪`；图片信息全部不能正常显示。
- 复现：登录管理后台，进入证书列表，打开任一已有证书编辑弹窗，查看文件与图片区域。
- 影响：管理后台运营编辑证书时无法可靠判断已有文件、图片列表和主图状态，可能误删、误替换或错误设置主图。
- 严重等级：`medium`。

## 根因分析

编辑弹窗可能复用了新增上传流程中的“上传完成/文件就绪”状态文案，并将已有证书详情对象直接传给图片展示组件，缺少稳定的展示模型归一化。图片字段可能因 `images`、`thumbnail_url`、`url`、`is_main`、排序或 ID 字段不一致而被过滤或隐藏。

## Decisions

- 明确区分“已有文件回显态”和“本次上传完成态”：已有 PDF/兼容文件不显示 `证书文件已就绪`。
- 图片展示以归一化后的证书图片模型为输入，至少覆盖图片 ID、预览 URL、缩略图 URL、主图状态、排序和操作回调。
- 主图状态以后端返回或保存模型中的唯一主图字段为事实源，前端不得把缺省值误判为全部非主图或全部隐藏。
- 不用对象 key、原始文件名或内部路径作为运营主要展示文案。
- 修复必须保留错误态：文件缺失、上传失败、格式不兼容、图片加载失败仍需展示稳定提示。

## 风险

- 若详情 API 与列表 API 返回的图片字段不一致，前端修复可能只覆盖部分入口。
- 若移除冗余文案时误删错误提示，会降低上传或文件缺失问题的可诊断性。
- 若主图兜底逻辑与保存 payload 排序不一致，可能导致保存后再次回显顺序变化。

## 验证

- 前端测试覆盖：打开已有证书编辑弹窗时不显示 `证书文件已就绪`。
- 前端测试覆盖：已有图片列表、主图标记、预览入口、删除入口和设为主图入口正常渲染。
- 前端测试覆盖：新增、替换、删除图片并保存后，再次打开弹窗回显一致。
- 回归验证 `BUG-0089`：不展示对象 key、原始文件名或无意义文件名噪音。
- 若涉及 API 字段补齐，运行后端相关 pytest、OpenAPI 生成和 Orval 校验。
