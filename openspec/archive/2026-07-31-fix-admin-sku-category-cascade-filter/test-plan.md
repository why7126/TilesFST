## Test Plan

## Scope

- 管理后台 SKU 页类目筛选控件。
- 管理端 SKU 列表 API 类目过滤语义。
- 关键词、品牌、状态、素材完整度、分页与排序组合筛选。

## Automated Tests

- 后端 pytest：
  - 父类目筛选返回父类目自身及全部子孙类目的 SKU。
  - 子类目筛选仅返回该子树下 SKU。
  - 类目筛选与关键词、品牌、状态、素材完整度组合时结果正确。
  - 分页与默认排序不因子树过滤发生重复、漏项或顺序跳动。
- 前端 Vitest/Testing Library：
  - SKU 页级联选择控件渲染完整类目层级。
  - 选择任意层级类目后发起正确查询。
  - 清空类目或重置后恢复「全部类目」。
  - SKU 新增/编辑弹窗的类目选择不回归。

## Manual Checks

- 在管理后台打开 SKU 页，确认筛选区可通过级联控件选择一级、二级、三级类目。
- 选择父类目后，列表包含其所有子孙类目的 SKU。
- 选择子类目后，列表只显示对应子树的 SKU。
- 与关键词、品牌、状态、素材完整度组合筛选后结果和分页仍正确。
- 检查筛选区布局、表格列、状态列和操作列无重叠。

## Not Required

- 不需要数据库迁移验证。
- 不需要 Docker Compose 验证，除非实现阶段发现本地单测无法覆盖接口联调。
- 不需要小程序回归测试。
