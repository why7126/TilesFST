## 背景

DeepSeek Harness 在文档层级、Agent Note 决策记录、文档 slop 审计、最小相关验证和防御性模式沉淀上有成熟治理实践。本项目已具备 spec-logs、命令门禁矩阵和知识库，但长期文档仍可能出现事实重复、会话推理残留、历史叙事、验证范围过大和最佳实践模板不统一的问题。

## 变更内容

- 强化文档事实唯一归属：每个长期事实只保留一个事实源，其他位置链接或摘要，不重复完整规则。
- 为治理类 Change 和学习报告补充轻量决策记录字段：采纳原因、未采纳替代方案、验证责任和后续触发条件。
- 新增文档 slop / CoT 泄漏审计规则与轻量脚本，扫描长期文档中的会话推理、临时草稿、review 叙事和历史“现在/之前”表述。
- 强化最小相关验证选择规则，要求按 diff scope 和影响面选择证据，不重复运行已经通过且未被新改动影响的检查。
- 新增防御性模式知识库模板，将已发生或险些发生的问题沉淀为“缺陷类别、预防规则、验证方式”。

## 能力范围

- 无。

### 修改能力

- `agent-workflow-tooling`：补充文档治理、最小相关验证、文档卫生审计和知识库模板行为要求。

## 影响

- API：不影响。
- 数据库：不影响。
- Web / 小程序 / 管理端：不修改业务实现。
- Orval：不需要。
- Docker Compose：不需要。
- 测试：新增文档卫生轻量校验脚本；业务测试不适用。
- 目录边界：仅触达治理资产、OpenSpec Change、Sprint scope、spec-logs 和知识库模板。
