## Overview

本变更修复小程序 SKU 详情页“备注说明信息未显示”的实现偏差。正式规格已经要求 SKU 详情信息展示包含备注说明，因此修复重点是确认并打通以下端到端链路：

```text
管理端/数据源维护备注说明
→ SKU 详情接口返回公开备注说明字段
→ 小程序服务层/页面数据模型映射字段
→ 商品详情页在非空时展示，在为空时安全空态
```

## Bug Analysis

- BUG：`BUG-0086-miniapp-sku-detail-remark-not-shown`
- 现象：商品/SKU 已维护备注说明，但微信小程序商品详情页未展示。
- 严重等级：medium。
- 关联需求：`REQ-0044-miniapp-sku-detail-page`。
- 关联能力：`miniapp-sku-detail-page`。

## Root Cause Direction

当前缺陷可能发生在以下任一环节，实际实现时必须用接口响应和页面渲染证据确认：

1. SKU 详情接口未返回备注说明字段。
2. 小程序端服务层未读取接口中的备注说明字段。
3. 页面数据模型字段名与接口字段名不一致。
4. 页面模板缺少备注说明展示节点或空态条件错误。

## Decisions

- 以 `miniapp-sku-detail-page` 作为唯一 spec delta capability。
- 备注说明属于公开商品补充信息；修复不得暴露后台内部备注、内部审核备注、库存管理或敏感配置。
- 页面展示应复用现有详情信息视觉结构，不新增独立功能入口。
- 空值展示必须遵循既有“空字段安全展示”规则。
- 若接口已有字段，仅修复小程序映射和展示；若接口缺字段，再同步 API 契约和 Orval。

## Validation

- 使用至少一条已维护备注说明的 SKU 验证接口响应字段和值。
- 验证小程序详情页非空备注说明展示，与接口返回值一致。
- 验证备注说明为空时页面不展示异常空白、`null`、`undefined` 或字段名。
- 回归商品主图、轮播图/视频、名称、品牌、类目、规格、收藏、分享和品牌跳转。
- 需要微信开发者工具证据；如出现平台差异，补充真机预览证据。

## Risks

- 字段名历史不一致可能导致后端、Web 管理端和小程序端理解偏差。
- 如果误用内部备注字段，可能暴露不应公开的信息。
- 备注说明内容较长时可能导致详情信息区布局拥挤，需要处理换行、行高和移动端可读性。
