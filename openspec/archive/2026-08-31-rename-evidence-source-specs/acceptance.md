# 验收

## 验收项

- OpenSpec delta 能表达旧 requirement 标题移除与新“证据来源声明 / 诊断” requirement 新增。
- media 与 miniapp 历史规格不再推荐 `production_only_pending` 作为新记录分类。
- 默认发布或归档门禁不因本次变更恢复环境分层强门禁。

- API：不适用。

- 管理端：不适用。
- Orval：不适用。
- Docker Compose：不适用。
