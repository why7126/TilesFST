# Apply 持续执行治理

## 背景

两个 apply 入口的宽泛暂停条件未区分可恢复错误和必要人工决策，部分完成收尾也缺少状态约束，可能导致开发反复等待继续指令。

## 变更内容

统一当前 Change 的持续执行、错误修复、依赖阻塞、恢复与完成判定；保留 Sprint、人工确认、归档和发布边界。补充治理校验与场景验证。

## 能力

- 扩展 `agent-workflow-tooling`：apply 持续执行与部分完成状态契约。

## 影响范围

仅 skills、rules、AGENTS、治理脚本与文档；不修改业务 src、API、数据库、Orval 或 Docker 配置。
