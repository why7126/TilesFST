## Why

BUG-0097 指出管理后台瓷砖 SKU 列表「素材」列在已有图片时仍展示「主图已设」标签。当前业务规则下，只要 SKU 有图片就会有主图兜底；该正向状态标签不提供额外维护判断，反而占用素材列空间并增加运营扫描噪音。

## What Changes

- 移除管理端 SKU 列表素材列中的主图状态标签，包括「主图已设」与「缺主图」。
- 保留图片数量、视频数量等素材完整度信息。
- 删除管理端 SKU 列表中的素材完整度条件筛选；列表请求不再提交 `material_completeness`。
- 确保缺图、缺视频或素材不完整状态仍能通过图片/视频数量识别，不在素材列额外展示状态标签。
- 补充管理端 SKU 列表回归测试，覆盖素材列文案和列表布局不回归。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `tile-sku-management`: 管理端 SKU 列表素材列只展示图片数量与视频数量，不展示主图状态标签；管理端页面不再展示素材完整度条件筛选，列表请求不提交 `material_completeness`。

## Impact

- 影响范围：管理后台 Web 的瓷砖 SKU 列表素材列展示与筛选区。
- 不影响 API 请求/响应契约、数据库结构、权限、MinIO 上传或小程序。
- 不需要 Orval。
- 需要补充或更新前端回归测试。
- 不需要 Docker Compose 验证。

## Rollback Plan

如修复引发素材列信息缺失或布局回归，可回退素材列渲染与筛选区改动，并保留本 Change 的测试用例作为复核基线；回退不得改变后端既有接口能力和图片主图兜底规则。
