## Why

BUG-0089 记录了管理端品牌证书新增 / 编辑弹窗中的 UI 噪音：当证书图片列表已有内容时，“支持 JPG / PNG / WebP，最多 9 张”说明下方会额外展示 `cover.webp`、`page-2.webp` 等图片文件名文本列表。

该文件名列表不承载明确编辑任务，图片缩略图、主图标记、删除、设为主图和继续添加入口已经覆盖必要上下文。当前展示降低弹窗信息清晰度，并与品牌证书多图上传控件的验收意图不一致。

## What Changes

- 移除管理端品牌证书图片上传说明下方的图片文件名文本列表。
- 保留证书图片卡片、主图标记、删除、设为主图、继续添加、上传进度和失败提示。
- 补充前端组件回归测试，覆盖有图片时不展示文件名文本，同时图片操作能力不回归。
- 不调整后端 API、数据库、OpenAPI/Orval、小程序、对象存储、图片上传保存、主图排序、删除或预览行为。

## Capabilities

### New Capabilities

- 无。该变更修复既有管理端品牌证书能力的 UI 展示问题。

### Modified Capabilities

- `brand-certificate-management`: 明确新增 / 编辑弹窗的证书图片上传区不得在上传说明下方额外展示图片文件名文本列表。

## Impact

- Web 管理端：影响 `CertificateImageGrid` 或等价品牌证书图片上传组件。
- 后端/API：无接口契约变化。
- 数据库：无结构变化。
- 小程序：无影响。
- Orval：不需要。
- 测试：需更新品牌证书组件 Vitest / Testing Library 测试。

## Rollback Plan

如修复引发图片上传控件操作回归，可回滚本 Change 对品牌证书图片上传组件和对应测试的修改。回滚不涉及数据迁移、API 回滚或对象存储清理。
