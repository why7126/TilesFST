## ADDED Requirements

### Requirement: 后端授权的直传会话

系统 MUST 逐操作鉴权并持久化唯一会话，短期授权只允许临时对象及必要分片操作；正式对象不可写，大小类型按effective设置在申请和确认时验证。

#### Scenario: 越权与过期续期

- **WHEN** 用户操作其他用户会话或权限被收回后续期
- **THEN** 系统 MUST 拒绝，不能发放凭证或泄露对象信息。

### Requirement: 确认与不可覆盖绑定

系统 MUST 核对实际对象、内容、大小与完整性，客户端MIME及multipart ETag不能单独作证；复制固定已验证内容到客户端不可写稳定对象，幂等绑定，SQLite/MySQL竞争语义一致。

#### Scenario: 确认后再次覆盖临时对象

- **WHEN** 旧授权仍有效且客户端改写临时对象
- **THEN** 已绑定正式内容 MUST 保持不变，复制竞态 MUST 被识别，重复确认返回一致结果。

### Requirement: 恢复取消与残留清理

系统 MUST 支持页内分片恢复、重试、续期、取消及持久查询；清理只覆盖新会话残留，需状态竞争保护和引用复核，不宣称立即撤销已发授权。

#### Scenario: 取消后晚到确认

- **WHEN** 取消已生效但传输或回调晚到
- **THEN** 会话 MUST 不可重新绑定，残留进入受控清理，已绑定对象不被删除。

### Requirement: 图片派生与全入口直传

系统 MUST 分两阶段覆盖SKU视频及既有SKU图片、Logo、Banner、头像、证书图片/文档；图片保持原图和既有派生规格，必要派生失败不可绑定。

#### Scenario: 派生失败后重试

- **WHEN** 图片已上传但必要派生失败
- **THEN** 系统 MUST 保留原图及错误，重试对应阶段而不重复上传，文档按原格式策略跳过派生。

### Requirement: 传输与业务保存状态

管理端 MUST 区分传输、校验、派生、可关联及保存结果，展示真实进度和就近错误，复用DS与既有权限，禁止未就绪新媒体引用保存。

#### Scenario: 传输达到百分之百

- **WHEN** COS传输完成但后端仍校验
- **THEN** UI MUST 显示校验中而非成功；保存失败后 MUST 保留已就绪媒体供重试。

### Requirement: 灰度兼容与链路观测

系统 MUST 按媒体选择上传模式，不静默代理重传；记录脱敏行为/请求/任务阶段与来源，保留期按观测规范；保持历史媒体读取和小程序展示兼容。

#### Scenario: 关闭直传开关

- **WHEN** 存在未完成直传会话时关闭新申请直传
- **THEN** 新会话 MUST 使用配置模式，已有会话仍可确认清理；读取签名刷新不属于本能力。
