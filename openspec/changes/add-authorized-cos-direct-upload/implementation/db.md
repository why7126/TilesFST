# 上传会话数据库实现

字段事实源：docs/04-database-design.md 的media_upload_sessions段。SQLite/MySQL schema与初始化迁移均新增幂等建表，现有业务数据不重写。应用回滚保留会话表和对象版本，待会话结束后另行清理，不能破坏性回滚DROP。

验证：本地SQLite10项仓储测试；一次性MySQL8.2容器内同10项测试通过，独立新表DDL连续执行两次成功。覆盖幂等、不同输入冲突、跨用户隔离、重启查询、回滚、租约恢复/心跳、过期、取消和绑定竞争。测试容器及卷已删除。这些是开发环境证据，不等于生产数据库迁移已执行。
