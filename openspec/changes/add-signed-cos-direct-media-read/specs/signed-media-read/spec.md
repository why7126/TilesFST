## ADDED Requirements

### Requirement: 媒体读取必须按业务归属授权

系统 MUST 提供公开与管理权限隔离的受控读取解析，输入为白名单业务媒体标识与规格，不接受自由Key/URL签名；批量最多50项，单项失败隔离，返回到期时间和稳定标识。

#### Scenario: 批量包含无权媒体

- **WHEN** 请求包含合法媒体与其他业务不可见媒体
- **THEN** 系统 MUST 合法项返回受控描述，不可见项安全失败且不泄露归属

### Requirement: 三端必须有限恢复短期授权

系统 MUST 使用300秒TTL、提前30秒检查、10秒超时、最多2次自动刷新、1/3秒退避及并发4；不得跨身份复用缓存，晚到请求不能覆盖新媒体。

#### Scenario: 页面长停留后恢复

- **WHEN** 页面返回前台且缓存地址过期
- **THEN** 系统 MUST 重新授权并有限恢复，耗尽显示人工重试，拒绝授权终止

### Requirement: 视频必须验证请求方法和恢复位置

三端视频 MUST 支持首播、暂停继续、重播和Range拖动，HEAD探测按方法独立适配；换址后恢复原播放意图与位置，误差不超过2秒。

#### Scenario: 播放中签名过期

- **WHEN** 视频正在播放且地址需更新
- **THEN** 系统 MUST 获取新授权后验证真实恢复位置，不能以授权接口成功替代播放成功

### Requirement: 历史及降级必须保留权限边界

系统 MUST 仅在同一已授权媒体内查找有限历史/规格候选，缺失才继续；外部URL不任意抓取或重签，原图降级可观测。

#### Scenario: 存储拒绝访问

- **WHEN** 候选探测返回权限拒绝或存储故障
- **THEN** 系统 MUST 终止并返回安全错误，不伪装缺失继续扩大候选

### Requirement: 撤权与代理回滚必须受控

系统 MUST 在下架或撤权后禁止新授权，已签发链接可在剩余300秒窗口内访问；默认关闭自动代理回退，显式回退每媒体最多一次且同等鉴权，不开放公共桶。

#### Scenario: 尝试旧代理绕权

- **WHEN** 无权用户访问旧媒体Key或错误代理票据
- **THEN** 系统 MUST 拒绝文件读取，不通过代理扩大权限

### Requirement: 图片附件与观测必须完整验收

系统 MUST 覆盖REQ矩阵的图片规格、相册、文件打开及三端事件，API同步OpenAPI/Orval；日志不得包含签名，证据必须区分key/object/URL/render及环境来源。

#### Scenario: 相册和附件长停留

- **WHEN** 打开过期相册图片或附件
- **THEN** 系统 MUST 先取得当前有效授权并验证实际显示或打开，记录脱敏恢复结果且采集失败不阻断展示
